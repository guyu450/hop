Neo4j视角

描述

Neo4j视角提供了一种查看方式，并允许您从Neo4j数据库查询Hfxt执行历史记录。该视角显示了NEO4J_LOGGING_CONNECTION（用于将执行日志加载到Neo4j）的值，允许选择一个工作流或管道来显示其日志（可选地，指定执行次数并仅显示根执行）。对于选定的工作流或管道（如果未选择，则为所有执行），将显示其ID、名称、类型、读取的行数、写入的行数、输入的行数、输出的行数和被拒绝的行数、错误行数以及执行日期和持续时间。在视角对话框的下半部分，将显示日志文本、错误路径以及一些有用的Cypher查询。

描述

Neo4j视角提供了一种查看方式，并允许您从Neo4j数据库查询Hfxt执行历史记录。

该视角显示了 NEO4J_LOGGING_CONNECTION 的值（用于将执行日志加载到Neo4j），允许选择一个工作流或管道来显示其日志（可选地，指定执行次数并仅显示根执行）。

对于选定的工作流或管道（如果未选择，则为所有执行），将显示其ID、名称、类型、读取的行数、写入的行数、输入的行数、输出的行数和被拒绝的行数、错误行数以及执行日期和持续时间。

在视角对话框的下半部分，将显示日志文本、错误路径以及一些有用的Cypher查询。

虽然功能完备，但我们建议您使用 Neo4j 执行信息位置 插件。
