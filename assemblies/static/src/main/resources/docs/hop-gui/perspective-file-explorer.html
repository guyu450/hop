文件资源管理器视角

描述

文件资源管理器视角是您进行大量文件操作的地方。此视角包含Hfxt已知的最常见文件类型的处理程序。这些显然包括hwf（工作流）和hpl（管道），但也包括JSON、CSV、TXT、XML、Markdown、SVG、日志和SAS 7 BDAT文件。文件资源管理器视角也是您通过Git集成来管理项目版本控制的地方。

文件资源管理器视角是您进行大量文件操作的地方。此视角包含Hfxt已知的最常见文件类型的处理程序。这些显然包括hwf（工作流）和hpl（管道），但也包括JSON、CSV、TXT、XML、Markdown、SVG、日志和SAS 7 BDAT文件。文件资源管理器视角也是您通过 Git集成 来管理项目版本控制的地方。

尽管功能齐全，但文件资源管理器中大多数文件类型的编辑器相当基础。预计这些将在Hfxt的后续版本中得到改进，或者如果您想通过贡献文件编辑器来帮助我们改进Hfxt，请查看 代码贡献指南。

文件操作

文件操作可通过多个工具栏选项实现：

  • 打开选定文件：使用右箭头或双击打开选定文件。您也可以直接双击文件来打开它。如果这是一个工作流或管道，它将在 数据编排 视角中打开。在所有其他情况下，文件将在新标签中打开。

  • 创建文件夹：添加新文件夹。

  • 删除：删除选定的文件或文件夹。

  • 重命名：重命名文件或文件夹。

  • 刷新：刷新文件列表。

  • 显示或隐藏文件：显示或隐藏文件或目录。

Git集成

描述

如果安装了git插件（文件夹 plugins/misc/git），文件资源管理器将在项目主文件夹中查找 .git/config 文件。如果存在此文件，资源管理器视角将开始对列出的文件进行颜色编码：

  • 红色：文件尚未添加到git（未暂存）。

  • 蓝色：文件已更改（已暂存）。

  • 灰色：文件被git忽略。

Git信息

如果有关于所选文件或文件夹的信息，工具栏中的”Git信息”图标将启用。如果您点击它，您将能够在新标签中查看有关git历史记录的各种信息：

在修订历史记录下方，您可以看到文件的修订版本。如果您选择一个修订版本，您不仅能够查看两个修订版本之间的文本差异，还可以使用标签右侧的”可视化差异”按钮。如果您选择”可视化差异”选项，GUI将切换到数据编排视角，在该视角中将打开两个新标签，分别显示更改前后的管道或工作流状态。

各种转换、操作和步骤将添加小信息图标，以指示它们是被更改、删除还是添加。

右键菜单选项

Hfxt Git集成中的右键菜单提供了几个有用的选项，可帮助您直接从界面管理文件和Git操作。以下是每个选项的详细说明：

  • 创建文件夹：在选定目录中创建新文件夹。这对于组织工作流、管道和其他项目资源很有用。

  • 打开：打开选定的文件或文件夹。对于工作流和管道，它将在数据编排视角中启动它们，而其他文件类型将在新标签中打开。

  • 重命名：允许您更改选定文件或文件夹的名称，帮助您保持项目文件的组织和清晰标记。

  • 复制名称：将选定文件或文件夹的名称复制到剪贴板，便于在其他地方粘贴和引用。

  • 复制路径：将选定文件或文件夹的完整路径复制到剪贴板，对于快速导航或与他人共享位置很有用。

  • Git信息：显示所选文件的Git状态的详细信息，包括任何最近的更改。

  • Git添加：将选定的文件暂存以进行提交，这意味着更改已准备好包含在您的下一次Git提交中。

  • Git还原：还原对选定文件所做的任何更改，将其恢复到上次提交的状态。当您需要撤销意外修改时，这很有帮助。

  • Git提交：打开一个对话框，用于将暂存的更改提交到本地Git存储库。您可以添加描述性的提交消息来总结您的更新。

  • 删除：从项目中删除选定的文件或文件夹。请务必谨慎使用此选项，因为它会从您的目录中永久删除该项目。

Git操作

以下是支持的基本git操作：

  • Git添加：将文件暂存以包含在提交中。

  • Git提交：将更改提交到原点。

  • Git还原：检出文件或文件夹以还原更改。

  • Git推送：推送更改。

  • Git拉取：拉取更改。
