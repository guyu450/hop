描述

配置视角为所有 Hfxt配置选项提供了一个集中的位置。

用法

配置视角将配置选项分组到以下标签中：

  • 常规选项控制 Hfxt和Hfxt Gui的行为。

  • 外观控制Hfxt Gui在您的桌面或浏览器中的显示方式。

  • 插件选项提供配置选项，以控制可用的 Hfxt插件的行为。

  • 系统变量允许您设置和配置 Hfxt全局变量。
