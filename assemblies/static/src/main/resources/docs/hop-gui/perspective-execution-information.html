执行信息视角

描述

执行信息视角提供了先前执行的工作流和管道的执行信息概述。该视角允许您浏览执行列表，并向上或向下钻取到父级或子级工作流和/或管道。此外，此视角还提供有关执行状态、日志记录信息、（管道）指标和分析数据的信息。

描述

执行信息视角提供了先前执行的工作流和管道的执行信息概述。该视角允许您浏览执行列表，并向上或向下钻取到父级或子级工作流和/或管道。此外，此视角还提供有关执行状态、日志记录信息、（管道）指标和分析数据的信息。

信息收集

此视角中显示的执行信息不会自动收集。您需要在所选的 管道运行配置 或 工作流运行配置 中指定要将执行信息发送到哪个 位置。

可能的操作：

操作 结果
双击列出的执行记录 有关管道或工作流的信息将加载到该视角右侧的新标签中。
点击刷新图标 将从该位置加载最后100条无父级的执行记录。
点击删除图标 当前选定的执行记录将被删除，或者（确认后）当前选定位置的所有执行记录将被删除。

在底部，您有不同的标签：

标签 描述
信息 在这里，您将找到有关您正在查看的管道或工作流的一般信息
指标 如果您正在检查管道执行情况，您可以查看总体转换指标（如果有）。
日志 在这里，您可以找到管道或工作流的日志文本。日志文本在选择标签时按需加载。日志的第一部分将显示到配置视角中在 最大执行日志文本大小 选项下指定的限制（以字符数指定）。
数据 在管道或工作流执行期间，Hfxt可以捕获各种数据。捕获哪些数据取决于正在进行的工作类型以及捕获的配置方式。例如，捕获的数据量取决于您为管道设置的 执行数据配置文件，或者在操作执行后是否有有趣的信息。

选择图标

如果您点击转换或工作流图标，该视角将自动尝试加载其拥有的所有相关数据。它将切换到底部的 “数据” 标签。在那里，您将找到可以查看的数据集列表。

以下是工作流操作可用的数据集：

数据集 描述
操作结果详情 您将了解是否有任何错误、结果（真/假）是什么，或者操作是否已停止。
操作结果文件 如果操作结果包含任何文件名，它们将在此数据集中
操作结果行 如果操作结果包含任何行，它们将在此数据集中
执行前变量 操作执行前有趣的（与工作流开始时不同）变量列表。
执行后变量 操作执行后有趣的变量（及其值）列表。

以下是使用 执行数据配置文件 在工作流转换中可以捕获的一些数据集：

数据集 描述
…… 的第一行 显示转换写入的第一行。
…… 的最后一行 显示转换写入的最后一行。
…… 的随机行 显示转换写入的随机行选择
数据剖析数据集 根据您启用的数据剖析选项，您可以找到每列的统计信息以及示例行。
