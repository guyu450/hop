管道单元测试

描述

描述了对管道的测试。在测试期间，使用替代数据集作为给定转换的输入，并将测试输出与黄金数据集进行对比。当管道执行产生的结果集与预期结果（黄金数据集）匹配时，测试成功。如果生成的结果与预期不符，测试失败。为了获得更多灵活性，在测试时可以绕过或移除管道中的特定转换。此外，单元测试可以批量执行。有关更多详细信息，请查看”管道单元测试”^。

描述

描述了对管道的测试。在测试期间，使用替代数据集作为给定转换的输入，并将测试输出与黄金数据集进行对比。

当管道执行产生的结果集与预期结果（黄金数据集）匹配时，测试成功。如果生成的结果与预期不符，测试失败。

为了获得更多灵活性，在测试时可以绕过或移除管道中的特定转换。

此外，单元测试可以批量执行。

有关更多详细信息，请查看 管道单元测试^。
