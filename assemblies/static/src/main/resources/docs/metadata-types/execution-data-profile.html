执行数据概要

描述

Hfxt执行数据概要在数据流经管道时构建数据概要。可以选择多个数据剖析器，并对剖析的数据类型和细节进行微调配置。

描述

Hfxt执行数据概要在数据流经管道时构建数据概要。可以选择多个数据剖析器，并对剖析的数据类型和细节进行微调配置。

选项

选项 描述

描述 此执行数据概要要使用的描述

描述

选项

数据概要输出行

允许对转换输出行执行一些基本的数据剖析

  • 样本大小：这是为任何发现的剖析结果保留的最大样本行数（默认值：25）

  • 仅最后转换：是否仅对管道端点（最后转换）执行数据剖析？（默认值：true）

  • 最小值：存储此数据概要的最小值（默认值：true）

  • 最大值：存储此数据概要的最大值（默认值：true）

  • 统计空值：统计此数据概要的空值（默认值：true）

  • 统计非空值：统计此数据概要的非空值（默认值：true）

  • 最小长度：存储此数据概要的最小长度（默认值：true）

  • 最大长度：存储此数据概要的最大长度（默认值：true）

首个输出行

对转换输出的首行进行采样

样本大小（默认值：100）

最后输出行

对转换输出的最后几行进行采样

样本大小（默认值：100）

随机输出行

对转换的输出行进行蓄水池采样

样本大小（默认值：100）
