Azure身份验证

描述

此元数据类型可用于向项目中添加新的Azure存储文件系统。这使你能够同时连接到多个存储账户。使用Azure身份验证连接到Blob存储时，需要在路径中指定容器名称。例如，如果你的Azure身份验证名为az，则需要将容器指定为az:/containerName。

选项

选项 描述
名称 文件系统的名称，将在文件路径 name:// 中使用
描述 用于添加额外信息的描述字段
存储账户名称 Azure中存储账户的名称
存储账户密钥 存储账户的主密钥或辅助密钥
存储终结点 对于默认的Azure终结点留空，使用兼容服务时填写
