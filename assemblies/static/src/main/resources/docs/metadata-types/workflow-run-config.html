介绍如何运行工作流

工作流可以在本地或远程执行。更多详细信息请查看 工作流运行配置。

相关插件

无/所有操作

选项

选项 描述
名称 此工作流运行配置使用的名称
描述 此工作流运行配置使用的描述
执行信息位置 此工作流运行配置要使用的 执行信息位置。
工作流引擎类型 Hfxt 本地工作流引擎或 Hfxt 远程工作流引擎
安全模式 （默认值：false）在安全模式下，Hfxt 在开始工作流执行之前会执行一些数据类型和其他验证。
