选项 信息
类型 关系型
驱动程序 驱动程序链接
包含的版本 无
Hfxt依赖项 无
文档 文档链接
JDBC链接 jdbc:bigquery://[主机]:[端口];项目ID=[项目];OAuth类型=[认证值]
驱动程序文件夹 <Hfxt安装目录>/lib/jdbc

Simba驱动程序打包为一个.zip文件，其中包含许多JAR文件。使用 Hfxt的Bigquery JDBC时，仅需要驱动程序中包含的一部分JAR文件。此外，某些JAR文件可能与Hfxt打包的文件冲突，必须排除。

要排除的SIMBA驱动程序JAR文件（这些JAR文件包含在SIMBA驱动程序中，但与Hfxt库冲突，必须排除）

grpc-alts-<版本>.jar
grpc-api-<版本>.jar
grpc-core-<版本>.jar
grpc-netty-shaded-<版本>.jar

要包含的SIMBA驱动程序JAR文件（仅包含这些JAR文件以进行最小化的Bigquery驱动程序安装）：

api-common-<版本>.jar
gax-<版本>.jar
gax-grpc-<版本>.jar
google-api-services-bigquery-v2-<版本>.jar
GoogleBigQueryJDBC42.jar
google-cloud-bigquerystorage-<版本>.jar
grpc-google-cloud-bigquerystorage-v1-<版本>.jar
grpc-google-cloud-bigquerystorage-v1beta1-<版本>.jar
grpc-google-cloud-bigquerystorage-v1beta2-<版本>.jar
json-<版本>.jar
proto-google-cloud-bigquerystorage-v1-<版本>.jar
proto-google-cloud-bigquerystorage-v1beta1-<版本>.jar
proto-google-cloud-bigquerystorage-v1beta2-<版本>.jar
threetenbp-<版本>.jar

* 使用Hfxt 2.5.0和Simba 1.3.3.1004进行了测试。并非所有认证方法都进行了测试，因此此列表可能不完整。
