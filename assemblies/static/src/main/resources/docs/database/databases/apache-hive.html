分区

Hive需要在字段定义之前生成一个PARTITION子句。要做到这一点，你可以在名为”表分区子句”的特定Hive字段中添加表和子句定义。指定的格式如下：

TABLE1(CLAUSE1);SCHEMA2.TABLE2(CLAUSE2)

例如，如果你想按statecode动态分区一个customers表，你可以添加以下内容：customers(statecode)，对于INSERT INTO语句，Hfxt将添加PARTITION(statecode)。

提示：对于动态分区，你可以在关系型数据库管理系统（RDBMS）元数据的”高级”选项卡中添加以下语句，作为连接后立即运行的语句：

SET hive.exec.dynamic.partition = true;
SET hive.exec.dynamic.partition.mode = nonstrict;
