DuckDB

DuckDB是一个进程内SQL OLAP数据库管理系统。

作为一个进程内数据库，DuckDB易于配置：将DuckDB文件名的路径指定为数据库名称，例如 <PATH_TO_YOUR_DUCKDB_FILE>/duckdb。

需要记住的一点是DuckDB如何管理并发。需要记住的事项总结如下：

  • 一次只有一个进程可以对数据库进行读写操作。

  • 多个进程可以从数据库读取数据，但不能有进程进行写入操作。要设置此行为，请记住在连接选项中指定属性duckdb.read_only = true。

有关详细信息，请参阅 DuckDB Java API文档。
