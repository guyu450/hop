数据库插件

Hfxt对多种数据库类型提供了优化支持。如果您使用的是不受支持的数据库，始终可以创建通用连接。

要创建数据库连接，请转到元数据透视图，右键单击 关系数据库连接 并选择 新建。

连接保存在一个中央位置，然后可供所有管道和工作流使用。如果您已将项目设置为与Hfxt一起使用，数据库信息将位于 ${PROJECT_HOME}/metadata/rdbms 文件夹中。对于每个连接，此文件夹中将生成一个单独的 .json 文件。此json文件将使用连接的名称，并包含所有连接信息。

添加JDBC驱动程序

Hfxt包含适用于所有在与公共许可证兼容的许可下提供驱动程序的数据库的JDBC驱动程序。 Hfxt附带的所有JDBC驱动程序都可以在您的 Hfxt安装文件夹中的 lib/jdbc 中找到。

以下小节中各种数据库类型的文档将向您展示是否包含您的数据库的驱动程序。如果包含，连接编辑器还将显示安装的驱动程序的版本。如果未包含驱动程序，文档将指导您前往下载位置。

将 HFXT_SHARED_JDBC_FOLDERS 环境变量设置为包含您的其他JDBC文件夹的文件夹。将它们放在一个中央文件夹中有助于您轻松升级或更改 Hfxt安装，而无需每次都添加JDBC驱动程序。此变量接受以逗号分隔的列表以指向多个目录，未设置时的默认值是 lib/jdbc，例如 <PATH_TO_YOUR_HFXT_INSTALLATION>/lib/jdbc,<PATH_TO_YOUR_JDBC_FOLDER>。

为避免冲突，请确保每个数据库只有一个驱动程序，并且确保不要有驱动程序的多个副本，例如，不要同时在 HFXT_SHARED_JDBC_FOLDERS 和 hfxt/lib/jdbc 文件夹中都有。

通用连接

如果您要使用的数据库尚无特定的数据库类型可用，您可以使用通用连接。要使用通用连接，您必须将jdbc驱动程序复制到 <PATH_TO_YOUR_HFXT_INSTALLATION>/lib/jdbc 文件夹或 HFXT_SHARED_JDBC_FOLDERS 文件夹中。

查看您的数据库的驱动程序类和URL语法的文档以创建连接。

在”驱动程序类”字段中指定驱动程序类，例如，如果您使用PostgreSQL，类是 org.postgresql.Driver。
