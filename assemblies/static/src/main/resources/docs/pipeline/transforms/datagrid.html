数据网格

描述

数据网格转换功能允许您在网格中输入静态行列表，类似于管道内的电子表格。这通常用于测试、参考或演示目的。将数据网格放置到数据编排网格上。在”元数据”选项卡上，添加字段名称、类型和格式。然后在”数据”选项卡上，为每一行数据添加字段值。

选项

元数据选项卡 指定数据的字段元数据（输出规范）
数据选项卡 包含数据。所有内容均以字符串格式输入，因此请确保在元数据选项卡中使用正确的格式掩码。

元数据注入支持

此转换支持元数据注入。它由两部分组成，即元数据（字段定义）和数据。元数据需要多行来定义字段。数据部分包含两个注入字段，第一个是包含所有值的串联字符串，第二个是用于拆分特定行的分隔符。可以混合使用分隔符，当为空时，使用逗号（,）作为拆分字符串。

限制

目前尚无法在两个现有列之间插入列，或者通常无法在元数据选项卡中重新排列字段顺序。

如果您计划这样做，请确保首先将数据部分复制到电子表格中（选择所有行并复制/粘贴整个网格），更改数据后再将其复制回数据部分。
