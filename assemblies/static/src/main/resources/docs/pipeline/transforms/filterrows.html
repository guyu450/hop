筛选行

描述

“筛选行”转换允许您根据条件和比较来筛选行。如果将”真”或”假”结果/分支连接到另一个转换，它将影响工作流。有3个路径可用作输出（真/假/主输出）。主输出仅遵循”真”路径。

用法

一旦此转换连接到上一个转换（一个或多个并接收输入），您可以点击”<字段>“、”=“和”<值>“区域来构建一个条件。下游转换可以连接到”真”或”假”分支。

右键单击一个条件以进行编辑、删除、移动或添加子条件。

您可以在”筛选行”转换中使用正则表达式。有关更多信息，请参阅”转换”部分下的”筛选行”。

要输入”IN LIST”运算符，请使用用分号分隔的字符串值。
列表也适用于数值，如整数。在这种情况下，值列表必须以字符串数据类型输入，例如：2;3;7;8。

请记住，所有转换都是并行执行的，因此在某些情况下，“真”和”假”路径都会运行。

“筛选行”转换仅检测输入流中的字段。如果您想根据变量值筛选行，可以修改上一个转换。例如，表输入转换可以在SQL中将变量作为另一个字段包含在内，例如”select field1, field2, ${myvar} as field3 from table1”，然后在筛选行条件中您可以说field1 = field3。或者，您可以使用”获取变量”转换在字段中设置参数。有各种SQL查询语句，例如，如果您始终需要返回字段和结果，可以使用”IF EXISTS”或”IS NULL”始终返回结果。

在名为”filter-rows-basic.hpl”的示例项目中可以找到一个示例。

如果由于元数据注入，您无法选择所需的字段，因为该字段尚不存在，请参阅此文档：https://hfxt.apache.org//manual/latest/pipeline/transforms/filterrows.html#_mdi_example 以及示例项目中的示例：metadata-injection/filter-rows-mdi-parent.hpl。

本质上，要使用尚不可选的MDI字段（例如在”筛选行”转换中），您可以设置一个具有相似字段和相似条件的转换。然后在文本编辑器中打开管道，并将字段名称更新为尚不存在的MDI字段名称。

筛选

基于变量值筛选行

“筛选行”转换仅检测输入流中的字段。如果您想根据变量值筛选行，可以像修改表输入转换那样修改上一个转换。例如，表输入转换可以在SQL中将变量作为另一个字段包含在内，例如

SELECT field1, field2, ${myvar} AS field3 FROM table1

，然后在筛选行条件中您可以说field1 = field3。或者，您可以使用”获取变量”转换在字段中设置参数。

您可以在”筛选行”转换中使用正则表达式。

一个查询：

SELECT field1,
field2,
${myvar} AS field3
FROM table
WHERE field1=xxxx

然后在筛选行条件中，您可以有：

field1 = field3

仅供参考 - 除了像上面所示的那样向表输入添加字段外，您还可以使用”获取变量”转换向流中添加字段。

您可以在”筛选行”转换中使用正则表达式。

请记住，所有转换都是并行执行的，因此在某些情况下，“真”和”假”路径都会运行。在某些情况下，在SQL查询中使用where筛选比使用”筛选行”转换更好。如果您需要返回任何一种情况（真/假）的输入行，您可以使用各种SQL查询方法，例如使用”IF EXISTS”或”IS NULL”始终返回结果。

筛选特殊字符

要筛选特殊字符，如显式EOF（例如来自旧的COBOL文件），请在”筛选行”转换中使用正则表达式，语法为：“\x${1A}”，其中\x表示十六进制表示，括号中的1A是要匹配的十六进制格式的EOF字符。

元数据注入支持

此转换的所有字段都支持元数据注入。您可以将此转换与ETL元数据注入一起使用，以便在运行时将元数据传递到您的管道中。

如果由于元数据注入，您无法选择所需的字段，因为该字段尚不存在，请参阅此文档：https://hfxt.apache.org//manual/latest/pipeline/transforms/filterrows.html#_mdi_example 以及示例项目中的此示例：metadata-injection/filter-rows-mdi-parent.hpl。

本质上，要使用尚不可选的MDI字段（例如在”筛选行”转换中），您可以设置一个具有相似字段和相似条件的转换。然后在文本编辑器中打开管道，并将字段名称更新为尚不存在的MDI字段名称。

条件字段的特殊注意事项

“筛选行”转换是一个特殊的MDI场景，因为它具有筛选条件的嵌套结构。条件以XML格式给出。条件XML的格式与我们在.HPL文件中以XML格式存储管道元数据的格式相同。我们没有.HPL XML格式的DTD（文档类型定义），也没有条件的DTD。

获取XML条件很容易：

  1. 使用您需要的不同条件创建一个示例筛选转换。这个示例转换为您提供所有信息，例如您使用的函数的值。

  2. 选择转换，将其复制到剪贴板，然后粘贴到文本编辑器中。或者，您可以存储.HPL文件，然后在文本编辑器中打开.HPL文件。

  3. 找到<condition>元素及其嵌套元素，并相应地进行修改，以便在您的MDI场景中使用。
