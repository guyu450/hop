表输出

描述

“表输出”转换将数据插入到关系数据库表中。

选项

选项 描述
转换名称 转换的名称，此名称在单个管道中必须唯一。
连接 写入数据的数据库连接
目标模式 要写入数据的表的模式名称 。这对于允许表名中包含句点的数据源很重要。
目标表 写入数据的表的名称。
提交大小 使用事务将行插入数据库表。如果N大于零 (0)，则每N行提 交一次连接；否则，不使用事务。（速度较慢）
截断表 如果希 望在将第一行插入表之前截断表，请选择此选项
在第一行时截断 如果希 望在转换接收到第一行时截断表，请选择此选项
忽略插入错误 使Hfxt忽略 所有插入错误，例如违反主键的错误。不过，最 多将记录20条警告。此选项不适用于批量插入。
指定数据库字段 启用此选项可在”数据库字段”选项卡中 指定字段。否则，默认情况下将考虑所有字段。
跨表分区数据

用于将数据拆分到多个表中。例如，不 是将所有数据插入到SALES表中，而是将数据放 入SALES_200510、SALES_200511、SALES_200512 等表中。在没有分区表且/或不允许插入到UNION ALL视图或继承表的主表的系统上使用此 选项。SALES视图可让您报告完整的销售情况：

CREATE OR REPLACE VIEW SALES AS
SELECT * FROM SALES_200501
UNION ALL
SELECT * FROM SALES_200502
UNION ALL
SELECT * FROM SALES_200503
UNION ALL
SELECT * FROM SALES_200504
...
使用批量更新进行插入 如果希望使用批量插入，请启用此选 项。此功能将插入语句分组，以减少与数据库的 往返次数。这是最快的选项，默认情况下启用。
表名是否在字段中定义？ 使用这些选项可将数据拆分到一个或 多个表中；目标表的名称在您指定的字段中定义 。例如，如果将客户数据存储在gender字段中， 数据可能最终存储在M和F表中（男性和女性）。 有一个选项可排除包含表名的字段插入到表中。
包含表名的字段 当启用”表名是否在字段中定 义？“选项时，在此处输入要使用的字段名称。
存储表名字段 当启用”表名是否在字段中定义？ “选项时，您可以选择是否将此字段写入表中。
返回自动生成的键 如果希望 获取通过将行插入表中生成的键，请启用此选项
自动生成键字段的名称 指定输出行中包含自动生成键的新字段的名称
SQL 自动生成用于创建输出表的SQL
