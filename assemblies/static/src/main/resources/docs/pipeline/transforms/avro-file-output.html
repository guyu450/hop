Avro文件输出

描述

Avro文件输出转换可以将 Avro消息写入文件或字段

选项

选项 描述
转换名称 转换的名称。注意：此名称在单个管道中必须唯一。
输出类型 所需的输出类型，可以是二进制文件、二进制消息或JSON消息。选择消息时，它将被发送到输出字段。
文件名 保存Avro数据文件的文件路径。
输出字段 不写入文件时，这是用于输出消息的字段名称。
自动创建模式 可以选择现有模式，也可以根据”字段”选项卡中的字段创建模式。
将模式写入文件 选择此选项可将模式写入单独的文件。
Avro命名空间 Avro文件中使用的命名空间。
Avro记录名称 用于Avro记录的名称。
Avro文档
模式文件名 写入或读取模式的文件路径。
创建父文件夹 创建文件时，如果要创建父文件夹，请选择此选项。
压缩编解码器 写入文件时用于Avro消息的压缩方式。
在文件名中包含转换编号 将转换实例编号添加到文件名中。
在文件名中包含分区编号 将分区编号添加到文件名中。
在文件名中包含日期 在文件名中包含文件创建日期
在文件名中包含时间 在文件名中包含文件创建时间
指定日期格式 指定要附加到文件名的自定义日期和格式
日期时间格式 用于格式化的日期时间规范
将文件名添加到结果中 将创建的结果文件名添加到文件名结果中

字段选项卡：

选项 描述
名称 流中的源字段。
Avro模式路径 目标字段，指定现有模式时，此字段将填充模式中的字段，以便将输入字段映射到这些字段。
Avro类型 Avro目标文件中字段的Avro类型。
可为空 此字段是否可为空？

元数据注入支持

要注入Avro字段类型，请使用以下代码

AVRO_TYPE_NONE = 0
AVRO_TYPE_BOOLEAN = 1
AVRO_TYPE_DOUBLE = 2
AVRO_TYPE_FLOAT = 3
AVRO_TYPE_INT = 4
AVRO_TYPE_LONG = 5
AVRO_TYPE_STRING = 6
AVRO_TYPE_ENUM = 7
