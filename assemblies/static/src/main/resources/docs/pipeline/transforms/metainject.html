元数据注入

描述

元数据注入使 Hfxt用户能够在运行时为管道提供所需的元数据。这可以显著减少为基本相同的管道开发略有不同版本的需求。

用法

元数据注入转换（MDI转换）将数据和转换属性插入到在运行时动态配置的管道中。这通常用于提高管道的可重用性。

例如用例：如果你有10种不同的CSV文件定义，并且不想为每个单独的文件创建10个管道，你可以使用ETL元数据注入。在配置好MDI转换（将数据和属性映射到模板/目标管道）后，在运行时它将动态填充目标管道中任何未配置的转换属性。例如，在模板文件中，如果你将”表输入数据库字段”留空，并且在MDI转换中进行了配置，它将动态填充”表字段”和”流字段”。

基本上，ETL元数据注入转换会覆盖命名管道的默认行为。并非所有传入流都需要具有相同的布局。从具有不同布局的不同流为元数据注入转换提供输入是完全可行的。

示例文件：

  • 配置MDI： read-and-inject-metadata.hpl

  • 读取并填充模板： read-file-template.hpl

通过输入模板管道的路径来指定它。点 击”浏览”，使用虚拟文件系统浏览器显示并输入路径详细信息。

如果你选择的管道 与当前管道具有相同的根路径，则变量${Internal.Transform. Current.Directory}将自动插入以代替公共根路径。例如，如果 当前管道的路径是/home/admin/pipeline.hpl，而你选择的管道 在/home/admin/path/sub.hpl文件夹中，那么路径将自动转换为 ${Internal.Transform.Current.Directory}/path/sub.hpl。

ETL元数据注入转换有两个带有字段的选项卡。下面分别描述每个选项卡。

注入元数据选项卡

此选项卡显示目标/模板文件上在运行时将被修改的转换和属性。将每个属性映射到你希望动态填充的源。

选项 描述
目标注入转换键 列出模板管道中每个转换中可注入元数据的可用字段。
目标描述 描述目标字段与目标转换的关系。
源转换 列出与作为元数据注入到目标字段的字段相关联的转换。
源字段 列出作为元数据注入到目标字段的字段。

要将源字段指定为要注入的元数据，请执行以下转换操作：

  1. 在”目标注入转换键”列中，双击要为其指定源字段的字段。将打开”源字段”对话框。

  2. 选择一个源字段，然后点击”确定”。

  3. 可选地，选择”使用常量值”，通过以下操作之一为注入的元数据指定常量值：

    • 手动输入一个值。

    • 使用内部变量设置值（例如${Internal.transform.Unique.Count}）。

    • 使用手动指定的值和参数值的组合（例如${FILE_PREFIX}_${FILE_DATE}.txt）。

当为字段或文件名等分组值列表指定常量值时，请注意目前没有很好的解决方案。最佳实践是使用 数据网格 转换来注入一整套常量值。你可以在此元数据注入转换中映射这些值。它将尽力满足你的需求，允许你使用指定的常量值注入组中的单行。

向ETL元数据注入转换中注入元数据

对于向ETL元数据注入转换本身注入元数据，适用以下例外情况：

  • 要注入一种指定字段的方法（例如通过文件名），请将PIPELINE_SPECIFICATION_METHOD常量设置到输入转换的字段。然后，你可以将该字段作为源映射到ETL元数据注入转换中的PIPELINE_SPECIFICATION_METHOD常量。

  • 将元数据插入原始注入的ETL元数据注入转换的目标字段由[组名称].[字段名称]定义。例如，如果组名称是”OUTPUT_FIELDS”，字段名称是”OUTPUT_FIELDNAME”，则应将目标字段设置为”OUTPUT_FIELDS.OUTPUT_FIELDNAME”。

故障排除

  • 在”可选目标文件（注入后的hpl）“中输入管道文件名，以便在注入后生成一个文件。此管道将包含注入后的所有属性，可用于查看和执行测试。
