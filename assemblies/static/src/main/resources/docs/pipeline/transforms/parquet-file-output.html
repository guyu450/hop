Parquet文件输出

描述

Parquet文件输出转换将数据写入 Parquet文件格式。有关此内容的更多信息，请参阅： Parquet。

选项

注意事项：

  • 输出文件名中可选引用的日期将是管道执行的开始时间。

  • 跳跃日期类型将序列化为EPOC：自 1970-01-01 00:00:00.000 以来的毫秒数

  • 字符串将以UTF-8二进制形式写入

  • 数据压缩为列格式是在内存中完成的。这在写入所有行时发生。为避免内存不足，请确保指定拆分大小。

选项 描述
转换名称 此转换的 名称，该名称在单个管道中必须唯一。
基本文件名

指定基本文 件名。这包括您要将Parquet文件写入 的位置以及文件名的开头部分。示例：

写入亚马逊AWS S3： s3://my-bucket-name/transactions

写入本地文件夹： /my/folder/customer-data
扩展名 这是文件的扩展名。通常这只是 snappy
是否包含日期？ 如果要在文件名中包含日期，掩码为 yyyMMdd，请选中此框。
是否包含时间？ 如果要在文件名中包含时间，掩码为 HHmmss，请选中此框。
是否包含日期时间格式？ 如果要在文件名中包含特定 的自定义日期时间格式，请选中此框。
是否包含转换副本编号？ 如果多次运行此 转换，为避免多个线程写入同一文件， 请启用此选项。副本编号的掩码格式为 00
是否拆分为多个部分并包含编号？ 如果要将输出拆分为多个部分，请启 用此选项。指定大于0的拆分大小，这 将是每个文件的行数。文件部分（拆分 ）编号将包含在文件名中，以确保不会 覆盖同一文件。拆分编号的掩码格式为 0000
压缩编解码器 在此处可以指 定要使用的压缩编解码器。默认是用于 Snappy压缩的SNAPPY。
版本 选择Parquet的协议版本（1.0或2.0）
行组大小 一个组中的行数
数据页大小 数据页 大小以1kB为边界（默认值为1048576）
字典页大小 数据字典页 大小以1kB为边界（默认值为1048576）
字段 您可以指定要写入的字段以及顺序。可 以使用”获取字段”按钮来填充对话框。
