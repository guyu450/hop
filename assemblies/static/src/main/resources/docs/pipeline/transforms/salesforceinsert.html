Salesforce插入

描述

Salesforce插入转换使用Salesforce Web服务将记录直接插入到您的Salesforce数据库中。您还可以使用以下其他转换来修改您的Salesforce数据库：

常规

在转换名称字段中输入以下信息：

  • 转换名称：指定画布上Salesforce插入转换的唯一名称。您可以自定义名称，也可以保留默认名称。

连接

在以下转换选项中输入连接信息：

选项

描述

Salesforce Web服务URL

指定Salesforce Web服务的URL。

默认值：https://login.salesforce.com/services/Soap/u/50.0

如果您的公司在Salesforce上使用”我的域名”，您可能需要更新此URL。如果是这样，请向您的Salesforce管理员询问URL。一般格式为 https://NAME.my.salesforce.com/services/Soap/u/50.0。您也可以在此处使用沙盒的URL来访问它。强烈建议使用 变量 来填充这些值。

用户名

指定用于向Salesforce进行身份验证的用户名

密码

指定用于向Salesforce进行身份验证的密码。输入您的密码，后跟您的安全令牌。例如，如果您的密码是PASSWORD，安全令牌是TOKEN，您应在此字段中输入PASSWORDTOKEN。

测试连接

点击以验证是否可以连接到您指定的Salesforce Web服务URL。

设置

在以下转换选项中输入插入过程设置：

选项

描述

超时

指定转换超时前的超时时间间隔（以毫秒为单位）。

使用压缩

选择在Hfxt和Salesforce之间连接时压缩（.gzip）数据。

回滚所有更改

除非所有记录都成功处理，否则恢复更改。当您选择此选项时，无错误的记录将被插入，而有错误的记录将在插入结果中标记为失败。默认行为是允许插入部分成功。

批大小

指示在提交插入之前收集的最大记录数。

模块

选择要在其中插入记录的模块（表）。

使用”测试连接”按钮成功向Salesforce进行身份验证后，此列表将被填充。

输出字段

在以下转换选项中输入输出信息：

  • Salesforce ID字段名称：指定用于包含您插入的一组记录（批）中第一条记录的Salesforce ID的字段。

字段

您可以通过”字段”表指定要插入到Salesforce数据库中的字段。点击”获取字段”，用Hfxt数据流中的输入填充该表。

该表包含以下列：

选项

描述

模块字段

模块内的字段名称

流字段

Hfxt数据流中的字段名称

使用外部ID？

指示该字段是否链接到外部ID的标志。为了解析ID，Salesforce需要对象类型、列名称和关系名称，语法如下：

对象名称:列名称/关系

可选地，点击”编辑映射”以指定自定义映射。例如，您可以将单个Hfxt字段映射到多个Salesforce字段。
