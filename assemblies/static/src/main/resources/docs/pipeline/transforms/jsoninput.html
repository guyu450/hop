JSON输入

描述

JSON输入转换通过JSONPath表达式从JSON结构、文件或传入字段中读取数据，以提取数据并输出行。

选项

文件标签

选项 描述
源来自上一个转换

选择从此前定义 的字段中检索源。选择此选项后，以下字段可用：

  • 选择字段

  • 将字段用作文件名

  • 将源读取为URL

  • 不将字段传递到下游

清除此选项后，以下字段可用：

  • 文件或目录

  • 正则表达式

  • 排除正则表达式

  • 选定文件
选择字段 指定要用作上一个转换源的字段名称。
将字段用作文件名 选择此选项以表明源是一个文件名。
将源读取为URL 选择此选项以表明源是否应作为URL访问。
不将字段传递到下游 选择此选项可从输出流中移除源字段。对于大 型JSON字段，此操作可提高性能并减少内存使用。
文件或目录

如果源未在字段中定义，请指定源位置。

  • 点击”浏览”以导航到源文件或目录。

  • 点击”添加”以将源包含在”选定文件”表中。
正则表达式 指定 一个正则表达式，用于匹配指定目录中的文件名。
排除正则表达式 指定 一个正则表达式，用于排除指定目录中的文件名。
文件/目录 在”文件或目录 “中指定源位置后，点击”添加”所指示的源位置。
通配符（正则表达式） 在”正则表达式”中指定的通配符。
排除通配符 在”排除正则表达式”中指定的排除通配符。
必需 输入所需的源位置。
包含子文件夹 源位置是否包含子文件夹。
删除 从表中移除一个源
编辑 从表 中移除一个源，并将其返回到”文件或目录”选项。
显示文件名 显示成功连接到JSON输入转换的源文件名。

内容标签

“内容”标签包含以下用于配置要检索的数据的选项：

选项 描述
忽略空文件 选择此选项可跳过空文件。清除此选项后，空文件将导致进程失败并停止。
无文件时不引发错误 选择此选项可在没有可用文件进行处理时继续执行。
忽略缺失路径 选择此选项可在出现以下错误时继续处理文件：（1）没有字段与JSON路径匹配；（2）所有值均为null。清除此选项后，出现错误时将不再处理更多行。
默认路径叶为空值 选择此选项可将缺失路径返回空值。
限制 指定从此转换生成的记录数限制。设置为零时，结果不受限制。
在输出中包含文件名 选择此选项可在结果中添加一个包含文件名的字符串字段。
在输出中包含行号 选择此选项可在结果中添加一个包含行号的整数字段。
将文件名添加到结果 选择此选项可将处理后的文件添加到结果文件列表中。

字段标签

“字段”标签显示从JSON结构中提取值的字段定义。此标签中的表包含以下列：

选项 描述
名称 映射到JSON输入流中相应字段的字段名称。
路径 JSON输入流中字段名称的完整路径。Hfxt使用JayWay库处理JSON路径表达式，文档位于 https://github.com/json-path/JsonPath。通过在路径中添加星号 * 可以检索所有记录。例如，$.mydata.*
类型 输入字段的数据类型。
格式 用于转换原始字段格式的可选掩码。有关此转换中可使用的常见有效日期和数字格式的信息，请参阅”通用格式”。
长度 字段的长度。
精度 数字类型字段的浮点数位数。
货币 货币符号（例如 $ 或 €）。
小数 小数点可以是 .（例如 5,000.00）或 ,（例如 5.000,00）。
分组 分组可以是 ,（例如 10,000.00）或 .（例如 5.000,00）。
修剪类型 应用于字符串的修剪方法。
重复 如果某行为空，则重复上一行的相应值。

选择字段

点击”字段”标签中的”选择字段”按钮，打开”选择字段”窗口。选中源文件中要包含在输出中的每个字段旁边的复选框。此转换中选择的所有字段都会添加到表中。您可以在”搜索”框中输入字段名称来搜索字段。

从代码片段选择字段

点击”从代码片段选择字段”按钮，粘贴整个JSON文本，它将填充”字段”标签中的”名称”、“路径”、“类型”列。例如：从以前的REST客户端输出结果复制JSON时，此功能很有用。

日期和时间戳

对于Hfxt类型的日期和时间戳，使用”格式”列指定传入格式。例如，对于日期：yyyy-MM-dd
