合并后同步

描述

“合并后同步”转换可与”合并行（差异）“管道转换结合使用，以便根据”合并行（差异）“的输出插入/更新/删除数据库字段。”合并行（差异）“管道转换会在每行添加一个”标志”列，其值为”相同”、“已更改”、“新增”或”已删除”。然后，“合并后同步”管道转换会使用此标志列对连接表执行更新/插入/删除操作。

选项

常规选项卡

选项 描述
转换名称 转换的名称。
连接 写入数据的数据库连接
目标架构 写入数据的表的架构名称。对于允许表名中包含句点的数据源，这一点很重要。
目标表 要执行插入/更新/删除操作的表的名称。
提交大小 运行提交操作前要更改的行数。
使用批量更新
表名在字段中定义
键查找表 允许您指定字段值和比较器列表。您可以使用以下比较器：=、<>、<、⇐、>、>=、LIKE、BETWEEN、IS NULL、IS NOT NULL
更新字段 允许您指定要插入/更新的表中的所有字段，包括键。通过在更新列中指定N，可以避免对某些字段（例如主键或非空约束字段）进行更新。
SQL按钮 点击”SQL”可生成用于创建表和索引以确保正确运行的SQL语句。
