语言模型聊天

描述

语言模型聊天转换（使用LangChain4j）能够与多种语言模型端点进行无缝交互，这些端点包括OpenAI、Anthropic、Hugging Face、Mistral和Ollama。此转换提供了一个统一的接口，允许在同一管道中轻松集成和配置不同的模型。此外，该转换支持应用一些提示工程技术，以优化模型交互并获得更符合上下文的相关响应。有关一些示例，请参阅下面的”基本提示工程技术”。

选项

通用参数

以下参数适用于所有语言模型选择。

选项 描述
转换名称 转换的名称。在单个管道中必须唯一。
输入JSON聊天 启用后，使用聊天完成JSON格式（系统、助手、用户消息）。禁用时，将输入视为纯文本。有关更多详细信息，请参阅”聊天完成”部分。
输出JSON聊天 启用后，以聊天完成JSON格式返回响应。禁用时，以纯文本形式返回响应。有关更多详细信息，请参阅”聊天完成”部分。
输入字段名称 保存输入文本/提示的字段名称
输出字段名称前缀 应用于所有输出字段名称的前缀。
标识符值（可选） 用于标记输出记录的可选标识符；如果留空，输出将默认为模型的名称。
并行度 用于API请求的并行线程数。警告：请注意端点容量和相关成本。 在测试和开发期间，建议启用 模拟 模式或将并行度设置为1。测试完成后，逐渐增加并行度，以评估消耗成本以及提供商管理多个线程的能力，包括速率限制和其他约束。
模拟（仿真） 启用一种测试模式，该模式可以模拟响应而无需执行实际的API调用。
模拟输出值 在模拟模式下返回的预定义响应，用于跳过实际API调用时。
模型API 定义用于与端点通信的API（例如，通过OpenAI、Anthropic、Ollama、Hugging Face、Mistral）。注意： Open AI API选项可与任何Open AI兼容的端点/服务器一起使用。例如，vLLM（Kwon等人，2023年）。
