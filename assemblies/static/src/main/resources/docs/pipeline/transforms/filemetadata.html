文件元数据

描述

文件元数据转换会扫描文件以确定其元数据结构或布局。当您需要读取结构化文本文件（例如CSV、TSV）但事先不知道确切布局时，请使用此转换。此文件中提供的信息可用于稍后实际读取文件，例如通过元数据注入。检测到的布局取决于扫描的行数。例如，如果扫描文件的前100行并且第一个字段被检测为整数，则该字段在后续行中有可能包含字母数字字符。将”限制扫描行数”设置为0行是确保扫描整个文件并正确检测布局的一种方法，尽管这对于大文件来说可能很耗时甚至无法实现。

选项

选项 描述
转换名称 此转换的名称
文件名 要扫描元数据的文件名
文件名在字段中？ 启用后可在输入流的字段中指定文件名
文件名字段 启用上一个选项后，您可以指定在运行时将包含文件名的字段。
限制扫描行数 限制扫描的行数（默认10,000）。使用0行扫描整个文件。
备用字符集 扫描文件时使用的字符集
分隔符候选列表 检测文件布局时尝试的分隔符列表。默认提供制表符、分号、逗号。
包围符候选列表 检测文件布局时尝试的分隔符列表。默认提供双引号和单引号。

输出字段

此转换返回的字段为

  • 字符集

  • 分隔符

  • 字段数量

  • 跳过标题行数

  • 跳过页脚行数

  • 是否存在标题行

  • 名称

  • 类型

  • 长度

  • 精度

  • 掩码

  • 小数点符号

  • 分组符号
