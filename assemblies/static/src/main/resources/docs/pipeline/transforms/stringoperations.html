字符串操作

描述

字符串操作转换可以对传入的跃点字段执行以下字符串操作：

选项

选项 描述
转换名称 转换的名称。
输入流字段 指定要转换的字段。
输出流字段 指定要创建的字段的名称。
修剪类型 指定修剪类型：无、左、右或两边。
小写/大写 指定大写或小写。
填充 指定左填充或右填充。
填充字符 指定填充字符。
填充长度 指定填充的长度。
首字母大写 转换为首字母大写。
转义 定义转义或取消转义XML、HTML，使用CDATA或转义SQL。
数字 指定是返回、移除数字还是对数字不做任何操作。
移除特殊字符 指定要移除的特殊字符。

元数据注入支持

此转换的所有字段都支持元数据注入。你可以将此转换与ETL元数据注入一起使用，以便在运行时将元数据传递到管道中。

元数据注入的值

字段 值
输入流字段 源字段列表
输出流字段 目标字段列表

1 = 左
2 = 右
3 = 两边
小写/大写 0 = 无
1 = 小写
2 = 大写
填充 0 = 无
1 = 左
2 = 右
填充字符 用于填充的字符
填充长度 填充的长度
首字母大写 0 = 否
1 = 是
转义 0 = 无
1 = 转义XML
2 = CDATA
3 = 取消转义XML
4 = 转义SQL

6 = 取消转义HTML
