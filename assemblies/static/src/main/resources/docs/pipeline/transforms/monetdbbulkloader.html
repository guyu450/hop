MonetDB批量加载器

描述

MonetDB批量加载器将数据批量加载到MonetDB中。这显著加快了向MonetDB加载数据的速度。

选项

常规

字段 描述
转换名称 指定管道中MongoDB输出转换的唯一名称。
连接 选择您的MonetDB数据库连接

常规设置选项卡

此选项卡包含目标设置、缓冲区大小和日志文件的位置。

字段 描述
目标模式 指定要使用的数据库模式。
目标表 指定数据库表，使用此字段旁边的”浏览”按钮通过菜单选择表和模式
缓冲区大小（行） 指定在传输到MonetDB之前将在内存中保留多少行。
日志文件 指定从MonetDB返回的批量命令日志的位置。
截断表 在加载数据之前从目标表中删除所有数据。
完全引用所有SQL语句 在执行时强制在所有对象周围加上引号。

MonetDB设置选项卡

此选项卡包含有关为加载数据而生成的临时文件的信息。

字段 描述
字段分隔符 这是在批量复制命令中使用的分隔符，输入数据中不允许有此字段。
字段包围符 用于包围值的字符。
空值表示形式 空值将转换为此字符串，这允许区分空字符串和空值。
编码 为复制语句生成文件时使用的文件编码。

输出字段选项卡

此选项卡包含源到目标的映射。

字段 描述
目标表字段 包含目标表中字段名称的字段
传入流字段 包含我们要插入到目标表中的值的字段
格式正确

如果传入流的字段根据目标数据类型格式正确，则设置为Y。

注意：

仅在应用延迟转换时才评估此设置。

例如：假设您从文本文件中获取值，传入数据包含数字或日 期，并且在输入转换中启用了延迟转换。在这种情况下，数据 不会在内部转换为目标数据类型，而是由Hfxt作为字符串处理 。通过将此标志设置为Y，我们是在告诉Hfxt，根据目标数据 类型，传入数据的值已经是目标数据库能够清楚理解的格式。
