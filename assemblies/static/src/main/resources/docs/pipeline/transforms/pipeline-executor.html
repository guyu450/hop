管道执行器

描述

管道执行器转换允许您在一个管道内执行另一个Hfxt管道。它与工作流执行器转换类似，但作用于管道。

用法

默认情况下，管道执行器转换会将行逐个发送到子管道。此默认行为可以在 “行分组” 选项卡中更改。

可选地，您可以在管道中使用 “从结果获取行” 转换，以从子管道获取先前的行。您无需在 “获取行” 转换中定义任何字段即可检索所有数据行字段。

您可以通过指定要执行的管道名称，为每一行运行相同的管道，也可以从传入字段（例如来自表的字段）接受管道名称。您可以启动多个此转换的副本以并行运行。

参数：可以将子管道参数映射到当前管道中的字段。如果启用 “从管道继承所有变量” 选项，则父管道中定义的所有参数/变量都会传递给该管道。但是，仅 “参数” 选项卡上定义的参数会根据输入到管道的数据行进行设置。

输出跳连接选项：如果为管道执行器选择了错误的输出选项，可能无法返回预期的数据。

  • 此输出将包含执行结果：返回执行统计信息，并且在输出中不限制字段、变量或参数。最好至少使用 “执行结果”（ExecutionResult）、“执行退出状态”（ExecutionExitStatus）或 “执行错误数”（ExecutionNrErrors）字段检查子管道中是否存在任何问题。

  • 此输出将包含执行后的结果行：输出由子管道复制到内存中的行集，例如使用 “将行复制到结果” 转换。使用管道执行器转换中的 “结果行” 选项卡，指定期望从子管道接收哪些字段。如果在您的作用域内有效，此选项对于在下游设置变量以及在上游使用变量也是必需的。

  • 输出将包含执行后的结果文件名：输出将包含复制到结果中的任何文件名的行集，例如使用 “文本文件输入” 转换的 “内容” 选项卡中的 “将文件名添加到结果”。

  • 输出将包含执行器转换的输入数据副本：输出管道执行器转换接收到的行集。

  • 转换的主输出：输出模拟管道执行器转换输入的行集。

根据您的需求，管道执行器转换可以配置为以下任何一种工作方式：

  • 默认情况下，为每个输入行执行一次指定的管道。您可以使用输入行设置参数和变量。然后，执行器转换将此行以结果行的形式传递给管道。

  • 您还可以根据字段中的值传递一组记录，以便当字段值动态变化时，执行指定的管道。在这些情况下，行组中的第一行用于设置管道中的参数或变量。

  • 您可以启动多个此转换的副本，以协助并行管道处理。

另请参阅：

  • 工作流操作，它从工作流中执行子工作流。

  • 管道操作，它从工作流中执行管道。

  • 工作流执行器转换，它从管道中执行工作流。

  • Hfxt中的循环 操作指南。

选项

常规

选项

描述

转换名称

转换的名称。

管道

使用此部分指定要执行的管道。您有以下选项来指定管道：

  • 使用文件作为管道：启用此选项后，您可以输入用作管道的.hpl文件。文件名可能包含变量（例如，您可以使用内置的Internal.Pipeline.Filename.Directory变量构造相对于当前管道的文件名），或者您可以使用 “浏览” 按钮通过文件浏览器选择文件。

管道来自字段？

启用后可在输入流的字段中指定管道文件名。

管道字段

启用上一个选项后，您可以指定在运行时将包含管道文件名的字段。文件名可能包含变量。

注意：必须考虑到，通过使用此选项指定管道文件名，我们可能会遇到一些性能损失，因为要执行的管道将在运行时初始化，而不是像往常一样在初始化阶段初始化。另一方面，此选项在动态指定管道文件名方面提供了更大的灵活性，这对于许多用例可能很有用。

运行配置

指定用于执行的管道运行配置。

参数选项卡

在此选项卡中，您可以指定使用哪个字段来设置某个参数或变量值。如果将多行传递给工作流，则取第一行来设置参数或变量。提示：如果您保持 “从管道继承所有变量” 选项选中（默认情况下是选中的），则当前管道中定义的所有变量都会传递给子管道。

您只能向下游传递 参数和变量。除非重新启动，否则不能在管道之间传递参数/变量。例如，当在管道执行器中每行启动一次每个命名管道时，您可以在管道之间传递参数/变量。

虽然您不能向上游（在嵌套或顺序管道中）传递参数和变量，但您可以通过以下模式将数据行传递回管道。请参阅项目：samples/loops/pipeline-executor.hpl

  • 父管道执行器 在 “结果行” 选项卡下指定子管道行中定义的行字段名称。父管道执行器的输出选项是 “执行后的结果行”。

  • 子管道：在子管道中生成一个数据行，其字段名称和类型与父管道执行器 “结果行” 选项卡中定义的相同。子管道的最后一个转换是 “将行复制到结果”。

请记住，所有参数必须在每个管道或工作流中（在编辑管道/工作流属性时）至少定义一次。

选项

描述

变量 / 参数名称

“参数” 选项卡允许您定义Hfxt变量或将其传递到管道中。

要使用的字段

指定使用哪个字段来设置某个参数或变量值。如果您指定使用输入字段，则不会使用静态输入值。

静态输入值

您可以在此处指定一个静态值，而不是使用字段。

选项卡右下角的 获取参数 按钮将插入指定管道的所有已定义参数及其描述。

选项卡右下角的 映射参数 按钮可让您将当前管道中的字段映射到子管道中的参数。

行分组选项卡

在此选项卡中，您可以指定以结果行的形式传递给管道的输入行数。您可以在管道中的 “从结果获取行” 转换中使用这些结果行。

选项

描述

发送到管道的行数

每X行后将执行管道，并将这X行传递给管道

用于分组行的字段

只要字段值保持不变，行就会累积在一个组中。如果值发生变化，将执行管道，并将累积的行传递给管道。

执行前等待收集行的时间

这是转换在执行管道之前累积行所花费的时间（以毫秒为单位）。

执行结果选项卡

您可以指定结果字段以及将它们发送到哪个转换。如果您不需要某个结果，只需留空输入字段。
