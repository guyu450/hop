Neo4j图输出

描述

图输出转换功能可让您将输入字段自动映射到图模型。用于更新图的算法会考虑映射到节点主属性的字段的空值。这些空值不会在这些节点上合并，也不会创建或更新与这些节点的关系。

限制

  • 不支持跨未知节点 ()--() 的更新

建模提示

  • 尝试使用像 Cypher Workbench 或 Arrows 这样的建模工具，并将结果导入到图模型中。

  • 尽量使您的模型保持简单。

  • 确保每个定义的节点都有一个主键字段

  • 每个节点限制使用一个主键字段

执行提示

  • 确保每个节点主键都有一个索引。使用图模型编辑器中提供的按钮来生成Neo4j索引和约束操作，它将为您处理此问题。

重要选项

选项 描述
转换名称 此转换在管道中的名称
Neo4j连接 用于写入图的Neo4j连接
图模型 要使用的 Neo4j图模型
批处理大小（行数） 用于向Neo4j写入数据的批处理大小
创建索引？ 在运行此转换之前创建Neo4j索引
返回图数据？ 返回Neo4j返回的图数据
图输出字段名称 将图数据写入的字段名称（如果启用了 返回图数据？）
根据模型验证？ 根据模型验证数据。这将检查是否为 标记为主键/索引的字段创建了索引，查看在更新 节点时标记为必需的属性是否可用等等。唯一性最 好通过对属性的约束来验证。使用提供的按钮生成 “Neo4j约束” 操作。
允许乱序更新？ 如果允许乱序更新，此转 换将生成展开语句。否则，将使用标准批处理更新 。更新将按每个不同的生成Cypher语句进行分组。
字段到属性映射标签页 在此标签页上，您可以指定希望输入字段在 图中的最终位置。根据您对此映射的选择，将执行 相应的Cypher合并语句。您可以将字段映射到节点 和关系属性。对于非常特殊的情况，即您希望在具 有相同标签的两个节点之间创建关系（自关系）， 您可以指定映射到哪个节点：源节点或目标节点。
字段到关系映射标签页

有时您希望根据 输入数据在图模型中选择一个关系。以下是您可以 应用的4种不同类型的关系映射，以引导此行为：

* 无映射：该行将被忽略

* 不更新指定节点之间的关系：您可 以指定不想更新任何关系的源节点和目标节点标签

* 使用字段值更新特定关系：您可以 指定要查看的字段以及要选择的关系要考虑的值。

* 更新指定节点之间的所有关系（ 默认）：图模型中定义的指定源节点和目标节点 之间的所有关系都将被更新（合并并更新属性）。
节点标签映射标签页

如果您 想从图模型中指定的标签中选择特定标签，可以在 此标签页中创建映射条目。以下是节点映射类型：

* 选择所有定义的标签（默认）： 匹配/合并节点时，将选择图模型中的所有标签。

* 使用字段值选择特定标签 ：对于指定的节点，我们查看您喜欢的输入字段， 如果它与值匹配，则选择该标签进行匹配/合并。

* 如果 字段包含特定值，则添加指定标签：对于选定的 节点，如果字段包含特定值，则设置选定的标签。

* 选择第一个标签：对于指定的节点，我 们仅使用图模型中的第一个标签进行匹配/合并。
