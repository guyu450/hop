拼接字段

描述

“拼接字段”转换操作可将多个字段拼接成一个目标字段。输入一个目标字段名称，这将始终创建一个新字段。您可以选择使用分隔符字段或字段间的包围符，并按顺序添加要拼接的字段或自由文本。

选项

常规

选项 描述
转换名称 转换的名称。
目标字段名称 目标字段的名称（字符串类型）
目标字段长度 字符串类型的长度（设置字符串类型的元数据，“快速数据转储”选项也会使用此设置以优化性能）
分隔符 指定在一行文本中分隔字段的字符。通常是”;“或制表符。
包围符 一对字符串可以包围某些字段。这允许字段中存在分隔符字符。包围符字符串是可选的。

字段标签页

这与”文本文件输出”转换的字段标签页选项相同，功能也一样。

选项 描述
名称 字段的名称。
类型 字段类型可以是字符串、日期或数字。
格式 用于转 换的格式掩码。有关格式符号的完整说明，请参阅”数字格式”。
长度

长度选项取决于字段类型，如下所示：

  • 数字 - 数字中的有效数字总数

  • 字符串 - 字符串的总长度

  • 日期 - 字符串打印输出的长度（例如，4 仅返回年份）
精度

精度选项取决于字段类型，如下所示：

  • 数字 - 浮点数的位数

  • 字符串 - 未使用

  • 日期 - 未使用
货币 用于表示货币的符号，如 $10,000.00 或 €5,000.00
小数点 小数点可以是”.”（10,000.00）或”,“（5,000.00）
分组符 分组符可以是”,“（10,000.00）或”.”（5,000.00）
修剪类型 应 用于字符串的修剪方法。仅在未指定字段长度时，修剪才有效。
空值 如果字段的值为空，则将此字符串插入到文本文件中
获取 点击以从输入字段流中检索字段列表
最小宽度 以某种方式更改字段标签页中的 选项，使文本文件中各行的最终宽度最小。因此，我们不再保存 0000001，而是写 1 等。字符串字段将不再填充到指定长度。
