管道数据探测器

描述

管道数据探测器转换接收由管道探测器元数据类型配置的数据探测器数据。有关更多信息，请查看管道探测器元数据类型。

选项

除转换名称外，管道数据探测器转换不需要任何配置。

此转换从 管道探测器 元数据类型接收数据，并生成以下输出：

sourcePipelineName 向此管道数据探测器转换传递数据的管道名称。
sourceTransformLogChannelId 向此管道数据探测器转换传递数据的日志通道的ID。
sourceTransformName 源管道中向此管道数据探测器转换传递数据的转换名称。
sourceTransformCopy 源管道中向此管道数据探测器转换传递数据的转换的副本编号。
rowNr 源管道中向此管道数据探测器转换传递数据的行号。
fieldName 源管道中向此管道数据探测器转换传递数据的字段的字段名称。
fieldType 源管道中向此管道数据探测器转换传递数据的字段的字段类型。
fieldFormat 源管道中向此管道数据探测器转换传递数据的字段的字段格式。
fieldLength 源管道中向此管道数据探测器转换传递数据的字段的字段长度。
fieldPrecision 源管道中向此管道数据探测器转换传递数据的字段的字段精度。
value 源管道中向此管道数据探测器转换传递数据的转换的值。
