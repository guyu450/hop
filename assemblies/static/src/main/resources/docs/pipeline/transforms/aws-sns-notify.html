AWS SNS通知

描述

AWS SNS通知转换功能使您能够通过亚马逊网络服务简单通知服务（Amazon Web Services Simple Notification Service），从 Hfxt管道向订阅用户发送通知。

前提条件

在首次执行之前，您需要创建一个IAM角色（例如，用于在EC2/ECS上使用）或一个带有AWS密钥和机密的IAM用户，并附加通过SNS推送通知所需的策略。

您还需要创建一个或多个要推送消息的订阅主题。

选项

AWS设置标签

选项 描述
使用AWS凭证链 Hfxt尝试从主机环境中获取AWS凭证。有关更多信息，请查看 凭证 文档。
AWS访问密钥 您的AWS访问密钥（AWS_ACCESS_KEY_ID）
AWS秘密访问密钥 您的AWS访问密钥的秘密（AWS_SECRET_ACCESS_KEY）
AWS区域 服务运行所在的AWS区域。

通知

在”通知”标签上，您可以定义发送通知时的行为、主题ARN、内容以及消息ID的字段。

选项 描述
事件类型

请选择是否应在以下情况下发送通知：

  • 第一行（推荐）

  • 或每行（注意不要向用户发送垃圾邮件！）。
消息ID 对于每个通知，都 会从SNS获取一个消息ID。可以将其写入此处定义的输出字段。
SNS字段表

在该表中只有三行 是有效的（保存/加载转换时，所有其他行将被忽略并拒绝）。

所有行都可以通过字段（字段 列）或静态值（静态值 列）指定。使用 值在字段中？ 选项在字段或静态值之间切换。

  • 主题ARN：您的SNS主题的ARN

  • 主题：您要发送的通知的主题

  • 消息：您要发送的消息
