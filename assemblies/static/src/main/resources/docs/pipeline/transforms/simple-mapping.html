简单映射

描述

简单映射转换允许您以”可重复使用的管道”（也称为”映射”）的形式重复使用一系列转换。

选项

这些选项相当直观易懂：

  • 转换名称：您的管道中一个唯一的名称

  • 管道：要嵌入的映射（子）管道的名称。此管道单独执行，被视为一个独立的实体。它始终使用标准的本地跃点管道运行配置执行，因为目前只有该配置能够将数据流入和流出转换。

  • 参数标签页：指定要传递给映射管道的参数

  • 输入标签页：指定要将哪些字段传递给映射中的 映射输入 转换。您可以映射（因此得名）字段名称。

  • 输出标签页：指定如何重命名从 映射输出 转换中获取的输出字段。

示例

在示例项目中，您可以找到两个简单映射转换的示例，即transforms/files/simple-mapping-child.hpl和simple-mapping-parent.hpl管道。

在上述示例文件中，父管道将名字和姓氏字段发送给子管道，执行一项计算，然后用计算结果填充一个字段并将其发送回。
