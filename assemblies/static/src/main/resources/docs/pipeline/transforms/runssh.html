运行SSH命令

描述

“运行SSH命令”转换允许你通过安全外壳（ssh）TCP/IP协议执行命令。你可以在命令中将文本输出到标准输出（stdout）或标准错误（stderr）。然后，此转换可以获取这些信息，并将其作为一个字段传递给后续的转换。

选项

常规选项卡

选项 描述
转换名称 转换的名称。
服务器名称/IP地址 你可以指定要在其上执行命令的计算机的服务器或IP地址。
服务器端口 服务器上ssh协议使用的TCP/IP端口。默认值为22。
超时时间 以秒为单位的超时时间。如果设置为大于零的数字，则可以指定非默认的连接超时时间。
用户名 用于登录的用户名。
密码 要使用的密码。
使用密钥 如果你想使用私钥登录，请启用此选项
私钥 私钥文件。私钥/公钥RSA密钥对的私钥部分（请参阅：ssh-keygen）
密码短语 生成密钥对时使用的可选密码短语。
代理主机 要使用的代理服务器主机（名称或IP地址）。
代理端口 要使用的代理服务器端口。
代理用户名 代理用户名。
代理密码 代理密码。
测试连接 使用此按钮查看提供的凭据是否足以登录到SSH服务器。

设置选项卡

输出

选项 描述
响应字段名称 将包含已执行命令输出的字符串输出字段的名称。这是标准输出和标准错误命令输出的串联。
错误响应字段名称 一个布尔输出字段的名称，如果发生错误，该字段将包含true，如果ssh命令成功执行，则包含false。

命令

选项 描述
从字段获取命令 如果你想执行在输入字段中指定的命令，请启用此选项
命令字段名称 选择将包含要执行命令的输入字段
命令 此字段允许你指定要执行的命令。
