获取文件行数

描述

“获取文件行数”转换操作可统计一个或一组文件中的行数。

选项

文件选项卡

选项 描述
转换名称 转换的名称。在管道中必须唯一。
从字段获取文件名 是否从指定字段获取文件名。
字段中的文件名 指定从中读取文件名的字段。
文件或目录 指定要统计行数的文件或文件路径。
添加 点击可将指定的文件、目录和正则表达式添加到”选定文件”列表中。
浏览 点击可选择一个文件或目录。
正则表达式 如果要加载多个文件，输入匹配所需文件的表达式。
!GetFilesRowsDialog.ExcludeFileMask.Label! 如果要排除目录中的文件，输入匹配要排除文件的表达式。
选定文件 列出为此转换选定使用的文件，包括每个文件的位置以及用于匹配或排除文件的正则表达式。
删除 点击可从列表中删除选定的文件。
编辑 点击可修改列表中选定的文件。
显示文件名 点击可查看将使用的所有文件。

内容选项卡

选项 描述
行数计数字段名 存储行数的字段名称。
行分隔符类型 选择定义行尾的字符类型，即回车符、换行符、制表符或自定义字符。
行分隔符 如果使用自定义字符，指定定义行尾的字符。
执行智能计数 如果未选中，计数返回文件中的分隔符数量。如果选中，将额外进行一次遍历以尝试返回实际行数。在行分隔符与列值分隔符相同或文件包含空行的情况下可使用此选项。
在输出中包含文件计数？ 是否在输出的字段中包含文件计数。
文件计数字段名 存储输出文件计数的字段名称。
将文件名添加到结果中 是否将文件名作为输出中的一个字段包含在内。
