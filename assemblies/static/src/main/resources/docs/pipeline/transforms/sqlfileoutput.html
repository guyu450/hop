SQL文件输出

描述

SQL文件输出转换将输入数据以一组SQL语句的形式写入文本文件。SQL语句是按照所选数据库的方言生成的。

选项

常规选项卡

选项 描述
转换名称 转换的名称。
连接

  • 连接：选择 要为其生成SQL的数据库。连接中的信息用于选择合适的方言。

  • 目标模式：要为其生成SQL的表的模式

  • 目标表：要为其生成SQL的表的名称
输出文件

  • 添加创建表语句：如果希望生成的SQL中包含”CREATE TABLE”语句，请选中此项

  • 添加截断表 语句：如果预期表已存在，并且希望生成的SQL中包含”TRUNCATE TABLE”语句，请选 中此项。请注意，根据数据库方言的不同，这也可能是”DELETE FROM”语句。

  • 每条语句另起一行：启用此选项可提高文件的可读性

  • 文件名：文件名（不含文件扩展名）

  • 创建父文件夹：如果指 定文件的父文件夹尚不存在，希望创建该文件夹，请选中此项。

  • 开始 时不创建空文件：如果在没有输入行的情况下不希望创建空文件

  • 扩展名：所需的文件扩展名（默认值为”sql”）

  • 在文件名中包含 转换编号：在输出文件名中包含转换编号（在运行多个副本时）

  • 在文件名中包含 日期：在输出文件名中包含格式为yyyyMMdd（20081231）的日期

  • 在文件名中 包含时间：在输出文件名中包含格式为HHmmss（235959）的时间

  • 追加：将生成的SQL追加到现有文件

  • 每……行 拆分：通过每……行开始一个新文件来限制单个文件的大小。

  • 显示文件名：点击此按钮可查看组装各个部 分（文件名、扩展名、转换编号、日期和时间）后的完整文件名

  • 将文件添加到结果：将写入 的文件名添加到此管道的结果中。内存中会保留一个唯一列表， 可在工作流的下一个工作流操作中使用，例如在另一个管道中。
