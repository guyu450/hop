令牌替换

描述

令牌替换转换会替换输入字符串或文件中的令牌。然后，该转换可以将此数据输出到文件或流中的字段。一个令牌包含起始字符串、名称和结束字符串。例如，${my_token} 可以是一个令牌。起始字符串和结束字符串是可配置的，可以是任何字符序列。在替换文件中的令牌时，此转换会读取整个文件。它不会一次处理一行。在替换文件中的令牌时，最佳做法也是将输出写入文件，以防止Hfxt将整个文件读入内存。

选项

输入选项卡

  • 输入类型 - 从何处读取要进行令牌替换的字段。可以是文本、字段或文件。

  • 输入类型为文本

    • 输入文本 - 要进行令牌替换的文本

  • 输入类型为字段

    • 输入字段 - 要进行令牌替换的输入字段

  • 输入类型为文件

    • 输入文件名 - 要进行令牌替换的文件名

    • 文件名在字段中？

      • 要进行令牌替换的文件名是否在字段中？

    • 输入文件名所在字段 - 文件名所在的字段。

    • 将输入文件名添加到结果中？

      • 将输入文件名添加到结果文件列表中。

输出选项卡

  • 输出类型 - 将令牌替换后的字符串输出到何处。可以是字段或文件。

  • 输出类型为字段

    • 输出字段名称 - 要将令牌替换后的字符串放入的字段名称。

  • 输出类型为文件

    • 输出文件名 - 要写入的文件名。

    • 文件名在字段中？

      • 输出文件名是否在字段中？

    • 输出文件名所在字段 - 输出文件名所在的字段名称。

    • 追加输出文件？

      • 如果输出文件已存在，是否应追加到该文件。如果未选中，若文件存在， Hfxt将覆盖该文件。

    • 创建父文件夹？

      • Hfxt是否应创建父文件夹？

    • 输出格式 - 输出文件的换行符格式。

    • 输出编码 - 写入文件时使用的字符编码。

    • 每 - 行拆分 - 每n行将输出文件拆分为一个新文件。

    • 在文件名中包含副本编号？

      • 是否应在输出文件名中包含转换的副本编号？

    • 在文件名中包含分区编号？

      • 是否应在输出文件名中包含分区编号？

    • 在文件名中包含日期？

      • 是否应在输出文件名中包含当前日期？

    • 在文件名中包含时间？

      • 是否应在输出文件名中包含当前时间？

    • 指定日期格式？

      • 是否要指定要包含在输出文件名中的日期格式？

    • 日期时间格式 - 要包含在输出文件名中的日期/时间格式。

    • 将输出文件名添加到结果中？

      • 将输出文件名添加到结果文件列表中。

令牌选项卡

  • 令牌起始字符串 - 表示令牌开始的字符串。

  • 令牌结束字符串 - 表示令牌结束的字符串。令牌起始字符串和令牌结束字符串之间的所有内容就是令牌名称。

  • 流名称 - 流中包含用于替换令牌的值的字段名称。

  • 令牌名称 - 要替换的令牌名称。

  • 获取字段按钮 - 获取输入字段列表，并尝试通过精确名称匹配将它们映射到Avro字段。
