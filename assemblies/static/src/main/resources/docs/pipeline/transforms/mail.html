邮件

描述

邮件转换使用SMTP服务器，利用管道字段中的数据发送电子邮件。

选项

地址

此选项卡定义由Hfxt生成的电子邮件的发件人、联系人以及收件人。

选项 描述
转换名称 转换的名称。
目标
目标地址 电子邮件的目标地址。可以是单个地址、用空格分隔的地址列表，或者是分发列表的电子邮件别名。
抄送 一个电子邮件地址、用空格分隔的电子邮件地址列表，或者是一个分发列表，用于接收电子邮件的抄送副本。
密送 一个电子邮件地址、用空格分隔的电子邮件地址列表，或者是一个分发列表，用于接收电子邮件的密送副本。
电子邮件发件人
发件人姓名 希望显示的电子邮件发件人姓名。
发件人地址 希望显示的电子邮件发件人的电子邮件地址或账户地址。
回复至 收件人回复电子邮件时将使用的电子邮件地址。
联系人 就电子邮件内容进行联系的人员姓名。
联系人电话 上一个字段中定义的联系人的电话号码。

服务器

此选项卡包含SMTP服务器的详细信息，包括身份验证和加密。

选项 描述
邮件服务器连接
邮件连接 如果在此处选择了邮件服务器连接，则将忽略此选项卡的其余部分。服务器配置将从 邮件服务器连接 元数据项中获取。
SMTP服务器
SMTP服务器 SMTP服务器的URL、主机名或IP地址。
端口 SMTP服务的端口号。
身份验证
使用身份验证 如果选中，您将能够在接下来的几个字段中输入SMTP用户名和密码。
使用XOAUTH2 如果选中，将使用XOAuth2对服务器进行身份验证。
身份验证用户 用于服务器身份验证的SMTP用户名。
身份验证密码 前面定义的SMTP用户名的密码。
使用安全身份验证 如果选中，您将能够在接下来的字段中指定SSL或TLS加密。
安全连接类型 确定服务器将使用SSL还是TLS加密协议。
检查服务器身份？ 检查服务器身份？
受信任主机 用空格分隔的受信任主机列表，例如：“host1 host2 host3”

电子邮件消息

此选项卡确定电子邮件的文本内容。

选项 描述
消息设置
在消息中包含日期？ 如果选中，日期将打印在电子邮件正文中。
仅在邮件正文中发送注释 如果选中，将不包含有关管道的信息。
在邮件正文中使用HTML格式？ 如果选中，此电子邮件将采用HTML格式而非纯文本格式。
编码 HTML电子邮件文本的字符编码。
管理优先级 如果选中，将启用以下两个字段以设置电子邮件的优先级和重要性级别。
优先级 要在电子邮件元数据中分配的优先级级别。
重要性 要在电子邮件元数据中分配的重要性级别。
敏感度 这允许将”敏感度”标头信息设置为”普通”、“个人”、“私人”、“机密”。
消息
主题 电子邮件主题行。
注释 电子邮件正文。另请参阅”附加内容文件”选项。

附件

此选项卡包含文件附件的选项。

选项

描述

附加内容文件

附加内容文件？

如果选中，您将使用接下来的两个字段来定义要用于创建邮件消息动态内容的流字段。

内容字段名

给定字段包含指向为内容加载的文件的字段。在内部，此文件内容将放入MimeBodyPart（使用application/x-any）中。

文件名字段名

此字段设置MimeBodyPart中的文件名。

附加文件名

动态文件名？

如果选中，您将使用接下来的两个字段来定义要用于为附件创建动态文件名的流字段。

文件名字段

要用于附件动态文件名的流字段。这也可以是文件夹名称，在这种情况下，您将使用通配符字段来确定文件名。

通配符字段

用于为附件创建动态文件名的正则表达式。

文件名/文件夹名

要附加的文件的静态名称和位置。

包含子文件夹

如果选中，将附加指定文件夹子文件夹中的文件。

通配符

用于标识要附加文件的正则表达式。

压缩文件

压缩文件

如果选中，多个文件附件将在附加到电子邮件之前压缩到一个存档中。

压缩文件名是否动态？

如果选中，压缩存档的名称将由数据流确定。

压缩文件名字段

用于压缩存档名称的数据字段。

压缩文件名

压缩存档的静态名称。
