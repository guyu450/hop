MongoDB删除操作

描述

MongoDB删除转换功能使您能够从MongoDB的集合中删除文档或记录。有关MongoDB的更多信息，请参阅MongoDB文档。

选项

常规

转换名称：在管道中指定MongoDB输入转换的唯一名称。

删除选项标签

字段 描述
MongoDB连接 用于MongoDB删除转换的 MongoDB连接。
集合 要从中删除数据的集合名称。点击”获取集合”，用数据库中的集合列表填充下拉菜单。
写操作的重试次数 写操作的重试次数
重试尝试之间的延迟（秒） 重试尝试之间的延迟（秒）

删除查询

  • 使用JSON查询：

    • 禁用时（默认），转换根据键/值对比较删除文档。该表需要以下字段：

      • Mongo文档路径：要删除的文档路径

      • 比较器：=、<>、,、<、⇐、>、>=、BETWEEN、IS NULL、IS NOT NULL

      • 传入字段1：第一个比较流字段

      • 传入字段2：第二个比较流字段（与 BETWEEN 一起使用）

    • 启用时：

      • 将删除查询传递给MongoDB进行删除。

      • 每行执行：将删除查询传递给数据库，针对每个传入行

删除查询示例：

基于文档路径和流字段删除（使用JSON查询 禁用）：

Mongo文档路径 比较器 传入字段1 传入字段2
name = lastname
firstname = firstname

基于JSON查询删除（使用JSON查询 启用）：

`{$or: [{"name": "${NAME1}"},{"name": "${NAME2}"}, {"name": "${NAME3}"} ]}`
