MongoDB输出

描述

MongoDB输出转换可以将数据输出到MongoDB数据库集合中。有关MongoDB的更多信息，请参阅MongoDB文档。

选项

常规

转换名称：在管道中指定MongoDB输出转换的唯一名称。

输出选项标签

“输出选项”标签提供了将数据插入MongoDB集合的控件。如果指定的集合不存在，将在插入文档之前创建该集合。

在此标签的字段中输入以下信息：

选项

描述

MongoDB连接

此MongoDB输出转换要使用的 MongoDB连接。

集合

指定输出的目标集合。设置有效的主机名和端口后，您可以单击”获取集合”以检索所选数据库中现有集合的名称。如果指定的集合不存在，将在插入数据之前创建该集合。

批量插入大小

指定批量插入操作的批量大小。默认值为100行。

截断集合

选择在插入新数据之前删除目标集合中的现有数据。

更新

设置指定数据库和集合的更新写入方法。

除非选择了”更新”字段，否则”插入或更新”和”修饰符更新”选项不可用。

插入或更新

选择将写入方法从插入更改为插入或更新。插入或更新方法会根据Mongo文档字段标签中指定的所有传入字段，用全新记录替换匹配的记录。如果更新的匹配条件不成立，则会创建一条新记录。

多次更新

选择对每次更新或插入或更新操作更新所有匹配的文档。

修饰符更新

选择启用修饰符（$运算符）来修改匹配文档中的各个字段。选择”多次更新”选项后，将更新所有匹配的文档。

要更新多个匹配文档，请选择”修饰符更新”和”插入或更新”。选择”修饰符更新”、“插入或更新”和”多次更新”将更新应用于所有匹配文档，而不仅仅是第一个。

写入操作的重试次数

指定写入操作尝试的次数。

重试尝试之间的延迟（以秒为单位）

指定下次重试前等待的秒数。

Mongo文档字段标签

使用”Mongo文档字段”标签定义进入转换的字段值如何写入Mongo文档。“修饰符策略”列控制修饰符操作的执行何时影响特定字段。当一个Mongo文档的数据分散在多个传入的Hfxt行中，或者无法同时执行影响同一字段的不同修饰符操作时，可以使用修饰符策略。

有2个辅助按钮可供使用： * 获取字段：用传入字段的名称填充表的”名称”列。 * 预览文档结构：打开一个对话框，以JSON格式显示将写入MongoDB的结构。

在此标签的字段中输入以下信息：

列

字段描述

名称

传入字段的名称。

Mongo文档路径

以点号表示法格式表示的文档中字段的分层路径。

使用字段名称

是否使用传入字段名称作为路径中的最后一项。值为Y（使用传入字段名称）和N（不使用传入字段名称）。设置为Y时，假定前面有一个句点（.）。

NULL值

指定是否在数据库中插入空值。值为：

- 插入NULL

- 忽略

JSON

表示传入值是一个JSON文档。

更新匹配字段

表示在执行插入或更新操作时是否匹配字段。集合中与该列中标记为Y的所有字段匹配的第一个文档将被使用所有定义字段路径的传入值构造的新文档替换。如果不存在匹配文档，则会在集合中插入一个新文档。

修饰符操作

指定对现有文档字段的就地修改。

修饰符有：

- 不适用

- $set：设置字段的值。

- $inc：如果字段不存在，则设置字段的值。如果字段存在，则增加（或使用负值减少）字段的值。

- $push：如果字段不存在，则设置字段的值。如果字段存在，则追加字段的值。

- $：（数组内匹配的位置运算符）。

修饰符策略

控制修饰符操作的执行何时影响字段。值为：

- 插入并更新：无论集合中是否存在匹配项，都会执行操作（默认）。“插入并更新”修饰符策略（插入或更新）允许您在执行插入或更新操作时指定要匹配的字段。插入或更新仅替换第一个匹配文档。修饰符插入或更新可用于替换多个文档中的某些字段值。

- 插入：仅在插入时执行操作（当匹配条件不成立时）

- 更新：当匹配条件成立时执行操作。
