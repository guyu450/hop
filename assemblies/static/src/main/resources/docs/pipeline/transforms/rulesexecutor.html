规则执行器

描述

规则执行器允许根据规则集对传入行的字段进行执行操作。这对于确定附加信息或将行路由到另一个转换可能很有用。目前Drools是规则引擎的实现方式，此转换可以参考其规则语言以供使用。Drools文档

详细信息

对于规则执行器转换处理的每一行，每一列都会转换为一个Rules.Column，然后注入到规则引擎中，并根据规则集执行。Rules.Column包含四个属性：

externalSource：布尔属性，指示此Rules.Column是否从外部源注入（来自已处理行的字段）

name：此字段的名称

type：有效负载中存储的数据类型（ValueMetaInterface.typeCodes之一 - 数字、字符串、整数、日期、布尔值等）

payload：此字段的值

结果通过创建Rules.Column对象生成。转换被配置为按名称获取这些生成的对象。

规则标签页

规则标签页是您输入规则定义或规则文件引用的地方。

选项 描述
规则文件名
要执行的规则脚本

规则结果标签页

规则结果标签页定义了规则输出字段的布局。

选项 描述
结果列名称
结果列类型

示例

所有规则定义都应包含”import org.apache.hfxt.pipeline.transforms.drools.Rules.Column;“，以便访问Rules.Column类。

对于输入行：fica_seed（整数）、hi（字符串）、fica（整数）；规则引擎中将创建三个Rules.Column对象：

Rules.Row→row（映射） 类型 有效负载
fica_seed 整数 -3561151667
hi 字符串 test
fica 整数 bad

可以定义并应用规则：

rule "Decline"
    dialect "mvel"
    when
        $fica : Column(name == "fica", payload < 550)

    then
        Column approvalStatus = new Column();
        approvalStatus.name = "approvalStatus"
        approvalStatus.type = String.class
        approvalStatus.payload = "declined"

        Column approvalClassification = new Column();
        approvalClassification.name = "approvalClass"
        approvalClassification.type = String.class
        approvalClassification.payload = "Declined: fica too low"

        insert(approvalStatus);
        insert(approvalClassification);

        System.out.println("Declined");
end
