更新

描述

“更新”转换使用一个或多个查找键在表中查找一行，并在需要时对其进行更新。如果找不到该行，则不执行任何操作。如果找到该行，则更新表中的该行。

选项

选项 描述
提交大小 运行提交操作前要更新的行数。
使用批量更新？ 允许使用批量更新。
跳过查找 跳过行查找。
忽略查找失败？ 允许转换跳过查找失败的情况。
标志字段（键已找到） 包含键是否找到的字段。
连接 写入数据的数据库连接。
键查找表 允许您指定字段值和比较器列表。您可以使用以下比较器：=、= ~NULL、<>、<、⇐、>、>=、LIKE、BETWEEN、IS NULL、IS NOT NULL
SQL按钮 点击”SQL”生成用于创建表和索引以确保正确运行的SQL语句。
转换名称 转换的名称；此名称在单个管道中必须唯一。
目标模式 写入数据的表的模式名称。这对于允许表名中包含句点的数据源很重要。
目标表 要进行更新操作的表的名称。
更新字段 允许您指定要更新的表中的所有字段。
