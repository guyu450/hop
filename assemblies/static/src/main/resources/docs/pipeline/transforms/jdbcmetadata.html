JDBC元数据

描述

JDBC元数据转换允许您从数据库连接中获取元数据，这包括模式、表和其他对象。

方法和参数标签页

在这个标签页中，您可以指定要调用的DatabaseMetaData对象的Java方法以获取元数据。它还控制该步骤行为的其他一些方面。

始终传递输入行： 控制在没有元数据的情况下此步骤的行为。如果未选中此选项，该步骤将不会生成任何输出行。如果选中此选项，传入的行仍将被传递。在这种情况下，任何源自元数据结果集的输出字段都将为NULL。

元数据方法： 此下拉列表可用于指定要在DatabaseMetaData对象上调用哪个元数据方法以获取元数据：

  • 目录：请参阅DatabaseMetaData.getCatalogs()

  • 最佳行标识符：请参阅 DatabaseMetaData.getBestRowIdentifier()

  • 列权限：请参阅 DatabaseMetaData.getColumnPrivileges()

  • 列：请参阅 DatabaseMetaData.getColumns()

  • 交叉引用：请参阅 DatabaseMetaData.getCrossReferences()

  • 导出键列：请参阅 DatabaseMetaData.getExportedKeys()

  • 外键列：请参阅 DatabaseMetaData.getImportedKeys()

  • 主键列：请参阅 DatabaseMetaData.getPrimaryKeys()

  • 模式：请参阅DatabaseMetaData.getSchemas()

  • 表权限：请参阅 DatabaseMetaData.getTablePrivileges()

  • 表类型：请参阅DatabaseMetaData.getTableTypes()

  • 表：请参阅 DatabaseMetaData.getTables()

  • 数据类型：请参阅DatabaseMetaData.getTypeInfo()

  • 版本列：请参阅 DatabaseMetaData.getVersionColumns()

  • 选择一个方法后，字段将添加到该标签页，以便您可以指定该方法所需的任何参数。有关特定方法的参数及其含义的描述，请参阅每个方法的Java文档（上面有链接）。

从字段获取参数： 如果选中此选项，可以通过从传入流中选择一个字段来指定方法的参数，并且该字段的值将用作实际参数值。如果未选中此选项，可以将参数值直接作为文本输入到参数字段中。

移除参数字段： 当选中”从字段获取参数”时，此选项适用。选中此选项后，被选作参数字段的字段将从输出流中移除。当您按顺序链接多个JdbcMetaData步骤，使用上游步骤输出的字段作为下游步骤的参数字段时，此选项通常很方便。在这种情况下，使用此选项将移除许多重复字段。

输出字段标签页

此标签页允许您控制如何将输出元数据添加到输出流中。

输出字段： 当您在”方法和参数”标签页中选择特定的元数据方法时，此网格将自动填充适当的字段。使用此网格视图可以移除或重命名输出字段。

获取字段： 使用此按钮重新填充网格。这将重新添加任何移除的字段，但保留任何重命名的字段。
