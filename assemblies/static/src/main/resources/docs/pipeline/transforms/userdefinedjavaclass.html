用户自定义Java类

描述

用户自定义Java类转换允许您输入用户自定义Java类，以驱动完整转换的功能。本质上，此转换允许您在转换中编写自己的插件。此转换的目标不是让用户在转换中进行全面的Java开发。显然，我们有一整套插件系统来协助完成这部分工作。目标是让用户用尽可能少的代码定义方法和逻辑，并尽可能快速地执行。为此，我们使用Janino项目库，它能在运行时以类的形式编译Java代码。

用法

处理行

处理器代码定义了processRow()方法，它是转换的核心。管道会在一个紧密的循环中调用此方法，并且会一直持续，直到返回false。

String firstnameField;
String lastnameField;
String nameField;

public boolean processRow() throws HfxtException
{
    // 出于性能考虑，我们只查找一次参数。
    //
    if (first) {
      firstnameField = getParameter("FIRSTNAME_FIELD");
      lastnameField = getParameter("LASTNAME_FIELD");
      nameField = getParameter("NAME_FIELD");
      first=false;
    }

    // 首先，从默认输入分支获取一行数据
    //
    Object[] r = getRow();

    // 如果行对象为null，我们就完成了处理。
    //
    if (r == null) {
      setOutputDone();
      return false;
    }

    // 调用createOutputRow()始终是最安全的，以确保输出行的Object[]足够大
    // 能够处理您在这个转换中创建的任何新字段。
    //
    Object[] outputRow = createOutputRow(r, data.outputRowMeta.size());

    String firstname = get(Fields.In, firstnameField).getString(r);
    String lastname = get(Fields.In, lastnameField).getString(r);

    // 在输出字段中设置值
    //
    String name = firstname+" "+lastname;
    get(Fields.Out, nameField).setValue(outputRow, name);

    // putRow会将该行数据发送到默认输出分支。
    //
    putRow(data.outputRowMeta, outputRow);

    return true;

错误处理

如果您希望Hfxt处理在管道中运行您的类时可能发生的错误，您必须实现自己的错误处理代码。在添加任何错误处理代码之前，在Hfxt客户端画布上右键单击”用户自定义Java类”转换，然后在出现的菜单中选择”错误处理”。生成的转换错误处理设置对话框包含用于指定错误目标转换以及相关字段名称的选项，您将在定义的代码中使用这些选项来实现错误处理。

try {

Object     numList = strsList.stream()
                        .map( new ToInteger() )
                     .sorted( new ReverseCase() )
                     .collect( Collectors.toList() );

    get( Fields.Out, "reverseOrder" ).setValue( row, numList.toString() );

} catch (NumberFormatException ex) {
    // 数字列表包含一个无法转换为整数的值。
    rowInError = true;
    errMsg = ex.getMessage();
    errCnt = errCnt + 1;
}

if ( !rowInError ) {
    putRow( data.outputRowMeta, row );
} else {
    // 将错误输出到错误分支。右键单击转换并选择“错误处理...”
    putError(data.outputRowMeta, row, errCnt, errMsg, "Not allowed", "DEC_0");
}

上面代码示例中的try语句用于测试numList是否包含有效的数字。如果列表中包含无效数字，则使用putError来处理错误，并将其定向到示例管道中的wlog: ErrorPath转换。ErrorPath转换也在”用户自定义Java类”转换的”目标转换”选项卡中指定。

日志记录

如果您希望Hfxt记录您的类中的数据操作（如读取、写入、输出或更新数据），则需要在定义的转换中实现日志记录。以下代码是如何实现日志记录的示例：

putRow( data.outputMeta, r );

if ( checkFeedback( getLinesOutput() ) ) {
  if ( log.isBasic() ) {
    logBasic( "Have I got rows for you! " + getLinesOutput() );
  }
}

类和代码片段

您可以通过”类和代码片段”面板浏览定义的类以及相关代码片段和字段。您可以右键单击此树中的任何项目，以进行删除、重命名或显示示例操作。

类

“类”文件夹指示哪些类在”类代码”面板中有对应的代码块标签。

代码片段

“代码片段”文件夹显示与”用户自定义Java类”转换相关的内部Hfxt代码。这些片段作为您的类代码的参考显示。

输入字段

“输入字段”文件夹包含您在代码中定义的任何输入字段。在处理定义的代码时，您将处理输入和输出字段。处理输入字段有很多方法。例如，首先，请查看以下关于输入行的描述。

IRowMeta inputRowMeta = getInputRowMeta();

inputRowMeta对象包含输入行的元数据。它包括所有字段、它们的数据类型、长度、名称、格式掩码等等。您可以使用此对象查找输入字段。例如，如果您要查找名为”customer”的字段，您可以使用以下代码。

IValueMeta customer = inputRowMeta.searchValueMeta("year");

如果您需要为通过管道的每一行查找字段名，这可能会很慢，因此您可以在第一段代码中提前查找字段名，如下例所示：

if (first) {
 yearIndex = getInputRowMeta().indexOfValue(getParameter("YEAR"));
 if (yearIndex<0) {
   throw new HfxtException("Year field not found in the input row, check parameter 'YEAR'\!");
 }
}

要获取”year”字段中包含的整数值，您可以使用以下结构。

Object[] r = getRow();
...
Long year = inputRowMeta().getInteger(r, yearIndex);

为了使这个过程更简单，您可以使用以下形式的快捷方式。

Long year = get(Fields.In, "year").getInteger(r);

此方法也考虑了上面提到的基于索引的优化。

阻止特定代码

作为一项简单的安全措施，您可以阻止包含特定字符串的代码执行。这可以通过在位于<Hfxt安装目录>/plugins/transforms/janino的codeExclusions.xml文件中添加排除项来实现。

示例：

    <exclusions>
        <exclusion>System.</exclusion>
        <exclusion>HfxtVfs.</exclusion>
    </exclusions>
