Beam Kinesis 消费

描述

Beam Kinesis 消费转换使用Beam管道执行引擎从Amazon Kinesis流中消费（读取）消息。

限制

Kinesis 消费者的主要限制是，它目前仅支持读取字符串消息。如果你希望看到对Avro消息和其他格式的支持，请在GitHub上创建一个请求。

选项

选项 描述
转换名称 转换的名称，此名称在单个管道中必须是唯一的。
AWS访问密钥 用于进行身份验证的亚马逊网络服务访问密钥。
AWS秘密密钥 用于进行身份验证的亚马逊网络服务秘密密钥。
流名称 要从中消费的Kinesis流的名称。
唯一ID输出字段的名称 这是转换输出中字段的名称，该字段将包含接收到的数据（消息）的唯一ID。
数据输出字段的名称 这是将包含实际数据（消息）的字段的名称
检索到的数据类型 目前仅支持字符串数据（消息）。
分区键字段名称 可选：输出中包含分区键的字段的名称
序列号字段名称 可选：输出中包含消息序列号的字段的名称
子序列号字段名称 可选：输出中包含消息子序列号的字段的名称
分片ID字段名称 可选：输出中包含消息分片ID的字段的名称
流名称字段名称 可选：输出中包含正在读取的流名称的字段的名称
最大记录数 可选：此转换在停止前将读取的最大记录数
最大读取时间（毫秒） 可选：此转换在停止前将读取的最长时间（以毫秒为单位）
请求记录限制 可选：每次请求（微批次）中一次读取的记录数
到达时间水印策略？ 在Beam管道中消息到达时设置水印。
到达水印空闲时间（毫秒） 表示水印可以空闲的持续时间
处理时间水印？ 在Beam管道中消息处理时设置水印。
固定延迟速率限制策略？ 指定固定延迟速率限制策略，默认延迟为1秒
固定延迟速率限制策略延迟（毫秒） 指定具有给定延迟的固定延迟速率限制策略。
每个分片的最大容量 指定每个分片的最大消息数。
