Azure事件中心监听器

描述

Azure事件中心监听器转换会无限期地监听Microsoft Azure云平台上的事件中心。

连接选项

  • 事件中心命名空间：你的事件中心命名空间名称

  • 事件中心实例名称：事件中心的名称，即实例本身

  • 事件中心连接字符串：通常与共享访问签名（SAS）密钥连接字符串相同

  • SAS策略密钥名称：Azure仪表板中事件中心命名空间的”共享访问策略”部分中的策略名称。此策略需要启用”发送”声明

  • SAS密钥连接字符串：你可以使用标记为”连接字符串 - 主密钥”的策略中的值

  • 批处理大小：每次调用Azure时在一批中发送的消息（事件）数量

  • 消息字段：包含用作事件的消息的字段。请注意，你可以使用诸如JSON输出或”JavaScript”之类的转换来组装消息

  • 使用者组名称：如果你没有创建特定的组，只需使用$Default

  • 存储容器名称：你的存储容器名称

  • 存储连接字符串：你的存储帐户”访问密钥”部分中的key1或key2连接字符串

优化选项

  • 批处理大小：一次从事件中心获取并（可选）传递到批处理管道的事件数量（见下文）

  • 预取大小：（可选）预取的事件数量

输出字段

  • 消息输出字段：包含消息（事件）的输出字段名称

  • 分区ID字段：分区ID的输出字段名称

  • 偏移量字段名称：事件偏移量的输出字段名称

  • 序列号字段名称：事件序列号的输出字段名称

  • 主机（所有者）字段名称：事件主机的输出字段名称

  • 入队时间字段名称：事件入队时间的输出字段名称

批处理选项

为了确保在检查点事件流之前安全处理所有记录，我们需要在执行此操作之前运行所有需要运行的逻辑，更新所有需要更新的内容。为此，我们将一批中读取的所有行传递到指定的批处理管道（将单线程运行）

  • 批处理管道：批处理管道文件名

  • 管道输入转换：批处理管道中用于发送事件的”注入器”或”从流中获取记录”转换的名称

  • 管道输出转换：（可选）批处理管道中读取并用作此监听器转换输出的转换名称

  • 最大等待时间（毫秒）：（可选但强烈建议！）即使批处理中可能没有指定数量的记录，在执行批处理管道之前等待的最长时间。当可能没有新事件从中心到达时，这对于防止陈旧记录长时间滞留在批处理管道输入中很有用

重要说明

批处理管道以注入器转换开始。它接收以下字段：

  • message（字符串）

  • partitionId（字符串）

  • offset（字符串）

  • sequenceNumber（整数）

  • host（字符串）

  • enqueuedTime（时间戳）
