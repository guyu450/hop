合并行（差异）

描述

“合并行（差异）”转换会比较并合并两个名为”参考（先前数据）“和”比较（新数据）“的数据流中的行，并为每行添加一个标志。

用法

此转换对于比较在两个不同时间收集的数据很有用。

例如，数据仓库的源系统可能不包含上次数据更新的时间戳。

您可以使用此转换来比较这两个数据流，并合并行中的日期和时间戳。

基于键字段和比较字段，此转换将参考行与比较行合并，并创建合并的输出行。

每行中的一个标志指示值是如何进行比较和合并的。可能的标志值有：

  • 相同：在两行中都找到了键，并且比较的值相同。

  • 已更改：在两行中都找到了键，但一个或多个比较的值不同。

  • 新增：在参考行中未找到键。

  • 已删除：在比较行中未找到键。

如果行的标志是 相同 或 已删除，则合并的输出行基于参考行。

如果标志是 新增 或 已更改，则合并的输出行基于比较行。

您还可以将合并并带有标志的行发送到管道中的后续转换，例如 切换-案例 或 合并后同步。在后续转换中，您可以使用 合并行（差异） 生成的标志字段来控制目标表上的更新/插入/删除操作。

选项

选项 描述
转换名称 转换的名称。
参考行来源 指定生成参考行的转换。它是一个包含原始行（您要将新行与之进行比较的行）的流。
比较行来源 指定生成比较行的转换。它是一个包含新行的流
标志字段名 指定输出流上标志字段的名称。
匹配键 指定包含用于匹配的键的字段。点击”获取键字段”可插入参考行中的所有字段
比较值 指定包含要比较的值的字段。点击”获取值字段”可插入比较行中的所有字段。此处无需重复键字段。
