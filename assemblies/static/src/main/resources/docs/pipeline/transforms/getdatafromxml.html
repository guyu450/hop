从XML获取数据

描述

“从XML获取数据”转换功能支持使用XPath规范从任何类型的XML文件中读取数据。“从XML获取数据”可以两种模式（静态或动态）从三种来源（文件、流和URL）读取数据。另请参阅：示例（示例项目）：

转换名称 转换的名称。在管道中必须唯一。

将源读取为URL 从URL指定的位置读取XML数据。

内容选项卡

选项 描述
设置
循环XPath 对于XML文件或数据中的每个匹配项，会向 输出中添加一行数据。这是用于将XML文件扁 平化的主要规范。你可以使用”获取XPath节点 “按钮在XML文档中搜索可能的重复节点，但是 ，如果XML文档很大，这可能需要一些时间。
编码 如果XML文档中未 指定编码，则为此处指定的XML文件名编码。
是否支持命名空间？ 如果XML文档 在解析时需要考虑命名空间，请启用此选项。
是否忽略注释？ 启用此 选项可在解析时忽略XML文档中的所有注释。
是否验证XML？ 启用此选项可 在解析之前验证XML。当你想在XPath字段值中 动态替换时，请使用令牌。令牌位于@_和 - （@_字 段名-）之间。请参阅示例1了解其工作原理。
使用令牌 启用此选项可使用令牌验证XML。
忽略空文件 启用此选项可忽略任 何无内容的文件。这些不是有效的XML文档。
如果没有文件则不引发错误 启用此选项后，如果未找到 文件则不执行任何操作。否则，将返回错误。
限制 指定要 返回的最大行数。零（0）表示返回所有行。
修剪路径以处理大文件 指定一 个类似于”循环XPath”的路径，用于处理XML文 件中的数据块。每个匹配值定义一个要读取和 处理的数据块。使用修剪路径可加快大文件的 处理速度。你也可以使用此参数避免多次HTTP URL请求。你也可以使用 XML输入流（StAX） 转换来实现此目的。
附加字段
是否在输出中包含文件名？ 允许你指定一个字段名称，以 便在该转换的输出中包含文件名（字符串）。
文件名的字段名 从中读取文件名值的字段。
是否在输出中包含行号？ 允许你指定一个字段名称 ，以便在该转换的输出中包含行号（整数）。
行号的字段名

从中读取行号值的字段。

字段选项卡

选项 描述
名称 输出字段的名称
XPath 要读取的元素节点或属性的路径
元素 要读取的元素类型：节点或属性
结果类型

“值”或”单个节点”

  • 值： 检索XPath表达式的值，例如元素的内容或属性的值。

  • 单个节点：检索XPath表达式返回的XML内 容。与”值”不同，“单个节点”的结果是一个XML片段。
类型 要转换到的数据类型
格式 数据类型转换中使用的格式或转换掩码
长度 输出数据值中的最大字符数
精度 输出数据中显示数字时使用的小数位数
货币 用于货币值的货币符号。
小数 用于浮点数的数字小数符号。
分组 用于在数据中分隔千位的数字分组符号
修剪类型 如何从值中删除空白字 符，可从左侧（修剪前导空格）、右侧（修剪尾随空格 ）、两侧（修剪所有空白）或不进行（不进行修剪）。
重复 如果列值为空（null），则重复上一行的列值
获取字段 点击用输入流中的字段填充表格。
从片段中选择字段 点击用与循环XPath和必须在 弹出对话框中提供的XML文档相对应的字段填充表格。
