用户定义的Java表达式

描述

此转换允许您输入Java表达式，这些表达式用于计算新值或替换字段中的值。表达式所依赖的任何自定义JAR库都需要放置在plugins/transforms/janino/lib文件夹中。

用法

如果您有一个Java表达式，例如：

C=A+B

那么您可以在对话框中直接输入表达式的右侧：

A+B

这些值作为其对应的Java对象暴露给表达式：

数据类型 Java类
大数字 BigDecimal
二进制 byte[]
日期 java.util.Date
整数 java.lang.Long
数字 java.lang.Double
字符串 java.lang.String

选项

选项 描述
转换名称 为此转换指定一个名称。在管道中此名称必须唯一。
新字段 数据流中的新字段，该字段包含表达式的结果。如果要覆盖现有字段，则需要在此处和”替换值”选项中定义相同的字段。
Java表达式 要计算的Java表达式。请参阅以下示例。
值类型 字段的数据类型。
长度 新字段中字符串的最大长度。
精度 用于表示数字的小数位数。
替换值 当您要替换现有字段中的值时，将此设置为与”新字段”名称相同。

示例

将两个整数A和B相加

A+B

连接两个字符串：firstname和name，并在中间添加一个空格

firstname+" "+name

或者，如果您真的很在意性能，下面这个可能会更快：

new StringBuffer(firstname).append(" ").append(name).toString()

使用原生Java和API函数

System.getProperty("os.name")

业务规则（If / Then / Else）

a<c?true:false

这个可以更复杂

a<c?(a==1?1:2):3

甚至可以使用OR、AND和其他运算符及函数

使用常量

如果使用常量，在某些表达式中可能需要定义正确的类型，否则可能会抛出错误。例如，如果使用”0”，它是”int”类型，但 Hfxt中的”Integer”是”java.lang.Long”类型，所以会得到一个异常：

表达式类型”int”和”java.lang.Long”不兼容

要解决这个问题，可以使用：

test == null? new Long(0) : test

上面的表达式检查”test”是否为null，如果是，则用一个长整型的零替换它。否则，返回不变的”test”。

从字符串末尾截取并测试是否为null和最小长度

假设您有像这样的输入字符串”location”

Orlando FL
New York NY

并且您想分离州和城市。您可以使用以下表达式：

对于州（获取最后两个字符）：

location != null && location.length()>2? location.substring(location.length()-2, location.length()) : null

对于城市（获取开头部分，不包括最后两个字符并去除首尾空格）：

location != null && location.length()>2? location.substring(0, location.length()-2).trim() : location

LIKE运算符的功能（包含字符串）

以下示例在源字符串中包含abc时返回1，否则返回2。当源字符串为null时也返回2。如果您希望返回值为Integer类型的值，请使用”new Long(1)“和”new Long(2)“。

samplestr != null && samplestr.indexOf("abc")>-1? 1 : 2

阻止特定代码

作为一项简单的安全措施，您可以阻止包含特定字符串的代码执行。这可以通过在位于/plugins/transforms/janino的codeExclusions.xml文件中添加排除项来实现。

示例：

    <exclusions>
        <exclusion>System.</exclusion>
        <exclusion>HfxtVfs.</exclusion>
    </exclusions>
