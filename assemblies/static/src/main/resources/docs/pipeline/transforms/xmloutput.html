XML输出

描述

XML输出转换允许您将任何来源的行写入一个或多个XML文件。

选项

文件选项卡

文件选项卡用于设置XML输出文件格式的常规属性。

选项 描述
转换名称 转换的名称。
文件名 指定输出文本文件的文件名和位置。
开始时不创建文件 启用此选项可在没有行被处理时避免创建空文件。
将输出传递给Servlet 启用此选项可通过Web服务返回数据，而不是写入文件（请参阅通过Web服务传输数据）。
扩展名 在文件名末尾添加一个句点和扩展名（.xml）。
在文件名中包含转换编号 如果您运行多个副本的转换（另请参阅启动转换的多个副本），副本编号将包含在文件名中，位于扩展名之前（_0）。
在文件名中包含日期 在文件名中包含系统日期（_20041231）。
在文件名中包含时间 在文件名中包含系统日期（_235959）。

内容选项卡

选项 描述
压缩 如果您希望将XML文件存储在ZIP存档中，请选中此选项。
编码 要使用的编码。此编码在XML文件的头部指定。
父XML元素 XML文档中根元素的名称。
行XML元素 XML文档中要使用的行元素的名称。
每……行拆分 在创建另一个XML文件之前，单个XML文件中要放入的数据的最大行数。

字段选项卡

选项 描述
字段名 字段的名称。
元素名 XML文件中要使用的元素的名称。
内容类型 该字段是属性还是元素
类型 字段的类型可以是字符串、日期或数字。
格式 用于转换值的格式掩码
长度

长度选项取决于字段类型，如下所示：

  • 数字 - 数字中的有效数字总数

  • 字符串 - 字符串的总长度

  • 日期 - 字符串打印输出的长度（例如，4仅返回年份）
精度

精度选项取决于字段类型，如下所示：

  • 数字 - 浮点数的位数

  • 字符串 - 未使用

  • 日期 - 未使用
货币符号 用于表示货币的符号，如$10,000.00或€5,000.00
小数点 小数点可以是”.”（10,000.00）或”,“（5,000.00）
分组符号 分组符号可以是”,“（10,000.00）或”.”（5,000.00）
空值 如果字段的值为空，则将此字符串插入到文本文件中
获取字段 点击以从输入流中检索字段列表。
最小宽度 以这样一种方式更改字段选项卡中的选项，使得 文本文件中各行的最终宽度最小；例如，不是保存0000001，而 是写入”1”，依此类推。字符串字段不会填充到其指定的长度。
