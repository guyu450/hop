获取文件名

描述

“获取文件名”转换允许您获取与文件系统上的文件名相关的信息。有关检索到的文件的信息将作为行添加到流中。

用法

此转换的输出字段如下：

  • filename - 完整的文件名，包括路径（/tmp/hfxt/somefile.txt）

  • short_filename - 仅文件名，不包括路径（somefile.txt）

  • path - 仅路径（/tmp/hfxt/）

  • type

  • exists

  • ishidden

  • isreadable

  • iswriteable

  • lastmodifiedtime

  • size

  • extension

  • uri

  • rooturi

文件选项卡

此选项卡定义要检索文件名的文件位置。有关指定文件位置的更多信息，请参阅”文本文件输入”转换中的”使用正则表达式选择文件”部分。

示例：您有一个静态目录c:\temp，预计会在其中放置扩展名为.dat的文件。在”文件/目录”下，您应指定c:\temp，在”通配符”下，您应使用类似.*\.dat$的正则表达式。

包含子文件夹？ 指示表达式是否考虑子文件夹中的文件。
文件或目录 如果文件不是由字段定义的，请指定文件名或要从中加载多个文件的目录。
添加 点击将指定的文件、目录和正则表达式添加到选定文件列表中。
浏览 点击选择一个文件。
包含通配符（正则表达式） 如果要加载多个文件，这是一个与要加载的文件名匹配的正则表达式。
排除通配符（正则表达式） 定义一个与要从转换中排除的文件匹配的正则表达式。

过滤器

“过滤器”选项卡允许您根据以下条件过滤检索到的文件名：

  • 所有文件和文件夹

  • 仅文件

  • 仅文件夹

它还为您提供：

  • 在输出中包含行号的功能

  • 限制返回行数的功能。限制参数将作用于返回的总行数，而不仅仅是返回的文件数。

  • 将文件名添加到结果列表的功能

  • 在未找到文件/文件夹时打印错误消息而不停止处理的功能

  • 在未找到文件/文件夹时引发异常并停止处理的功能。

选项 描述
过滤类型 选择过滤所应用的对象。选择所有文件和文件夹、仅文件或仅文件夹。
在输出中包含行号？ 指示行号是否作为一个字段包含在输出中。
行号字段名 报告行号的字段名称。
不报告错误 指示如果没有文件或文件夹与过滤条件匹配，管道是否安静地失败。如果未选中，如果没有可用的文件或文件夹，则会报告错误。
引发异常并停止处理 指示如果没有文件或文件夹与过滤条件匹配，是否会引发异常，这也会阻止管道继续运行。如果未选中，管道将在没有文件的情况下继续运行。
限制 输出中包含的文件和文件夹数量。
将文件名添加到结果？ 指示文件名是否作为一个字段添加到输出中。

未找到文件时引发异常的详细信息

如上所述，如果您在”过滤器”选项卡中启用该开关，Hfxt将在未找到文件的情况下引发异常并停止处理。

在这种情况下，我们需要注意，根据您选择识别要查找的文件集的方式，异常会以两种不同的方式引发。

  • 如果您在”选定文件”表中将文件（或包含/排除表达式）指定为一组，则会一次性考虑指定的整个集合来执行文件检索，如果未找到文件，则会引发异常。

  • 如果您通过”字段中的文件名”选项指定文件，则我们要检索的文件的详细信息来自传入的行。这意味着检索是逐行进行的，一旦用于指定搜索文件的任何一个详细信息失败，就会引发异常。因此，在这种情况下，触发异常的评估是在评估每个传入行之后进行的，而不是评估传入行中找到的详细信息返回和生成的整个数据集。
