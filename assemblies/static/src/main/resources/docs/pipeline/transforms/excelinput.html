Microsoft Excel输入

描述

Microsoft Excel输入转换从Microsoft Excel电子表格读取数据。默认的电子表格类型（引擎）设置为Excel XLSX、XLS。当您读取其他文件类型（如OpenOffice ODS）并使用特殊功能（如受保护的工作表）时，您需要在”内容”选项卡中相应地更改电子表格类型（引擎）。

“字段”选项卡

“字段”选项卡用于指定必须从Excel文件中读取的字段。您可以选择使用 模式定义 或手动定义所需字段的布局。

如果工作表有标题行，请使用”从标题行获取字段”自动填充可用字段。

“类型”列对给定字段执行类型转换。例如，如果您要读取日期，而Excel文件中有一个字符串值，请指定转换掩码。注意：在数字到日期的转换（例如，20051028 -> 2005年10月28日）的情况下，请指定转换掩码yyyyMMdd，因为在进行字符串到日期的转换之前会进行隐式的数字到字符串的转换。

选项 描述
模式定义 我们要引用的 模式定义 的名称。
名称 字段的名称。
类型 字段的数据类型；字符串、日期或数字。
长度 长度选项取决于字段类型。数字：数字中的有效数字总数；字符串：字符串的总长度；日期：确定打印或记录的日期字符串的长度。
精度 精度选项取决于字段类型，但仅支持数字类型；它返回浮点数的位数。
修剪类型 在处理之前截断字段（左、右、两侧）。对于没有固定长度的字段很有用。
重复 如果设置为Y，如果下一行中的字段为空，将重复此值。
格式 格式掩码（数字类型）。有关格式符号的完整描述，请参阅”文本文件输入”转换和”数字格式”部分。
货币 用于表示货币的符号。
小数 小数点；可以是点或逗号。
分组 一种在四位数或更大的数字中分隔千位单位的方法。可以是点或逗号。

“附加输出字段”选项卡

此选项卡检索自定义元数据字段以添加到转换的输出中。每个字段的用途在其名称中定义，但您可以根据需要使用这些字段。每个项目定义一个输出字段，该字段将包含以下信息。其中一些信息可能缺失。

选项

描述

完整文件名字段

完整的文件名加上扩展名。

工作表名称字段

您正在使用的工作表名称。

工作表行号字段

当前工作表的行号。

写入的行号字段

写入的行数。

短文件名字段

包含不带路径信息但带有扩展名的文件名的字段名称。
