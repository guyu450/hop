雪花批量加载器

描述

雪花批量加载器转换使用雪花复制命令来加载数据，而不是通过表输出转换发送单个插入语句。它通过一个三步流程执行此批量加载操作：

选项

批量加载器选项卡

  • 连接：批量加载时要使用的数据库连接

  • 模式：（可选）包含要加载表的模式。

  • 表名：要加载的表的名称。

  • 暂存位置类型：用于存储文件的雪花阶段类型。

    • 用户位置：使用用户的主目录来存储正在加载的文件。

    • 表位置：使用表的内部阶段来存储正在加载的文件。

    • 内部阶段：使用已创建的内部阶段来存储正在加载的文件。

  • 内部阶段名称：（当暂存位置类型 = 内部阶段时）要使用的内部阶段的名称。

  • 工作目录：在将临时文件加载到雪花之前存储它们的本地工作目录。

  • 出错时：（中止、跳过文件、跳过文件百分比、继续）加载时遇到错误的行为。

  • 错误限制：（当出错时 = 跳过文件或跳过文件百分比）在跳过文件之前的错误限制。如果为空或为0，则在遇到第一个错误时将跳过文件。

  • 每……行拆分加载：将临时文件拆分为多个较小的文件将允许雪花并行执行批量加载，从而提高性能。这是每个文件应包含的行数。

  • 加载后删除文件：（是/否）加载后是否应从雪花阶段删除文件？你还需要将变量 SNOWFLAKE_DEBUG_MODE 设置为 true 以保留文件。

数据类型选项卡

  • 数据类型：正在批量加载的数据的类型。

    • CSV:

    • 去除空白字符：（是/否）在加载到雪花时是否应去除字段值周围的任何空白字符。

    • 为空值如果：一个逗号分隔的字符串列表，在加载到雪花时应将这些字符串转换为空值。这些字符串无需加引号。

    • 列数不匹配时出错：如果表中的列数与输出的列数不匹配，则不加载该行并抛出错误。

    • JSON：正在加载的数据在输入流中作为包含JSON的单个字段接收。

    • 去除空值：是否应去除JSON中的空值，从而减少所需的存储量。

    • 忽略UTF8错误？：解析JSON时忽略任何UTF8字符编码错误。

    • 允许重复元素：允许JSON多次包含相同的元素。如果同一元素多次出现，该元素的最后一个值将存储在雪花中。

    • 解析八进制数：将JSON中存储的任何数字解析为八进制而不是十进制。

字段选项卡

  • 数据类型CSV

    • 指定字段：（是/否）是否明确指定从Hfxt到雪花的字段映射。如果未指定字段映射，则此转换的输入字段顺序必须与表中的字段顺序匹配。

    • 字段映射表：（当选中指定字段时）字段无需按任何顺序排列。

    • 流字段：输入流上的字段

    • 表字段：要将输入字段映射到的表中的字段。

    • 获取字段按钮：从输入流获取字段，并将它们映射到表中同名的字段。

    • 输入字段映射按钮：打开一个窗口，帮助用户指定输入字段到表字段的映射。

  • 数据类型JSON

    • JSON字段：输入流上包含要加载的JSON数据的字段。
