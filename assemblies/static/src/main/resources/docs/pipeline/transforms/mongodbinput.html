MongoDB输入

描述

MongoDB输入转换功能使您能够从MongoDB中的集合中检索文档或记录。有关MongoDB的更多信息，请参阅MongoDB文档。

选项

常规

转换名称：在管道中指定MongoDB输入转换的唯一名称。预览按钮：显示此转换生成的行。输入您要预览的最大记录数，然后单击”确定”。预览数据将显示在”检查预览数据”窗口中。

输入选项标签

“输入选项”标签使您能够指定要从中检索信息的连接和集合。

在”输入选项”字段中输入以下信息：

选项 定义
MongoDB连接 用于此MongoDB输入转换的 MongoDB连接。
集合 要从中检索数据的集合名称。单击”获取集合”，用数据库中的集合列表填充下拉菜单。

查询标签

“查询”标签使您能够优化读取请求。此标签在两种不同的查询模式下运行：

  • 查询表达式 模式（默认）

  • 聚合管道规范 模式。

查询为聚合管道 选项可在这两种模式之间切换。查询表达式使用MongoDB类似JSON的查询语言和查询运算符来执行 查询操作。聚合管道规范 字段使用MongoDB的 聚合框架 来转换和组合集合中的文档。聚合管道将多个 管道表达式 连接在一起，前一个表达式的输出成为下一个表达式的输入。

在”查询”字段中输入以下信息：

字段/选项

定义

查询表达式（JSON）

在此字段中输入查询表达式以限制输出。

聚合管道规范（JSON）

选择 查询为聚合管道 选项以显示 聚合管道规范（JSON） 字段。然后输入管道表达式以执行聚合或选择操作。方法名称（包括您在”输入选项”标签中选择的数据库的集合名称）将显示在此字段标签之后。

查询为聚合管道

选择此选项以使用聚合管道框架。

为每行执行

选择此选项以对每行数据执行查询。

字段表达式（JSON）

输入一个参数以控制查询的投影（要返回的字段）。如果为空，则返回所有字段。此字段仅适用于查询表达式。

字段标签

使用”字段”标签为导出字段定义属性。“字段”标签在两种不同的模式下运行：

  1. 将所有字段包含在单个JSON字段中

  2. 在输出中包含选定的字段。

如果将输出存储在单个JSON字段中，可以使用JSON输入转换或用户定义的Java类转换来解析此JSON。

注意： 当选择”输出单个JSON字段”时，“字段”标签中的所有字段（除了”JSON输出字段名称”）均处于非活动状态。当未选择”输出单个JSON字段”时，“JSON输出字段名称”处于非活动状态。

常规选项：

  • 获取字段按钮：单击它以生成一组示例文档。您可以编辑示例中每个字段的字段名称、路径和数据类型列表。

  • 输出单个JSON字段：指定查询结果为具有字符串数据类型（默认）的单个JSON字段。

  • JSON输出字段名称：指定包含服务器JSON输出的字段名称。

如果要输出不同的字段，请在表中输入以下信息：

选项

定义

#

此条目在列表中的顺序。

名称

基于”路径”字段中的值的字段名称。此处显示的名称将管道中显示的字段名称与MongoDB数据库中显示的字段进行映射。您可以编辑该名称。

路径

指示MongoDB中字段的JSON路径。

如果显示的路径是一个数组，您可以通过在数组的括号部分传递键值来指定数组的特定元素。

例如：

  • $.emails[0] 表示您希望结果显示数组中的第一个值。

  • 要显示所有数组值，请使用星号作为键，如下所示 $.email[*]。

  • 如果数组包含记录，而不仅仅是字符串，您可以指定要显示的记录，如下所示： $.emails[].sender。

类型

指示数据类型。

索引值

为字符串字段指定用逗号分隔的合法值列表。当您在此字段中指定值时，Hfxt索引数据类型将应用于数据。如果未指定值，则应用字符串数据类型。通常，只有在使用Weka元数据处理标称字段时，才需要修改此字段。

示例：数组最小：最大索引

指示示例文档中索引的最小值和最大值。

示例：出现次数/文档数

指示字段出现的频率和处理的文档数。

示例：不同类型

指示在示例文档中，相同字段是否由不同的数据类型填充。当对多个文档进行采样且相同字段包含不同的数据类型时，“示例：不同类型”字段将填充为”Y”，“类型”字段将显示字符串数据类型。此字段的Hfxt类型将设置为字符串数据类型，以处理不同的输出值类型。

以下部分包含查询表达式和聚合管道的示例。

查询表达式

MongoDB允许您使用特定字段和值在集合中选择和过滤文档。MongoDB扩展JSON 文档详细介绍了如何使用查询。 Hfxt仅支持此页面上讨论的功能。

下表显示了一些可用于从MongoDB请求数据的查询语法和结构示例：

查询表达式

描述

{ name : "MongoDB" }

查询所有”name”字段值等于”MongoDB”的记录。

{ name : { '$regex' : "m.*", '$options' : "i" } }

使用正则表达式查找以”m”开头的”name”字段，不区分大小写。

{ name : { '$gt' : "M" } }

搜索所有大于”M”的字符串。

{ name : { '$lte' : "T" } }

搜索所有小于或等于”T”的字符串。

{ name : { '$in' : [ "MongoDB", "MySQL" ] } }

查找所有名称为”MongoDB”或”MySQL”的记录（引用）。

{ name : { '$nin' : [ "MongoDB", "MySQL" ] } }

查找所有名称既不是”MongoDB”也不是”MySQL”的记录，或者该字段未设置的记录。
