LDAP输入

描述

LDAP输入转换允许您从LDAP服务器读取诸如用户、角色和其他数据等信息。以下各节介绍LDAP输入转换的可用选项。

常规选项卡

选项 描述
转换名称 转换的名称；此名称在单个管道中必须唯一。
主机 主机可以是LDAP目录服务器的IP地址或其DNS名称。
端口 LDAP目录服务器的端口号。
使用身份验证 启用LDAP身份验证
用户名 身份验证期间传递的用户名。
密码 身份验证期间传递的密码。
使用证书 启用证书的使用。
信任库路径
信任库密码
信任所有证书
测试连接 测试配置的到LDAP服务器的连接。

搜索选项卡

选项 描述
动态搜索基 启用搜索基字段。
搜索基字段名 包含LDAP基本节点的字段。
搜索基 用于搜索LDAP内容的LDAP基本节点。
动态筛选字符串 启用筛选字符串字段。
筛选字符串字段名 包含筛选字符串的字段。
筛选字符串 用于搜索自定义内容的LDAP筛选器，在当前阶段仅支持”单筛选格式”，例如：mail=*

高级选项卡

选项 描述
在输出中包含行号？ 向输出中添加行号。
行号字段名 包含行号的字段。
限制 限制返回的结果数量。
时间限制 限制返回结果的时间。
多值字段分隔符
设置分页
页面大小
搜索范围 对象范围、一级范围、子树范围

字段选项卡

选项 描述
名称 导入字段的名称。注意：如果您在”选择和修改”选项卡中重命名字段，此处的名称必须与重命名后的值匹配。
属性
提取为 字符串、二进制
是否为排序键？ 是/否
类型 此字段的数据类型。
格式 格式掩码（数字类型或日期格式）
长度 字段长度。
精度 精度选项取决于字段类型，但仅支持数字类型；它返回浮点数的位数。
货币 用于表示货币的符号
小数 小数点；可以是点或逗号
分组 在四位数或更多位数的数字中分隔千位的方法。可以是点或逗号。
修剪类型 在何处修剪字段，左、右、两边、不修剪
重复 如果LDAP为某个属性返回空值，则使用上一行的值
获取字段 获取结果字段
