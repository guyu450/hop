分组依据

描述

“分组依据”转换会根据指定的一个字段或一组字段，对来自源的行进行分组。为每个组生成一个新行。它还可以为这些组生成一个或多个聚合值。常见用途包括计算每个产品的平均销售额，以及统计库存中某一物品的数量。“分组依据”转换是为已排序的输入设计的。如果输入未排序，只有连续的两行会被正确分组。如果在Hfxt外部对数据进行排序，字段中数据的大小写敏感性可能会产生意外的分组结果。可以使用”内存分组依据”转换来处理未排序的输入。

选项

选项 描述
转换名称 转换的名称。
包含所有行？ 如果希望输出中包含所有行，而不仅仅是聚 合行，请启用此选项；为了在输出中区分这两种 类型的行，输出中需要一个标志。在这种情况下 ，必须指定标志字段的名称（类型为布尔值）。
临时文件目录 存储临时文件的目录（当 启用”包含所有行”选项且分组后的行数超过5000 行时需要此目录）；默认是系统的标准临时目录
TMP文件前缀 指定命名临时文件时使用的文件前缀
添加行号，每组重新开始 启用 此选项可添加一个行号，每行组从1重新开始。
行号字段名称 添加的用于包含行号的字段名称。
始终返回一行 如果启用此选项，“分组依 据”转换将始终返回一个结果行，即使没有输入 行。如果要统计行数，此选项会很有用。不启用 此选项，永远不会得到计数为零（0）的结果。
分组字段表 指定要依据其进行分组的字段 。点击”获取字段”可从输入流中添加所有字段。
聚合表

指定必须进行聚合的字段、聚合方法以及 生成的新字段的名称。以下是可用的聚合方法：

  • 求和

  • 平均值（均值）

  • 中位数

  • 百分位数

  • 最小值

  • 最大值

  • 值的数量（N）

  • 用逗号（,）分隔连接字符串

  • 第一个非空值

  • 最后一个非空值

  • 第一个值（包括空值）

  • 最后一个值（包括空值）

  • 累积求和（仅”所有行”选项可用！）

  • 累积平均值（仅”所有行”选项可用！）

  • 标准差（总体）

  • 用 <值>

分隔连接字符串：在”值”列中指定分隔符（支持 十六进制）

  • 不同值的数量

  • 行数（无字段参数）

  • 标准差（样本）

  • 百分位数（最近秩方法）

  • 用换行符（CRLF）分隔连接字符串

  • 用 <值>

分隔连接不同值：在”值”列中指定分隔符（支持 十六进制）
