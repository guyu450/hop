将文件内容加载到内存中

描述

“将文件内容加载到内存中”转换操作会将文件内容加载到内存里。

选项

文件标签

选项 描述
文件名在字段中定义 从字段中获取文件名
从字段获取文件名 包含文件名的字段
文件或目录 要添加的文件或目录路径
添加 将文件或目录添加到选定文件中
浏览 使用本地文件浏览器选择路径
正则表达式 允许根据正则表达式包含文件
排除正则表达式 允许根据正则表达式排除文件
选定文件 要加载到内存中的选定文件
显示文件名 预览选定的文件

内容标签

选项 描述
编码 文件编码（UTF、ISO等）
忽略空文件 忽略空文件
忽略缺失路径 忽略缺失路径
限制 限制从文件中加载的行数
在输出中包含文件名？ 允许在输出中包含文件名
文件名字段名 包含文件名的字段
在输出中包含行号？ 允许在输出中包含行号
行号文件名 包含行号的字段
将文件添加到结果文件名 将文件添加到生成的文件名中

字段标签

要从文件中加载的字段。

选项 描述
名称 导入字段的名称。
元素 文件内容或大小
类型 此字段的数据类型
格式 格式掩码
长度 字段长度
精度 精度选项取决于字段类型，但仅支持数字类型；它返回浮点数的小数位数
货币 用于表示货币的符号
小数 小数点；可以是点号或逗号
分组 在四位数及以上的数字中分隔千位的方法。可以是点号或逗号。
修剪类型 修剪类型：无、左、右、两边
重复 如果希望在当前行对应值为空时重用最后一个非空行的值，请输入”Y”。输入”N”则使该行留空。
获取字段 根据文件内容检索可用字段

附加输出标签

选项 描述
短文件名字段 包含不带路径信息但带有扩展名的文件名的字段名。
扩展名字段 包含文件名扩展名的字段名。
路径字段 包含操作系统格式路径的字段名。
是否隐藏字段 包含文件是否隐藏（布尔值）的字段名。
最后修改字段 包含最后修改时间的字段名。
Uri字段 包含URI的字段名。
根Uri字段 仅包含URI根部分的字段名。

按钮

选项 描述
预览行 预览此转换生成的行。
