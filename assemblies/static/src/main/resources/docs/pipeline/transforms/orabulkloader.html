Oracle批量加载器

描述

此转换允许您将数据批量加载到Oracle数据库。它会将接收到的数据写入合适的加载格式，然后调用Oracle SQL*Loader将其传输到指定的表中。

选项

选项 描述
转换名称 转换的名称。
连接 目标表所在的数据库连接名称。
目标模式 要写入数据的表的模式名称。
目标表 目标表的名称。
Sqldr路径 sqlldr实用程序的完整路径（包括sqlldr）。
加载方法 加载数据时要使用的SQL*Loader方法： * 自动加载（结束时）将在接收 到此转换中指定参数的所有输入后启动sqlldr。 * 手动加载仅创建一个控制文件和数据文件，这可 以用作后门：您可以让Hfxt生成数据并创建例如 自己的控制文件来加载数据（在此转换之外）。 * 自动 加载（实时）将启动sqlldr，并在该转换接收到 输入时将数据通过管道传输到sqlldr作为输入。
加载操作 追加、插入、 替换、截断。这些对应于要执行的sqlldr操作。
最大错误数 达到此错误行数后， sqlldr将中止。这对应于sqlldr的”ERROR”属性。
提交行数 达到此行数后 提交，这对应于sqlldr的”ROWS”属性，该属性在 使用常规路径加载和直接路径加载时有所不同。
绑定大小 对应于sqlldr的”BINDSIZE”属性。
读取大小 对应于sqlldr的”READSIZE”属性。
控制文件 用作sqlldr控制文件的文件名。
数据文件 将写入数据的数据文件名。
日志文件 日志文件名（可选）。
错误文件 将包含被拒绝记录的错误文件名（可选）。
丢弃文件 将包含未与控制文件中指定的任何记录选 择标准匹配的过滤记录的丢弃文件名（可选）。
编码 以特定编码对数据进行编码，除 下拉列表中的编码外，可选择任何有效的编码。
Oracle字符集 要使用的Oracle字符集。
备用记录终止符 指定此值可覆盖SQL*Loader的默认记录终止符。
直接路径 开启直 接路径加载（对应于sqlldr中的DIRECT=TRUE）。
使用后删除cfg/dat文件 此选项会在使用后删除控制文件和数据文件。
遇到警告时失败 此选项会导致转换在加载警告时失败。
遇到错误时失败 此选项会导致转换在加载错误时失败。
并行加载数据 此选项会导致数据并行加 载。并行加载仅在使用直接路径选项时才可能。
要加载的字段

此 表包含要从中加载数据的字段列表，属性包括： * 表字段：要加载到PostgreSQL表中的表字段； * 流字段：要从传入行中获取的字段； * 日期掩码：“直通”、“日期”或”日期时 间”，确定日期/时间戳在Oracle中的加载方式。
