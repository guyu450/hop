XSD验证器

描述

XSD验证器转换会针对文件或输入字段中的数据执行XSD验证。XSD是XML Schema Definition（XML模式定义）的缩写。因此，这里涉及两个实体：更复杂的是，XSD可以存储在XML自身内部。另请参阅XSD验证器工作流操作。

选项

选项 描述
转换名称 转换的名称。
XML源

  • XML源是一个文 件：如果在XML字段中将XML文件定义为文件名，请选中此项

  • XML字段：读取包含XML文件名或XML内容本身的字段
输出字段

  • 结果字段名称：结果字段的名称

  • 输出字 符串字段：如果要在验证后指定特定消息，请选中此选项：

    • XML有效时显示：如果XML有效时显示的消息。

    • XML无效时显示：如果XML无效时显示的消息。

  • 在输出中添 加验证消息：如果要在输出中添加验证消息，请选中此项。

  • 验证消息字段：验证消息字段的名称。
XML模式定义

XSD源：选择以下选项之一：

  • XSD源是一个文 件，请让我指定文件名（在下面的XSD文件名字段中指定）。

  • XSD源是一个文 件，在一个字段中定义（在下面的XSD文件名字段中指定）。

  • XSD源在源XML内部定义。
