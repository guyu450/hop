谷歌表格输出

描述

谷歌表格输出转换将数据写入谷歌表格工作表。此转换需要一个谷歌服务账号（JSON文件）以及一个启用了谷歌云端硬盘和谷歌表格API的谷歌云项目。

选项

服务账号标签页

选项 描述
JSON凭证密钥文件 允许您指定或浏览服务账号云端硬盘中已有的电子表格，或与服务账号电子邮件共享的电子表格。
应用名称 您在谷歌开发者控制台中为服务账号设置的应用名称。
超时时间 允许您指定一个https超时时间（以分钟为单位，默认值为5）。
模拟身份 允许您模拟服务账号。有关更多信息，请查看 谷歌文档。

点击 测试连接 按钮，以验证您为服务账号指定的JSON凭证密钥文件是否可以使用谷歌云端硬盘和电子表格API，并有权访问您的谷歌电子表格。成功时，您将看到一条 谷歌云端硬盘API：成功！ 的消息。

电子表格标签页

选项 描述
电子表格密钥 允许您指定或浏览服务账号云端硬盘中已有的电子表格，或与服务账号电子邮件共享的电子表格。如果您输入一个（在云端硬盘中不存在的）工作表名称，并且勾选了”创建”复选框，它将尝试创建一个工作表。
工作表ID 应从选定的电子表格密钥中浏览获取。如果您想创建一个新文件，请输入任何将成为创建的电子表格中工作表名称的密钥。
追加到工作表 将行 不包括标题 追加到现有电子表格中。这与下面的”创建”选项不兼容。
如果不存在则创建新工作表 如果勾选此复选框，那么如果在”电子表格密钥”字段中指定的电子表格密钥不存在，它将在服务账号云端硬盘中创建一个新的电子表格（请注意，此账号没有用户界面）。
与……共享完全权限（读写） “共享给用户电子邮件”字段允许您指定一个用户的电子邮件，该用户将对新创建的文件获得完全权限。
域范围权限 允许与您的整个域共享（如果在谷歌云端硬盘中进行了配置）。
