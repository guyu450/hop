文本文件输出

描述

文本文件输出转换用于将数据导出为文本文件格式。这通常用于生成可由电子表格应用程序读取的逗号分隔值（CSV文件）。也可以通过在”字段”选项卡中设置字段长度来生成固定宽度的文件。您可以选择使用架构定义或手动定义所需的字段布局。如果您决定使用架构定义来定义字段布局，请使用”架构映射”转换根据所选的架构定义调整传入的数据流。

选项

文件选项卡

“文件”选项卡用于定义正在创建的文件的基本属性，例如：

选项 描述
转换名称 转换的名称。此名称在单个管道中必须唯一。
文件名 指定输出文本文件的文件名和位置。点击”浏览”选择位置。
将输出传递给Servlet 启用此选项可通过Web服务返回数据，而不是写入文件。
创建父文件夹 启用此选项可在创建文件时创建父文件夹。否则，该文件夹必须已经存在，否则写入将失败。
启动时不创建文件 启用此选项可在没有处理任何行时避免创建空文件。否则，在处理任何数据之前就会创建文件，可能会生成空文件。
从字段接受文件名？ 启用此选项可在输入流的字段中指定文件名。
文件名字段 启用上一个选项后，指定在运行时将包含文件名的字段。
扩展名 指定文件扩展名。创建文件时，这会在文件名和扩展名之间自动添加句点字符。例如，name.txt。
在文件名中包含转换编号 如果多次运行此转换（启动同一转换的多个副本），副本编号将包含在文件名中，位于扩展名之前，并用下划线与文件名分隔。例如，name_0。
在文件名中包含分区编号？ 在文件名中包含数据分区编号，如果数据未分区，则为null。
在文件名中包含日期 在文件名中包含系统日期。这用下划线与文件名分隔，默认格式为YYYYMMDD。例如，name_20230405。
在文件名中包含时间 在文件名中包含系统时间。这用下划线与文件名分隔，默认格式为hhmmss。例如，name_235959。
指定日期时间格式 启用此选项可指定日期和时间格式。否则，这些组件将使用默认格式。
日期时间格式 从列表中选择日期和时间格式，应用于附加到文件名的日期和时间值。
显示文件名 查看将生成的文件列表。
将文件名添加到结果 这会将所有处理过的文件名添加到内部结果文件名集中，以便进一步处理。

内容选项卡

“内容”选项卡包含以下用于描述正在读取的内容的选项：

选项 描述
追加 选中此选项可将行追加 到指定文件的末尾。否则，文件将被替换。
分隔符 指定在一行文本 中分隔字段的字符。通常是”;“或制表符。
插入制表符 点击可在”分隔符”字段中插入制表符。
包围符 一对字符串可 用于包围某些字段。这允许字段中包含分隔 符或包围符字符。包围符字符串是可选的。
强制在字段周围使用包围符？ 此选项强 制传入的字符串类型的所有字段（与文本文 件输出字段定义中最终更改的字段类型无关 ）用上述”包围符”属性中指定的字符包围。
禁用包围符修正？ 当字符串字段包含包围符时，它 会被包围，并且包围符字符会被转义。当字 符串字段包含分隔符时，它也会被包围。如 果不需要此逻辑，请选中此选项。由于需要 扫描字符串中的包围符和分隔符，这还会带 来额外的性能负担。因此，如果您确定不需 要此逻辑，因为您的字符串中没有这些字符 ，并且您想提高性能，请取消选中此选项。
标题 如果希望文本文件有 标题行（文件的第一行），请启用此选项。
页脚 如果希望文本文件有页脚行（文件 的最后一行），请启用此选项。注意：在追 加模式下使用此选项时要小心，因为在追加 新行之前无法从文件内容中删除页脚。在某 些用例中可能需要此选项，例如在管道每次 运行后添加页脚以分隔文件中的不同部分。
格式

可以是 DOS或UNIX。UNIX文件的行以换行符分隔。

DOS文件的行以回车符和换行符分隔。

选项有：CR+LF终止（Windows、DOS）/ LF终止（Unix）/ CR终止 / 无换行终止符
编码

指定要使用的文本 文件编码，或留空以使用系统的默认编码。

要使用Unicode，请指定UTF-8或UTF-16。
压缩

允许您压缩文件并指定压 缩类型，即.zip或.gzip，用于压缩输出。

注意：单个压缩存档中仅放置一个文件。
右对齐填充字段 在 字段末尾添加空格（或删除末尾的字符）， 直到它们达到”字段”选项卡中指定的长度。
快速数据转储（无格式） 在将大量数据转储到文本文件 时，通过不包含任何格式信息来提高性能。
每……行拆分 指定将文件拆分为指定行数的块的行数。
添加文件结束行 指定输出文件的替代结束行。

字段选项卡

“字段”选项卡用于定义要导出的字段的属性。下表描述了配置字段属性的每个选项：

选项

描述

架构定义

我们要引用的 架构定义 的名称。

名称

字段的名称。

类型

字段的数据类型。可以是字符串、日期或数字。

格式

选择要应用于字段值的格式。仅适用于数字和日期。

长度

长度选项取决于字段类型：

  • 数字 - 数字中的总有效位数

  • 字符串 - 字符串的总长度

  • 日期 - 字符串打印输出的长度（例如，. 仅返回年份）

精度

对于数字，指定浮点数的小数位数

货币符号

用于表示货币的符号，如美元（$10,000.00）或欧元（€5,000.00）

小数点

用于表示浮点数中小数点的字符。小数点可以是”.”（10,000.00）或”,“（5,000.00）。

分组符号

用于表示数字中千位分隔符的字符。可以是”,“（10,000.00）或”.”（5,000.00）

修剪类型

用于从字符串值中删除空白字符的修剪方法。可以是左（删除前导空格）、右（删除尾随空格）、两者都有或无。

注意：仅在未指定字段长度时修剪才有效。
