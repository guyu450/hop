从属性文件中读取数据（键，值）

描述

属性输入转换从Java属性文件中读取键/值对。

选项

文件标签

选项 描述
转换名称 转换的名称。此名称在单个管道中必须是唯一的。
文件名在字段中定义？ 要读取的文件名在输入流的某个字段中可用。
从字段获取文件名 指定从中读取文件名的字段。
文件或目录 指定输入文本文件的位置和/或名称。
添加 点击将文件/目录/通配符组合添加到下面选定文件列表（网格）中。
浏览
点击从文件浏览器中选择要加载的文件。 正则表达式
指定要用于在先前选项中指定的目录中选择文件的正则表达式。 排除正则表达式
指定一个正则表达式，用于从指定目录中排除文件。 选定文件
包含选定文件（或通配符选择）的列表，以及一个属性，用于指定该文件是否为必需文件。如果某个文件是必需的但未找到，则会生成错误，否则将跳过文件名。 删除
点击从列表中删除选定的文件或通配符选择。 编辑
点击修改选定的文件或通配符。 显示文件名…​

内容标签

选项 描述
文件类型 文件的类型。应为”属性文件”。
编码 文件使用的字符编码。
部分 如有必要，指定要读取的文件部分。
限制 指定从文件中读取的最大行数，或指定0表示无限制。
用变量替换值 如果文件是以变量形式提供的，则解析该变量以获取文件名。
在输出中包含文件名？ 允许指定一个字段名称，以便在该转换的输出中包含文件名。
在输出中包含行号 允许指定一个字段名称，以便在该转换的输出中包含行号（整数）。
每个文件重置行号？ 启用后，在每个单独文件的开头将生成的行号重置为1。否则，行号将统计所有文件中的所有行。
在输出中包含部分名称？ 允许指定一个字段名称，以便在该转换的输出中包含部分名称。
将文件名添加到结果？ 将读取的文件名称添加到该管道的结果中。在内存中保留一个唯一列表，可在工作流的下一个工作流操作中使用，例如在另一个管道中。

字段标签

选项 描述
名称 输出字段的名称
列 要读取的属性
类型 字段的数据类型。如果源文件使用的类型不同，可能需要进行转换。以下所有选项均适用于转换后的结果。
格式 数据类型转换中使用的格式或转换掩码
长度 输出数据类型的最大字符数，或-1表示无限制。
精度 用于显示浮点数的小数位数。
货币 货币值要显示的货币符号。
小数 数字使用的小数点符号。通常是”.”（10.5）或”,“（10,5）。
分组 数字使用的千位分隔符符号。通常是”,“（5,200,820）或”.”（5.200.820）。
修剪类型 用于从字符串值中删除空白字符的修剪方法。可以是左（删除前导空格）、右（删除尾随空格）、两者（前后空格都删除）或无（不删除）。
重复 如果列值为空（null），则重复上一行的列值

附加输出字段标签

选项 描述
短文件名字段 用于包含文件名（不包含路径）的字段。
扩展名字段 用于包含文件扩展名的字段。
路径字段 用于包含文件路径的字段。
大小字段 用于包含文件大小的字段。
是否隐藏字段 用于包含文件是否隐藏的字段。
最后修改字段 用于包含文件最后修改日期的字段。
Uri字段 用于包含文件完整源URL的字段。根据文件的来源，这可能是http:// 或file:// URL。
根Uri字段 用于包含文件源URL的根，包括协议和顶级地址的字段。
