字符串替换

描述

“字符串替换”转换操作会对字符串字段执行简单的搜索和替换操作。它还支持正则表达式和组引用。在替换字符串中，组引用以 $n 的形式表示，其中 n 是组的编号。你还可以使用十六进制替换特殊字符。

选项

选项 描述
转换名称 转换的名称。在一个插件中，此名称必须唯一。
输入流字段 需要进行替换操作的字段。
输出流字段 结果字段。如果你将”输出流字段”留空，它将替换”输入流字段”中的值。否则，替换后的值将输出到一个新字段中。
使用正则表达式 指定是否使用正则表达式来指定要替换的值。此值必须为 Y 或 N。
搜索 搜索特定模式。你可以使用通配符 (*) 匹配多个字符。如果你使用正则表达式，请在此字段中指定模式。
替换为 指定用于替换搜索模式的值。如果你使用正则表达式，请在此处指定字符串的替换部分。
设置为空字符串？ 指定是否将字段值替换为空字符串。此值必须为 Y 或 N。
用字段替换 用你指定的字段值替换搜索模式。
全字匹配 指定是否必须全字匹配搜索模式才能进行替换。此值必须为 Y 或 N。
区分大小写 指定搜索是否区分大小写。此值必须为 Y 或 N。
是否为 Unicode 指定搜索是否使用 Unicode 编码。此值必须为 Y 或 N。

示例

你可以按如下方式解析字符串的各个部分

  • 正则表达式 = ^([0-9]{4})([0-9]{7})$

  • 替换为 = $2

这将把任何 11 位数字替换为最后 7 位数字。
