HTTP POST请求

描述

HTTP POST转换使用HTTP POST命令通过URL提交表单数据。

选项

常规标签页

常规标签页用于定义要使用的RSS/Atom URL，也可以选择指定包含这些URL的字段。

选项 描述
URL 要提交到的Web服务URL。
从字段接受URL？ 如果勾选此选项，则必须指定从哪个字段检索URL。
URL字段名称 如果勾选了上一个选项，则在此处指定URL字段。
编码 正在访问的文件的编码标准。
请求实体字段 将包含POST请求的字段名称。启用此选项后，“上传文件”选项将检索此字段中指定名称的文件，并提交该文件的内容。
上传文件 如果在”请求实体字段”中定义了一个文件，并且勾选了此选项，则将上传该文件的内容。目前，为了使”上传文件”功能生效，必须填写”请求实体字段”。如果选择了”上传文件”并在”正文参数”下指定了一个字段，但没有为”请求实体字段”（文件名所在位置）选择一个值，操作将悄然失败。
使用多部分上传 这将以多部分请求的形式将数据发送到服务器，在上传文件时此功能很有用。
连接超时 定义连接尝试出错时的超时时间（默认值为10000），单位为毫秒。
套接字超时 定义套接字出错时的超时时间（默认值为10000），单位为毫秒。
连接关闭等待时间 定义连接关闭后的等待时间，单位为毫秒。默认值-1表示使用操作系统的默认等待时间（通常为2分钟）。背景信息：每一行都会打开一个连接，并在所谓的TIME-WAIT状态下保持特定的时间。大量（可能数千个）处于TIME-WAIT状态的连接会带来显著的内存开销。此选项可以通过减少将关闭的连接保持在TIME-WAIT状态的时间来减少这种内存开销。
结果字段名称 要将结果输出发布到的字段。
HTTP状态码字段名称 要将状态码输出发布到的字段。
响应时间（毫秒）字段名称 要将响应时间（以毫秒为单位）发布到的字段。
HTTP登录名 如果此表单需要身份验证，此字段应包含用户名。
HTTP密码 如果此表单需要身份验证，此字段应包含与用户名对应的密码。
代理主机 如果使用代理服务器，则为代理服务器的主机名或IP地址。
代理端口 如果使用代理服务器，则为代理服务器的端口号。

字段标签页：正文（头部）参数

字段标签页用于定义HTTP请求头部和正文的参数。如果已在常规标签页中填写了URL和其他必要详细信息，则可以使用”获取值”按钮在此处预先填充字段。正文参数用于POST和PUT操作。

选项 描述
# 此参数传递给Web应用程序的顺序。
名称 包含要映射到参数的值的字段名称。
参数 要将”名称”的值映射到的参数。
放入头部？ 如果设置为Y，则该参数将放入请求头部。

字段标签页：查询参数

字段标签页用于定义HTTP请求头部和正文的参数。如果已在常规标签页中填写了URL和其他必要详细信息，则可以使用”获取值”按钮在此处预先填充字段。查询参数在URL中指定，可用于任何HTTP方法。

选项 描述
# 此参数传递给Web应用程序的顺序。
名称 包含要映射到参数的值的字段名称。
值 要映射到参数的值。
