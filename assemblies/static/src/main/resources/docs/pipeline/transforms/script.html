脚本

描述

“脚本”转换允许您使用JSR - 223标准支持的任何语言编写代码。默认情况下，Hfxt项目附带以下语言支持：

选项

选项 描述
转换名称 此转换的名称，该名称在单个管道中必须唯一。
脚本引擎 您可以从下拉列表中选择任何检测到的JSR - 223脚本引擎。
脚本

您可以添加一个或多个脚 本。有不同类型的脚本，您可以通过右键单击脚本标签来更改。

转换 ：每行读取后将执行该脚本。 开始 ：在转换开始时将执行一次该脚本。 结束 ：读取最后一行后将执行该脚本
字段 在 此处，您可以指定每行之后从转换脚本的上下文中检索的字段。

变量绑定

为了让您能够处理输入字段值或周围的Java生态系统，Hfxt公开了一系列变量绑定。

变量 描述
input 所有输入字段都以其自身名称存在 。请注意，某些脚本语言对变量的允许名称有限制。 请确保使用”选择值”转换重命名不合适的字段名称。
transform 这是对父转换类 Script 的引用。您可以 使用此引用来记录某些重要事件或写入额外的输出行
pipeline_status

这个特殊变量可以设置为以下任何值：

CONTINUE_PIPELINE ：处理当前行并生成输出（默认值） SKIP_PIPELINE ：不写入输出行 STOP_PIPELINE ：导致管道停止处理行 ERROR_PIPELINE ：导致管道因错误而中止
rowNumber 这是当前行号，从1开始。
rowMeta 输入行元数据。它是一个值元数据列表。
row

一个对象数组，包含当前的字段值集。请确保使用 rowMeta 来访问这些值，以确保进行适当的数据转换。

例如，使用 rowMeta.getString(row, 0) 从输入行中获取第一个字符串值。
previousRow 上一行，如果 row 是第一行输入行，则为null。
transformName 转换的名称
pipelineName 管道的名称

生成行

以下是使用3种不同脚本引擎中的简单循环生成10个输出行的脚本。此操作会发生3次，输出相同。对于这3个示例，您需要定义2个输出字段：

  • id ：整数

  • name ：字符串

ECMAScript

var Long = Packages.java.lang.Long;
var RowDataUtil = Packages.org.apache.hfxt.core.row.RowDataUtil;

var START=100000;
var COUNT=10;
var END=START+COUNT;
var id=START;

for (var id=START;id<END;id++) {
  var outputRow = RowDataUtil.allocateRowData(rowMeta.size());
  outputRow[0] = new Long(id);
  outputRow[1] = " Hfxt "+id;
  transform.putRow(outputRowMeta, outputRow);
}

pipeline_status=SKIP_PIPELINE;

Groovy

def COUNT=10;

id = 100000L;
(1..COUNT).each {
 outputRow = RowDataUtil.allocateRowData(rowMeta.size());
 outputRow[0] = id;
 outputRow[1] = " Hfxt "+id
 transform.putRow(outputRowMeta, outputRow);

 id++;
}

pipeline_status=SKIP_PIPELINE;

Python

import java.lang.Long as Long

START=100000
COUNT=10
END=START+COUNT
id=START

for id in range(START,END):
    outputRow = RowDataUtil.allocateRowData(rowMeta.size())
    outputRow[0] = Long(id)
    outputRow[1] = " Hfxt "+str(id)
    transform.putRow(outputRowMeta, outputRow)

pipeline_status=SKIP_PIPELINE

聚合行

以下是对不同组的行进行聚合的脚本。数据按字段 group 排序，并包含一个 value 字段，该字段的值将累加到字段 sum 中。在开始脚本中，我们定义变量 sum = 0 和 previousGroup = ""。

对于这3个示例，您需要定义1个输出字段：

  • sum ：整数

ECMAScript

if (group!==previousGroup) {
  sum=value;
  previousGroup=group;
} else {
  sum+=value;
}

if (nextGroup==null) {
  pipeline_status=CONTINUE_PIPELINE;
} else {
  pipeline_status=SKIP_PIPELINE;
}

Groovy

if (!group.equalsIgnoreCase(previousGroup)) {
  sum=value;
  previousGroup=group;
} else {
  sum+=value;
}

if (nextGroup==null) {
  pipeline_status=CONTINUE_PIPELINE;
} else {
  pipeline_status=SKIP_PIPELINE;
}

Python

if group!=previousGroup:
  sum=value
  previousGroup=group
else:
  sum=sum+value

if nextGroup is None:
  pipeline_status=CONTINUE_PIPELINE
else:
  pipeline_status=SKIP_PIPELINE;

添加脚本语言

您可以通过将所需的库添加到 plugins/transforms/script/lib 文件夹中来添加其他脚本语言。

例如，要添加对Ruby脚本语言的支持，您需要添加以下 JRuby库：

  • jruby-stdlib-<version>.jar

  • jruby-core-<version>.jar

要添加Javascript支持，请下载 Nashorn Core jar

  • nashorn-core-15.4.jar

重新启动 Hfxt GUI后，您会注意到”脚本引擎”下拉框中有一个 ruby 或 Javascript 条目。
