详细输出

启用详细输出。

高IO

true

忽略基于环境的启发式方法，并指定目标存储子系统是否能够支持高吞吐量的并行IO。

通常对于固态硬盘、大型RAID阵列和网络附属存储，此选项为true。

在堆上缓存？

false

确定是否允许在堆上为缓存分配内存。

如果为false，则缓存仍将在堆外分配，但JVM内的额外可用内存将不会分配给缓存。

使用此选项可更好地控制堆内存。

忽略空字符串

false

确定是否忽略输入源中的空字符串字段，如 ""（视为null）。

忽略额外列？

false

确定在导入期间是否应忽略未指定的列。

传统样式引用？

false

确定是否将反斜杠转义的引号（例如 \"）解释为内部引号。

字段可以有多行数据？

false

确定输入源中的字段是否可以跨多行，即包含换行符。

设置 --multiline-fields=true 可能会严重降低导入器的性能。因此，请谨慎使用，尤其是在进行大型导入时。

规范化类型？

false

确定是否将属性类型规范化为Cypher类型，例如int变为long，float变为double。

导入期间跳过记录不良条目？

确定在导入期间是否跳过记录检测到的不良条目。

跳过不良关系？

false

确定是否跳过导入引用缺失节点ID的关系，即起始或结束节点ID/组引用的节点未在节点输入数据中指定。

跳过的关系将被记录，最多包含 --bad-tolerance 指定的实体数量，除非 --skip-bad-entries-logging 选项另有指定。

跳过重复节点？

false

确定是否跳过导入具有相同ID/组的节点。

如果同一组中有多个节点具有相同的ID，则将导入第一个遇到的节点，而后续遇到的此类节点将被跳过。

跳过的节点将被记录，最多包含 --bad-tolerance 指定的实体数量，除非 --skip-bad-entries-logging 选项另有指定。

修剪字符串？

false

确定是否应修剪字符串中的空白字符。

不良容限

1000

在导入被视为失败之前的不良条目数量。

此容限阈值主要适用于引用缺失节点的关系。输入数据中的格式错误仍将被视为错误。

最大内存

false

neo4j-admin可用于各种数据结构和缓存以提高性能的最大内存。

值可以是普通数字，如10000000，或20G表示20千兆字节。也可以指定为可用内存的百分比，例如70%。

读取缓冲区大小

4M

读取输入数据的每个缓冲区的大小。

它必须至少足够大，以容纳输入数据中的最大单个值。值可以是普通数字或字节单位字符串，例如128k、1m。
