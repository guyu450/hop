HTTP客户端

描述

HTTP客户端转换会使用附加选项对基础URL执行简单调用。格式为http://?param1=value1&param2=value2&param3... 结果会存储在指定名称的字符串字段中。

选项

选项 描述
转换名称 转换的名称；此名称在单个管道中必须唯一
URL 基础URL字符串
从字段接受URL？ 如果要从上一个转换获取URL，请启用此选项。启用此选项还可以指定输入字段的名称。
URL字段名称 包含URL的传入字段的名称
连接超时
套接字超时 如果服务器未返回数据，等待的秒数。
连接关闭等待时间
结果字段名称 存储结果的字段的名称
HTTP状态码字段名称 存储HTTP响应代码（例如200、404）的字段的名称
响应时间（毫秒）字段名称 存储响应时间的字段的名称
HTTP登录名 在HTTP（基本）身份验证期间传递的用户名
HTTP密码 在HTTP（基本）身份验证期间传递的密码
代理主机 要使用的代理服务器的主机名
代理端口 要使用的代理服务器的端口号
参数 在此区域定义要在URL上传递的参数名称-值对
自定义HTTP头 在此区域定义可选的HTTP头

常见问题解答

HTTP客户端转换没有任何作用

问：HTTP客户端转换没有任何作用，我该如何使其工作？

答：HTTP客户端转换需要被触发。使用行生成器转换生成例如1个空行，并通过跳转将其与HTTP客户端转换链接起来。

HTTP客户端转换与SOAP

问：HTTP客户端支持SOAP吗？

答：不支持，它只是使用参数调用一个URL。未来的转换可能会提供SOAP功能，目前正在开发支持WSDL的Web服务转换。
