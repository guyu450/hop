写入日志

描述

“写入日志”转换将信息写入Hfxt日志系统。典型的用例是将特定值或自定义日志消息记录到Hfxt日志中。

用法

向Hfxt日志系统写入变量或字段中的（未加密）密码或其他敏感信息时要小心！

如果在”写入日志字段”列表中未添加任何字段，并且指定了”基本”日志级别，它将把所有字段写入日志。如果在字段列表中添加了字段，它将只打印那些字段。参数和变量必须在”日志消息”部分指定。

必须设置日志级别。如果希望打印变量，请将日志详细级别设置为”基本”。

在”日志消息”部分打印参数或变量的示例： 计数器：${myCounter}

如果不存在包含字段的数据行，记录字段、参数或变量将不起作用。您可以使用”生成行”转换来创建一个虚拟行，以便打印变量或参数。

如果错误导致无法将任何内容写入日志，您可以禁用失败的Hfxt，在失败之前添加日志记录，然后重新运行。

选项

选项 描述
转换名称 此转换的名称，在单个管道中必须唯一。
日志级别 要使用的日志级别。
打印标题 是否打印数据值的列名。在下面的示例中，此值设置为false，因此只打印实际值（3, 4）。
限制行数 通过参数”要打印的行数”限制行数。
要打印的行数 当选中”限制行数”选项时要打印的行数。
写入日志 日志行中要使用的文本。
字段 应写入日志的字段数据。
