添加XML

描述

“添加XML”转换允许您将一行中多个字段的内容编码为XML。此XML以字符串字段的形式添加到该行中。

选项

内容选项卡

选项 描述
转换名称 转换的名称。
编码 要使用的编码；此编码在XML文件的头部指定
输出值 包含XML的新字段的名称
根XML元素 生成元素中的根元素名称
省略XML头部 启用此选项可在输出中不包含XML头部。
从XML结果中省略空值 不添加具有空值的元素或属性。这通常用于限制目标XML的大小。

字段选项卡

“字段”选项卡用于配置输出字段及其格式。下表描述了字段的每个可用属性。

选项 描述
字段名称 字段的名称
元素名称 XML文件中要使用的元素名称
类型 字段类型可以是字符串、日期或数字
格式 选择要应用于字段值的日期或数字格式
长度 如果指定了此长度，则输出字符串将填充到此长度
精度 用于显示浮点数的小数位数。
货币符号 用于表示货币的符号，如$10,000.00或€5,000.00
小数点 用于表示浮点数中小数点的符号，通常是”.”（10.75）或”,“（5,25）
分组符号 用于表示千位分隔符的符号，通常是”,“（10,000.00）或”.”（5.000,00）
空值 字段值为空时要使用的字符串。
属性 如果为”是”，则使此字段成为一个属性。否则，使其成为一个元素。
属性父元素名称 如果上一个参数”属性”设置为”是”，则可以指定要添加属性的父元素名称。如果未指定父元素名称，则将属性设置在父元素中。
