波束窗口

描述

波束窗口转换使用波束执行引擎添加基于事件时间的窗口函数。

选项

选项 描述
转换名称 转换的名 称，此名称在单个管道中必须唯一。
窗口类型

  • 固定

  • 滑动

  • 会话

  • 全局
窗口大小（以秒为单位的持续时间） 设置窗口持续时间的 大小（以秒为单位），默认值为60。
每x秒（滑动窗口） 设置滑 动窗口的持续时间（以秒为单位）。
窗口开始字段 包含窗口开始时间的字段。
窗口结束字段 包含窗口结束时间的字段。
窗口最大字段 包含事件之间最大持续时间的字段。

窗口类型

固定

固定或滚动窗口用于将数据重复分割成不同的时间段，且不重叠。事件不能属于多个窗口。

滑动

滑动窗口仅在事件发生时产生输出，并持续向前移动。每个窗口至少会有一个事件，并且可以重叠。事件可以属于多个窗口。

会话

会话窗口将到达时间相近的事件分组，并过滤掉没有数据的时间段。

窗口在第一个事件发生时开始，并扩展到在指定的超时时间内包含新事件。如果事件持续发生，窗口将持续扩展，直到达到最大持续时间。

全局

全局窗口化是波束中的默认设置，它忽略事件时间（跨越所有事件时间），并使用触发器提供该窗口的快照。
