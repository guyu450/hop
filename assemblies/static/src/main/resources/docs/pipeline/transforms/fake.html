虚假数据

描述

虚假数据转换功能允许您使用Java Faker库（文档）生成虚假数据。它可用于为开发、测试或展示项目生成美观的数据。例如，我们可以生成一些随机的宝可梦数据。

选项

选项 描述
转换名称 转换的名称。
区域设置 区域设置可用于使生成的数据更特定于某个单一地点。
输出字段名称 生成字段的名称。
虚假数据类型 数据类别。
生成主题 在数据类别内要生成的主题。
