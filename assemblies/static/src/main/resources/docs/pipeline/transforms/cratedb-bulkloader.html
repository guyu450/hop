CrateDB批量加载器

描述

CrateDB批量加载器转换通过两种不同的方法将数据从 Hfxt加载到CrateDB：

常规选项

选项 描述
转换名称 转换的名称。
目标模式 写入数据的目标模式名称。这是一个必填字段，因为CrateDB需要知道要写入哪个默认模式（在CrateDB中，doc和blob是默认模式）。
目标表 写入数据的目标表名称。

主要选项

选项 描述
连接 目标表所在的数据库连接名称。
使用HTTP端点 选择将数据加载 到CrateDB的模式。支持的选项有HTTP端点和COPY； 当选择HTTP端点时，COPY选项将被禁用，反之亦然。
批量大小 HTTP模式以批量写入方式工作。由于没有 默认值，因此必须设置单次批量发送到CrateDB的行数。
指定数据库字段 指定数据库和流字段的映射
流到文件 在执行COPY加 载之前，将当前管道流写入本地文件系统或S3中的文件。
本地文件夹

存储将由COPY命令使用的文件的本地文件夹。

根据文档，Crat eDB从其节点文件系统（方案file://）检索文件。然而 ，在大多数情况下，Hfxt在与CrateDB不同的机器上执行 ，因此在这种情况下最常用的解决方案是例如通过卷将远 程文件夹（CrateDB）与本地文件夹（Hfxt）进行映射。

在本地文件夹字 段中，您可以指定将写入文件的本地文件夹。文件将写入 与远程文件系统链接的本地文件系统（例如Docker卷）。

在其他情况下（即：写入S3），则留空。
从文件读取 不要流化当 前管道的内容，而是从本地文件系统或S3中预先存在的文 件执行COPY加载。支持的格式是CSV（逗号分隔）。

AWS认证

选项 描述
使用AWS系统变量 选中后，将从操作系统的环境变量中获取AWS_ACCESS_KEY_ID和AWS_SECRET_ACCESS_KEY的值。
AWS_ACCESS_KEY_ID （如果未选中使用AWS系统变量）为您的AWS_ACCESS_KEY_ID指定一个值或变量。
AWS_SECRET_ACCESS_KEY （如果未选中使用AWS系统变量）为您的AWS_SECRET_ACCESS_KEY指定一个值或变量。

HTTP认证

目前，Hfxt仅支持基本和Bearer认证方法。

选项 描述
HTTP登录名 输入HTTP认证的用户名
HTTP密码 输入HTTP认证的密码

字段

将当前流字段映射到CrateDB表的列。
