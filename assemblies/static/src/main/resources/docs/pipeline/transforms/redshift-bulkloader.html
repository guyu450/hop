Redshift批量加载器

描述

Redshift批量加载器转换使用COPY命令将数据从 Hfxt加载到AWS Redshift。

常规选项

选项 描述
转换名称 转换的名称。
连接 目标表所在的数据库连接名称。
目标模式 写入数据的目标模式名称。
目标表 写入数据的目标表名称。
AWS身份验证

选择与COPY命令一起使用的身份验 证方法。支持的选项有”AWS凭证”和”IAM角色”。

  • 查看基于密钥的访问控制（基于密钥的 访问控制），了解有关”凭证”选项的更多信息。

  • 查看IAM角色文档（I AM角色），了解有关”IAM角色”选项的更多信息。
使用AWS系统变量 （仅”凭证”！）从操作系统的环境变量中获取AWS _ACCESS_KEY_ID和AWS_SECRET_ACCESS_KEY的值。
AWS_ACCESS_KEY_ID （如果选择”凭证”且未选中”使用AWS系统变 量”）为AWS_ACCESS_KEY_ID指定一个值或变量。
AWS_SECRET_ACCESS_KEY （如果选择”凭证”且未选中”使用AWS系统变量” ）为AWS_SECRET_ACCESS_KEY指定一个值或变量。
IAM角色 （如果选 择”IAM角色”）指定要使用的IAM角色，语法为ar n:aws:iam::<aws-账户ID>:role/<角色名称>
截断表 在加载数据之前截断目标表。
在第一行数据时截断 在加载 数据之前截断目标表，但仅在接收到第一行数据 时进行（当管道运行空流（0行）时不会截断）。
指定数据库字段 指定数据库和流字段的映射

主要选项

选项 描述
将流写入S3 CSV 在执行COPY加载之前，将当前管道流写入S3存储桶中的CSV文件。
从现有文件加载 不流式传输当前管道的内容，而是从S3中的现有文件执行COPY加载。支持的格式有”CSV”（逗号分隔）和”Parquet”。
从现有文件复制到Redshift 要从其COPY加载数据的S3文件路径。

数据库字段

将当前流字段映射到Redshift表的列。
