Neo4j输出

描述

Neo4j输出转换功能允许您在一个节点、两个节点或两个节点及它们之间的关系上进行高性能更新。该转换功能会生成所需的Cypher语句以及相应的参数。

用法

您可以更新一个节点，或者两个节点及其关系。节点和关系可以有属性，并且会根据您提供的信息生成相应的MERGE语句。利用对话框右侧的”获取字段”按钮，可避免您输入过多内容。

标签

您可以从字段列表中获取一个节点的标签，也可以使用静态值（可选择包含变量）。如果您同时指定了这两种方式，当字段值为空时将使用静态值。如果标签为空或空白，则该节点不会使用该标签。

显著选项

选项 描述
批处理大小 为提高性能，该转换功能会将记录分组到单个事务中
使用CREATE而非MERGE 这将绕过任何查找操作，速度更快。
创建索引 为节点中的所有主属性创建唯一字段约束，以确保在处理合并操作以及查找关系中的节点时性能良好。 注意： 请仅在进行原型设计和测试时考虑使用此功能。最好将索引创建语句明确放在Cypher脚本操作中，以确保即使迁移到新数据库也不会忘记创建索引。
