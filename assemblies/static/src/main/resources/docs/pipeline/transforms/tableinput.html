表输入

描述

表输入转换用于使用连接和SQL查询从关系数据库中读取信息。SQL查询可以通过变量进行参数化，并可以接受来自先前转换字段的输入。

从单个表中获取所有列

通过点击 获取SQL选择语句 按钮，可以自动生成基本的SQL语句。

数据库资源管理器将打开，让您直接从可用数据库模式列表中选择一个表。

视图可以作为视图或表显示并选择。有关更多详细信息，请查看您的数据库和JDBC驱动程序文档。

选择表后，一个新的弹出对话框将询问您要生成哪种SQL语句：

  • 单独选择所有列，例如 select col_a, col_b, col_c from my_table;

  • 使用SQL通配符选择所有列，例如 select * from my_table;

接受来自先前字段的输入

表输入转换可以接受在 从转换插入数据 选项中指定的先前转换的字段。

如果选择了一个转换，此转换中的SQL查询将被指定为一个 JDBC预编译语句。

请注意，除了允许参数化之外，预编译语句最重要的优点是它们有助于防止SQL注入攻击。副作用是，并非SQL查询中的所有元素都可以通过预编译语句进行参数化。

在SQL查询中使用 ? 来用输入转换提供的值替换参数。这些值将按照输入转换提供的顺序使用。使用 选择值 转换来修改输入流，以便以正确的顺序为 表输入 转换提供正确的字段。

? 选项不能用于为SQL IN 子句指定值。

预编译语句 ? 参数可以与下面描述的 在SQL语句中使用变量 结合使用。

示例

使用数据行字段参数化查询的示例：

Select * from table1 where NameId = ? and AddressId = ?

  • 替换脚本中的变量：未选中

  • 从转换插入数据：<指向包含字段的转换>

使用日期范围的示例：

SELECT * FROM customers WHERE changed_date BETWEEN ? AND ?

此SQL语句请求两个日历日期以创建一个范围，这些日期从 从转换插入数据 选项中读取。可以使用 获取系统信息 转换提供目标日期范围。例如，如果您想读取所有数据在昨天发生更改的客户，可以获取昨天的目标范围并读取客户数据。

在SQL语句中使用变量

“表输入” 转换中的SQL查询可以通过使用变量进行参数化。

要在查询中启用变量替换，请选中 替换脚本中的变量 复选框。

此选项将在将查询发送到数据库之前，用变量值替换SQL语句中的变量。请确保为查询语句应用正确的引号，例如 select '${variable value}' as free_text_col, col_a, col_b from my_table。

查询变量语句让您完全控制发送到数据库的SQL语句，但不像上面描述的 接受来自先前字段的输入 选项那样防止SQL注入。

在SQL语句中使用变量 可以与上面描述的预编译语句 ? 参数结合使用。

示例

使用变量值参数化查询的示例：

此示例使用一个整数。如果您使用的是字符串，很可能需要使用语法 ${PRM_NAME}

Select * from table1 where id = ${myId}

  • 替换脚本中的变量：选中

  • 从转换插入数据：<空>

专业提示

表输入转换不会将输入数据传递到输出，只有查询中的字段会返回到管道中，因此所有其他变量和数据都将丢失。您可以通过在查询中添加变量作为字段来解决此问题，或者在表输入之后放置一个 获取变量 转换。
如果您得到意外的查询结果，请使用清除数据库缓存图标（扫帚），或者您可以使用Hfxt菜单图标：工具 / 清除数据库缓存。此外，点击确定，保存管道，关闭并重新打开管道。
笛卡尔连接转换将组合来自多个表输入的不同数量的字段，而无需键连接字段。
使用 “从转换插入数据” 下拉菜单将阻塞，直到所选转换完成。

选项

选项 描述
转换名称 转换的名称。
连接 从中读取数据的数据库连接
SQL 用于从数据库连接读取信息的SQL语句。您也可以点击 “获取SQL选择语句…” 来浏览表并自动生成基本的选择语句。
替换脚本中的变量？ 启用以替换脚本中的变量；提供此功能是为了让您可以测试是否执行变量替换。
从转换插入数据 指定Hfxt期望信息来自的输入转换名称。然后，此信息可以插入到SQL语句中。Hfxt插入信息的位置用问号：? 表示。
为每行执行？ 启用可为每一行执行数据插入。
限制大小 设置从数据库读取的行数；零 (0) 表示读取所有行。
