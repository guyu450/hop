AWS SQS读取器

描述

AWS SQS读取器转换功能使您能够在 Hfxt管道内从亚马逊网络服务简单队列服务接收消息。

前提条件

在首次执行之前，您需要创建一个IAM角色（例如用于EC2/ECS）或一个带有AWS密钥和机密的IAM用户，并附加通过SNS推送通知所需的策略。

您还需要创建一个或多个要推送消息的订阅主题。

选项

AWS设置选项卡

选项 描述
使用AWS凭证链 Hfxt尝试从主机环境中获取AWS凭证。有关更多信息，请查看 凭证 文档。
AWS访问密钥 您的AWS访问密钥（AWS_ACCESS_KEY_ID）
AWS秘密访问密钥 您的AWS访问密钥的秘密（AWS_SECRET_ACCESS_KEY）
AWS区域 服务运行所在的AWS区域。
SQS队列URL SQS队列的URL（以https://开头 - 不是ARN！）

输出定义

在”输出定义”选项卡上，您可以定义从SQS消息读取的信息的输出字段，以及接收消息的一些初始设置。

输出设置

选项 描述
删除消息 接收后是否从队列中删除消息？
最大检索消息数 达到此最大消息数后结束。零（0）将接收队列中的所有消息。

输出设置

选项 描述
消息ID 从SQS为每个消息检索一个唯一ID。可以将其写入此处定义的输出字段。
消息正文 消息的完整内容。
接收句柄 接收消息的唯一标识符。
MD5哈希 消息正文的MD5哈希值
来自SNS的消息节点 如果消息是从SNS发送的，此字段将包含消息正文中JSON节点”Message”的内容。
