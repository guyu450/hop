工作流执行器

描述

工作流执行器转换可在管道内执行一个Hfxt工作流。

用法

默认情况下，指定的工作流将为每一行输入数据执行一次（可在”行分组”选项卡中更改此设置）。

数据行中的字段可用于设置参数和变量，并以结果行的形式传递给工作流。请记住，每个管道或工作流中必须至少定义一次所有参数（编辑管道/工作流属性）。当您从”参数”选项卡向工作流执行器发送字段/参数/变量时，就是在传递参数。

您还可以根据某个字段的值（当该值发生变化时执行工作流）或时间来传递一组记录。在这些情况下，组中的第一行或多行将用于设置工作流中的参数或变量。

可以启动此转换的多个副本，以促进并行工作流处理。

另请参阅：

  • 工作流操作，它可从一个工作流中执行一个子工作流。

  • 管道操作，它可从一个工作流中执行一个管道。

  • 管道执行器转换，它可从一个管道中执行一个子管道。

  • Hfxt中的循环操作指南。

示例（示例项目）

  • loops/workflow-executor.hpl

常规

选项 描述
转换名称 转换的名称。

参数选项卡

在此选项卡中，您可以指定使用哪个字段来设置某个参数或变量值。如果您指定了一个输入字段，则不会使用静态输入值。如果将多行数据传递给工作流，则将使用第一行来设置参数或变量。

该选项卡的右下角有一个按钮，可插入指定工作流的所有已定义参数。为提供信息，参数的描述将插入到静态输入值字段中。

如果您保持选中”从管道继承所有变量”选项（默认情况下是选中的），则当前管道中定义的所有变量都将传递给子工作流。

该选项卡右下角的”获取参数”按钮将插入指定工作流的所有已定义参数及其描述。

该选项卡右下角的”映射参数”按钮可让您将当前管道中的字段映射到子工作流中的参数。

行分组选项卡

在此选项卡中，您可以指定以结果行的形式传递给工作流的输入行数。

使用以下方法之一指定如何对结果行进行分组：

  • 特定的行数。

  • 特定的字段。

  • 指定的时间段。

您可以在管道或工作流操作中使用结果行，也可以通过在管道中使用”从结果中获取行”操作直接检索记录。

要访问”用于分组行的字段”或”收集行时的持续时间”选项，请删除”发送到管道的行数”选项中的默认值（1）。

选项 描述
发送到管道的行数 指定一个数字。每处理完 n 行数据后，将执行工作流，并将这 n 行数据传递给管道。默认值：1
用于分组行的字段 指定一个用于分组行的字段。只要字段值保持不变，行就会累积在一个组中。如果值发生变化，将执行工作流，并将累积的行传递给工作流。
收集行时的持续时间 以毫秒为单位指定一个持续时间。这是转换在执行工作流之前累积行所花费的时间。

请注意，您只能指定一种分组方法。

结果行选项卡

在”结果行”选项卡中，您可以指定此工作流预期结果行的布局，以及执行后将它们发送到哪个转换。

工作流执行器会对我们在此选项卡中声明的作为要接收输出的字段进行一致性检查。检查将通过确保我们要求的字段确实存在于结果流中，并且每个字段的类型确实是我们预期的类型来进行。如果有任何差异，将抛出一个错误。该错误将为您提供有关哪些字段缺失和/或哪些字段声明的数据类型错误的完整信息。
