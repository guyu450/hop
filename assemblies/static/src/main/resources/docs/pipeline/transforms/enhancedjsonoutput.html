增强的JSON输出

描述

增强的JSON输出转换功能允许您根据输入的转换值生成JSON块。根据转换设置，输出的JSON将以Javascript数组或Javascript对象的形式提供。

选项

常规选项卡

常规选项卡用于指定转换操作的类型、输出JSON结构以及转换输出文件。此文件将用于转储所有生成的JSON。

选项 描述
转换名称 转换的名称；此名称在单个管道中必须唯一。
操作

指定转换操作类型。目前有3种操作类型可用：

  1. 输出值 -

仅将输出JSON作为转换输出字段传递，不转储到输出文件

  1. 写入文件 - 仅写入文件，不传递到输出字段

  2. 输出值并写入文件 - 转储到文件并将生成的JSON作为转换输出文件传递
JSON块名称 此值将用作JSON块的名称。可以 为空字符串，这将影响输出JSON结构，详细说明见下文。
输出值 此值将用作转换 输出字段。根据转换设置，它将包含生成的JSON输出块。
强制JSON为数组 如果 选中，JSON输出将被强制设置为一个内容为数组的单项。
强制单个分组项 分组值 将存储在JSON内部的数组中，而不是创建一个JSON数组。
美化打印JSON 如果选中，JSON输出将进行美化打印。

输出文件

选项 描述
文件名 输出文件的完整路径
追加 如果未选中 - 每次运行转换时都会创建一个新文件。如果具有指定名称的文件已存在，它将被新文件替换。如果选中 - 新的JSON输出将追加到现有文件的末尾。或者，如果文件不存在，将像之前的情况一样创建文件。
每n行拆分JSON 如果此数字N大于零，将生成的JSON文件拆分为多个部分，每个部分包含N行。
创建父文件夹 通常文件名包含一些路径文件夹作为父文件夹。如果父文件夹不存在且选中此选项，将创建父文件夹作为新文件夹。否则 - 文件将找不到，转换将失败。
启动时不打开/创建 如果未选中 - 文件（在某些情况下还有父文件夹）将在管道初始化期间创建/打开以进行写入。如果选中 - 文件和父文件夹将仅在转换获取任何第一个输入数据后创建。
扩展名 输出文件的扩展名。默认值为'js'
编码 输出文件的编码
文件名中包含日期？ 如果选中 - 输出文件名将包含文件名值 + 当前日期。这可能有助于生成唯一的输出文件。
文件名中包含时间 如果选中 - 输出文件名将包含文件创建时间。与”文件名中包含日期”选项相同
显示文件名按钮 这对于测试完整的输出文件路径可能很有用
将文件添加到结果文件名？ 如果选中 - 创建的输出文件路径将可从转换结果中访问

分组键选项卡

此选项卡用于映射输入转换字段键，以正确生成输出JSON值。

选项 描述
字段名 输入转换字段名称，将有助于定义输入转换字段键。使用”获取字段”按钮发现可用的输入字段。
元素名称 JSON元素名称。例如”A”：“B” - A是元素名称，B是为此元素名称映射的实际输入值。

字段选项卡

此选项卡用于将输入转换字段映射到输出JSON值。

选项 描述
字段名 输入转换字段名称。使用”获取字段”按钮发现可用的输入字段。
元素名称 作为键的JSON元素名称。例如”A”：“B” - A是元素名称，B是为此元素名称映射的实际输入值。
JSON片段 如果该值设置为Y，则该字段中包含的值是一个JSON块，并将相应地进行处理。
移除元素名称 如果该值设置为Y，它将忽略元素名称，并在不包装的情况下插入JSON片段。仅在JSON片段 = Y时有效。
空白时移除 如果该值设置为Y且传入字段中的值为null，则相关属性将从JSON输出中省略。
