数据库连接

描述

数据库连接转换允许您使用从先前转换中获取的数据对数据库运行查询。

转换属性对话框中的数据网格。这使您可以选择从源跃点传入的数据。在SQL查询中用问号（?）表示。当转换运行时，这些问号将被数据网格中定义的字段传入的数据替换。问号将按照数据网格中定义的顺序被替换。例如，数据库连接允许您运行查询，查找购买特定产品的最年长者，如下所示：

数据库连接转换比标准的 数据库查找 转换为您提供了更大的灵活性。请记住，您的查询决定了此转换的性能。 
SELECT      customernr
FROM        product_orders, customer
WHERE       orders.customernr = customer.customernr
AND         orders.productnr =?
ORDER BY    customer.date_of_birth

选项

选项

描述

转换名称

转换的名称；此名称在单个管道中必须是唯一的

连接

用于查询的数据库连接。

启用缓存？

启用数据库查找的缓存。这意味着一旦查找了一个键（或一组键），查找的值将被存储，并且下次查找此键（或一组键）时将再次返回（无需承担数据库调用的成本）。

重要：如果其他进程正在更改您执行查找的表中的值，请不要缓存值。在所有其他情况下，缓存值会显著提高性能，因为数据库查找相对较慢。如果您无法使用缓存，可以考虑同时启动多个副本。同时启动通过不同的连接使数据库保持繁忙。请参阅启动转换的多个副本。

缓存行数

缓存的大小（行数），0表示缓存所有内容。

SQL

用于形成连接的SQL查询；使用问号作为参数占位符

返回的行数

零（0）返回所有行；任何其他数字限制返回的行数。

外连接？

启用此选项可始终返回结果，即使查询未返回结果

参数字段表

指定包含参数的字段。参数类型是必需的。
