合并行

描述

合并行（笛卡尔积）转换允许您在不基于键进行连接的情况下组合/合并多个输入流（笛卡尔积）。它在每个流只有一行数据时效果最佳。您可以添加一个条件，以便仅在满足条件时进行合并。

选项

选项 描述
转换名称 此转换的名称，该名称在单个管道中必须唯一。
临时目录 如果您要合并的行数超过缓存数量，请指定系统存储临时文件的目录名称。
临时文件前缀 这是将生成的临时文件的前缀。
最大缓存大小 在系统从临时文件读取数据之前要缓存的行数；当您要合并无法放入内存的大数据集时需要此选项。
主要读取的转换 指定从中读取大部分数据的转换；当来自其他转换的数据被缓存或假脱机到磁盘时，来自此转换的数据不会。
条件 您可以输入一个复杂条件来限制输出行的数量。
