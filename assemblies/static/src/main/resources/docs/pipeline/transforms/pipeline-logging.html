管道日志记录

描述

管道日志记录转换提供有关管道及其转换的详细日志记录信息。此转换从管道日志元数据项接收输入。该转换所需的配置很少，但能提供大量信息。

相关插件

  • 管道日志

选项

选项 描述
转换名称 此转换的名称
也记录转换详细信息

  • 选中：转换将输出管道和转换的日志记录及指标。 在这种情况下，日志记录将为每个转换包含一行。对 于每个转换，管道日志记录和指标信息将重复显示。

  • 未选中：转换仅输出管道日志记录和指标。

输出字段

字段名称 类型 描述
管道日志记录字段
loggingDate 日期 此管道执行的日期和时间
loggingPhase 字符串 日志记录时此管道所处的阶段（例如”结束”）
pipelineName 字符串 记录的管道名称
pipelineFilename 字符串 记录的管道文件名
pipelineStart 日期 记录的管道执行开始日期
pipelineEnd 日期 记录的管道执行结束日期
pipelineLogChannelId 字符串 记录的管道的日志记录通道ID
parentLogChannelId 字符串 记录的管道的父日志记录通道ID（例如父工作流的通道ID）
pipelineLogging 字符串 记录的管道的完整日志记录文本
pipelineErrorCount 整数 记录的管道执行过程中发生的错误数量
pipelineStatusDescription 字符串 记录的管道的状态描述（例如”已完成”）
转换日志记录字段
transformName 字符串 记录的管道中的转换名称
transformCopyNr 整数 当前转换的副本编号
transformStatusDescription 字符串 当前转换的状态（例如”已完成”）
transformLogChannelId 字符串 当前转换的日志记录通道ID
transformLoggingText 字符串 当前转换的日志记录文本
transformLinesRead 整数 当前转换读取的行数
transformLinesWritten 整数 当前转换写入的行数
transformLinesInput 整数 当前转换的输入行数
transformLinesOutput 整数 当前转换的输出行数
transformLinesUpdated 整数 当前转换更新的行数
transformLinesRejected 整数 当前转换拒绝的行数
transformErrors 整数 当前转换的错误数量
transformStart 日期 当前转换的开始日期和时间
transformEnd 日期 当前转换的结束日期和时间
transformDuration 整数 当前转换的总持续时间
