MySQL批量加载器

描述

MySQL批量加载器转换使用复制命令来加载数据，而不是发送单个插入语句。它将创建一个本地文件，然后使用LOAD DATA命令加载该文件。更多信息在此处

选项

在客户端连接中，服务器和客户端都必须启用批量加载。添加以下选项 allowLoadLocalInfile=true。在服务器端，以下查询应返回”ON” show global variables like 'local_infile';

常规

选项 描述
连接 批量加载时要使用的数据库连接
目标模式 （可选）包含要加载表的模式。
目标表 要加载的表的名称。
FIFO文件 临时文件位置
分隔符 用于确定字段的分隔符。
包围符 你可以指定一个包围字符串，当它放在一个值周围时，允许该值中存在分隔符。
转义字符 为了在值中包含分隔符字符，有时会使用转义字符串，如反斜杠、双反斜杠等。
字符集（加载命令） 加载命令中使用的字符集（可选）。
字符集（文件创建） 创建文件时使用的字符集（可选）。
批量大小（行数） 这将把数据加载分成多个块。
使用替换子句 使用REPLACE时，与现有行中唯一键值具有相同值的新行将替换现有行。
使用忽略子句 使用IGNORE时，与现有行在唯一键值上重复的新行将被丢弃。
本地数据 如果未指定LOCAL，则文件必须位于服务器主机上。

字段

选项 描述
表字段 表中的字段名称。
流字段 流中的字段名称。
字段格式是否正确？

你可以决定是否应保留格式（不更改格式）或更改格式：

  • 格式化为日期（yyyy-MM-dd）

  • 格式化为时间戳（yyyy-MM-dd HH:mm:ss）

  • 格式化为数字（分组符号为”,” - 小数为”.”）

  • 找到包围字符时进行转义
