数据验证器

描述

数据验证器转换允许您添加数据验证规则，这些规则可以分别验证输入行中各个字段的输入数据。如果检测到某一输入行未能通过此转换中定义的一个或多个验证规则，验证器将抛出错误（异常）。要获取所有验证错误的列表，您可以从此转换定义一个错误处理跳转。

选项

您可以使用”新建验证”按钮添加新的验证规则，使用”删除验证”按钮删除选定的验证规则。在对话框左侧选择一个验证规则后，您可以为每个数据验证指定以下属性：

选项 描述
转换名称 此转换的名称，该名称在单个管道中必须唯一。
报告所有错误，而非仅第一个错误 启用此选项后，将为每个输入行报告0个、1个或多个错误。
输出一行，用分隔符连接错误信息 如果启用此选项，错误代码和描述将用指定的分隔符字符串连接起来。
验证描述 您可以在此处选择描述要测试的内容。
要验证的字段名称 选择要验证的输入字段名称
错误代码 定义一个唯一的错误代码，以便在错误处理输出中识别问题所在。
错误描述 指定一个错误描述，以便在错误处理输出中识别问题所在。
验证数据类型 如果要进行数据类型验证，请启用此选项
数据类型 输入字段所需的数据类型
转换掩码 预期的转换掩码
小数点符号 预期的小数点符号
分组符号 预期的小数点符号
允许为空？ 如果不允许空值，请禁用此选项
仅允许空值？ 如果只期望空值，请启用此选项
仅预期数值数据 如果需要输入字段为数值类型（整数、数字、大数字）或仅包含数字（0-9）的字符串，请启用此选项
最大字符串长度 转换为字符串后输入字段的最大长度
最小字符串长度 转换为字符串后输入字段的最小长度
最大值 输入允许的最大值
最小值 输入允许的最小值
预期起始字符串 转换为字符串后，输入字段预期以此值开头
预期结束字符串 转换为字符串后，输入字段预期以此值结尾
不允许的起始字符串 转换为字符串后，输入字段不应以此值开头
不允许的结束字符串 转换为字符串后，输入字段不应以此值结尾
预期匹配的正则表达式 您可以指定一个正则表达式，输入字段的值应与之匹配
不允许匹配的正则表达式 您可以指定一个正则表达式，输入字段的值不允许与之匹配
允许的值 您可以指定此输入字段允许的可能值列表。使用右侧的”添加”和”删除”按钮编辑此列表。
从另一个转换读取允许的值 如果要从另一个转换读取输入数据，请启用此选项。
要读取的转换 从此转换读取此字段允许值的名称。
要读取的字段 从此字段读取此字段允许值的名称。
