选择值

描述

“选择值”转换对于选择、删除、重命名、更改数据类型以及配置流上字段的长度和精度非常有用。这些操作分为不同的类别：

选项

选择与更改标签页

此标签页包含用于选择和更改数据类型及字段的选项。“获取要选择的字段”按钮将根据现有的输入转换检索可用字段，并填充此标签页中的条目。

选项 描述
转换名称 转换的名称，此名称在单个管道中必须唯一
字段名 输入流中的字段名称
重命名为 字段的新名称。如果不想重命名字段，请留空
长度 如果要隐式选择输入流中在”字段”部分未明确选择的所有其他字段，请指定此值。
精度 精度选项取决于字段类型，但仅支持”数字”类型；它返回浮点数的位数
按名称排序包含未指定的字段 如果要隐式选择输入流中在”字段”部分未明确选择的所有其他字段，请启用此选项

编辑映射

“编辑映射”对话框允许您轻松定义源字段和目标字段之间的多个映射。

选项 描述
源字段 可供映射的输入字段列表。选择一个字段开始映射
目标字段 源字段可映射到的字段列表。选择源字段后，选择一个目标字段以创建映射
添加 将源字段和目标字段映射对添加到”映射”部分
删除 删除选定的映射条目

删除标签页

此标签页允许您从输入流中删除字段。点击”获取要删除的字段”以从先前的转换中导入字段。

元数据标签页

此标签页下的选项允许您重命名输入字段、将其转换为不同的数据类型，并更改其长度和精度。点击”获取要更改的字段”以从先前的转换中导入字段。

选项 描述
字段名 导入字段的名称。注意：如果您在”选择与更改”标签页中重命名字段，此处的名称必须与重命名后的值匹配。
重命名为 如果要重命名字段，在此处输入新名称
类型 此字段的数据类型
长度 字段长度
精度 精度选项取决于字段类型，但仅支持”数字”类型；它返回浮点数的位数
二进制转常规？ 在适当的时候将字符串转换为数字数据类型
格式 格式掩码（数字类型或日期格式）
日期格式宽松？ 确定日期解析器是严格还是宽松。宽松意味着将处理无效的日期值。如果设置为”N”，则仅接受严格有效的日期值；如果设置为”Y”，则解析器将尝试确定错误日期的意图（如果可能）并进行纠正。
日期区域设置 指定用于日期转换和计算的日期区域设置。留空以使用系统上的默认编码，或从填充的列表中相应选择。
日期时区 指定用于日期转换和计算的日期时区。留空以使用系统上的默认编码，或从填充的列表中相应选择。
宽松数字转换 当此选项设置为”Y”时，数字将被解析，直到找到非数字值（例如破折号或斜杠），然后停止解析而不报告错误。当设置为”N”时，数字将被严格解析，如果输入中存在无效数字，则会抛出错误。
编码 指定要使用的文本文件编码。留空以使用系统上的默认编码。要使用Unicode，请指定UTF-8或UTF-16。首次使用时，Spoon会在您的系统中搜索可用的编码，并相应地填充此列表。
小数点 小数点；可以是点或逗号
分组 在四位数或更多位数的数字中分隔千位的方法。可以是点或逗号。
货币 用于表示货币的符号
