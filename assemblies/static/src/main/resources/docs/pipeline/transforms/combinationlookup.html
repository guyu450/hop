组合查找/更新

描述

组合查找 - 更新转换允许您将信息存储在一个垃圾维度表中。该转换也可能用于维护金博尔（Kimball）纯类型1维度。此转换将…… 此转换根据具有业务键的数据创建/维护一个技术键。经过此转换后，维度表中所有剩余的数据更改都可以作为更新进行，因为业务键对应的行要么已经存在，要么已经创建。此转换仅维护键信息。您必须更新维度表中的非键信息，例如，在组合更新/查找转换之后放置一个（基于技术键的）更新转换。阿帕奇霍普（ Hfxt）将信息存储在一个表中，该表的主键是表中业务键字段的组合。由于如果字段数量众多，此过程可能会很慢，因此支持一个 “哈希码” 字段，该字段以数值形式表示维度中的所有字段。这可以显著提高查找性能，同时将索引字段限制为仅一个字段。

选项

选项 描述
转换名称 转换的名称。
连接 维度表所在的数据库连接名称。
目标模式 这允许您指定一个模式名称。
目标表 维度表的名称。
提交大小 定义提交大小，例如 ，将此设置为10将每10次插入或更新生成一次提交。
缓存行数

这是将保留在内存中的缓存行 数，通过减少与数据库的往返次数来加快查找速度。

缓存大小为0时，将尽可 能多地缓存行，直到您的JVM内存不足。对于不会增 长过大的维度，请明智地使用此选项。缓存大小为 - 1表示禁用缓存。
键字段 指定流 中和维度表中的键名称。这将使转换能够进行查找。
技术键字段 这表示维度的主键。它也被称为代理键。
技术键的创建

指定 技术键的生成方式，您的连接不可用的选项将变灰：

  • 使用表最大值 + 1：将根 据表中的最大键创建一个新的技术键。请注意，新的 最大值始终被缓存，因此无需为每一行计算最大值。

  • 使用序列 ：如果您想在表连接上使用数据库序列来生成技术键 （例如，这在Oracle中很常见），请指定序列名称。

  • 使用自动递增字段：使用数据库表中的自动 递增字段来生成技术键（例如，DB2支持此方式）。
是否移除查找字段？ 如果您想在输出中从输入流中移除所有查找字段， 请启用此选项。然后添加的唯一额外字段是技术键。
使用哈希码 此选项允许 您生成一个哈希码，以数值形式（有符号64位整数） 表示键字段中的所有值。此哈希码必须存储在表中。
最后更新日期字段 必要时，指定要 从源系统复制到数据仓库的最后更新日期字段（时间 戳）。例如，当您有一个没有主键的地址时。该字段 将不属于查找字段（也不参与哈希码计算）。该值仅 写入一次，因为任何更改都会导致写入一条新记录。
获取字段按钮 填充输入流中除您指定的键之外的所有可用字段。
SQL按钮 生成用于构建维度的SQL，并允许您执行此SQL。
