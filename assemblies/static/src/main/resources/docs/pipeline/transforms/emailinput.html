电子邮件消息输入

描述

电子邮件消息输入转换允许您使用POP3、IMAP或MBOX标准协议从邮件服务器检索消息及其附件。

选项

常规

在此选项卡上，您将找到常规邮件服务器连接设置：

选项 描述
转换名称 转换的名称。
邮件服务器连接
邮件连接 如果在此处选择了邮件服务器连接，则此选项卡的其余部分将被忽略。服务器配置将从 邮件服务器连接 元数据项中获取。
服务器设置
源主机 邮件服务器主机
使用SSL？ 如果您的服务器需要SSL连接，请选中此选项
使用XOAuth2 如果选中，将使用XOAuth2对服务器进行身份验证。
用户名 要连接的邮箱的用户名
密码 要使用的密码
使用代理？ 如果您想通过代理连接，请选中此选项。
代理用户名 用于连接代理的用户名
分批获取？ 如果您想分批检索大量邮件，请启用此选项
忽略读取字段时的错误 有时服务器不支持检索特定的信息。启用此选项可忽略这些错误。
协议 指定标准协议POP3、IMAP或MBOX来检索邮件
测试连接按钮 这将仅尝试使用指定的设置连接到邮件服务器。此按钮不会检索邮件。

设置

POP3设置

选项 描述
检索 指定”所有电子邮件”或”检索前……封电子邮件”
检索前……封电子邮件 允许您指定一次最多要检索多少封邮件

IMAP设置

选项 描述
从字段获取文件夹 启用此选项可允许IMAP文件夹名称出现在此转换的输入字段中。
文件夹字段 如果启用上述选项，则为文件夹字段。
IMAP文件夹 从中检索邮件的IMAP文件夹
测试文件夹……按钮 使用此按钮测试文件夹是否有效
打开按钮 使用此按钮选择IMAP文件夹
包括子文件夹 选中此选项还可从子文件夹中检索邮件
检索 指定要检索哪些邮件：获取所有、新的、旧的、已读、未读、已标记、未标记、草稿、非草稿、已回复或未回复的邮件。
检索前……封电子邮件 指定最多要检索多少封电子邮件

分批设置

选项 描述
分批大小 一次一批中要检索的电子邮件数量
从消息编号开始 开始检索的第一个消息编号
在消息编号结束 结束检索的最后一个消息编号

过滤器

这些是您可以在邮件消息的标题上设置的过滤器。标题与您的过滤器匹配的邮件将被检索，其余的将被忽略。
