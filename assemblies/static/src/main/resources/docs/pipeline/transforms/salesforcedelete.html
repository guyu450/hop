Salesforce删除

描述

Salesforce删除转换使用Salesforce Web服务直接从您的Salesforce数据库中删除记录。

用法

您可以通过指定起始点（字段名id）和要删除的记录数量（批量大小）来删除一批记录。

您还可以使用以下其他转换来修改您的Salesforce数据库：

  • Salesforce输入：直接从您的Salesforce数据库读取记录。

  • Salesforce插入：直接将记录插入您的Salesforce数据库。

  • Salesforce更新：直接在您的Salesforce数据库中更新记录。

  • Salesforce插入或更新：更新现有记录并将新记录插入您的Salesforce数据库。

常规

在转换名称字段中输入以下信息：

  • 转换名称：指定画布上Salesforce删除转换的唯一名称。您可以自定义名称或保留默认名称。

连接

在以下转换选项中输入连接信息：

选项 描述
Salesforce Web服务URL

指定Salesforce Web服务的URL。

默认值：https: //login.salesforce.com/services/Soap/u/50.0

如果您的公司在Salesforce上使用”我 的域名”，您可能需要更新此URL。如果是这样， 请向您的Salesforce管理员咨询URL。一般格式为 https://NAME.my.sa lesforce.com/services/Soap/u/50.0。您也可以 在此处使用沙盒的URL来访问沙盒。强烈建议使用 变量 来填充这些值。
用户名 指定用于向Salesforce进行身份验证的用户名
密码 指定用于向Salesforce进行身份验 证的密码。输入您的密码，后跟您的安全令牌。 例如，如果您的密码是PASSWORD，您的安全令牌 是TOKEN，您应在此字段中输入PASSWORDTOKEN。
测试连接 点击以验证是否可以连接到您指定的Salesforce Web服务URL。

设置

在以下转换选项中输入插入过程设置：

选项 描述
超时 指定转换超时前的超时时间间隔（以毫秒为单位）。
使用压缩 选择在Hfxt和Salesforce之间连接时压缩（.gzip）数据。
回滚所有更改 除非所有记录都成功处理，否则恢复更改。当您 选择此选项时，无错误的记录将被插入，而有错误的记录将 在插入结果中标记为失败。默认行为是允许插入部分成功。
批量大小 指示在提交插入操作之前要收集的最大记录数。
模块

选择要插入记录的模块（表）。
