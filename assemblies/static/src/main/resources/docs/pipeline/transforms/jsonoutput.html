JSON输出

描述

JSON输出转换允许您根据输入的转换值生成JSON块。根据转换设置，输出的JSON将以JavaScript数组或JavaScript对象的形式提供。

选项

常规选项卡

常规选项卡允许指定转换操作的类型、输出JSON结构以及转换输出文件。此文件将用于转储所有生成的JSON。

设置部分

选项 描述

转换名称

转换的名称；此名称在单个管道中必须是唯一的。

操作

指定转换操作类型。目前有3种操作类型：

  1. 输出值 -

仅将输出JSON作为转换输出字段传递，不转储到输出文件

  1. 写入文件 - 仅写入文件，不传递到输出字段

  2. 输出值并写入文件 - 转储到文件并将生成的JSON作为转换输出文件传递

JSON块名称

此值将用作JSON块的名称。

每个块中的行数

组合为一个JSON数组的行数

每个块将生成一个新文件

输出值

输出字段名称

兼容模式

向后兼容的模式，更多信息 此处

输出文件部分

选项 描述

文件名

输出文件的完整路径

追加

勾选后，新行将追加到现有文件中

创建父文件夹

勾选后，如果父文件夹不存在将创 建它们，否则如果文件夹不存在转换将失败

启动时不打开/创建

如果未勾选：
在管道初始化期间将创建/打开文件（在 某些情况下还包括父文件夹）进行写入。
如果勾选：
仅在转换接收到任何第 一个输入数据后才会创建文件和父文件夹。

扩展名

输出文件扩展名。默认值为'json'

编码

输出文件编码

将输出传递给Servlet

启用此选项可 通过Web服务返回数据，而不是写入文件。

文件名中包含日期？

如果勾选 - 输出文件名将包含文件名值 + 当前 日期。这可能有助于生成唯一的输出文件。

文件名中包含时间

如果勾选 - 输出文件名将包含文件 创建时间。与”文件名中包含日期”选项相同

显示文件名按钮

这对于测试完整的输出文件路径可能很有用

将文件添加到结果文件名中？

如果勾选 - 创建的输出文件路径将可从转换结果中访问

字段选项卡

此选项卡用于将输入转换字段映射到输出JSON值

选项 描述
元素名称 作为键的JSON元素名称。例如”A”：“B” - A是元素名称，B是为此元素名称映射的实际输入值。
字段名称 输入转换字段名称。使用”获取字段”按钮来发现可用的输入字段

兼容模式

本文档的这部分将解释启用兼容模式时的差异。对于所有新开发，不建议使用此模式。假设我们正在生成一个简单的键值对列表，键名是”name”和”value”以及它们相应的值。

我们将使用以下设置：

  • JSON块名称 = “data”

  • 每个块中的行数 = 3

  • 兼容模式 = 未勾选（这是默认选项）

这将输出：

第一个文件：

{
  "data" : [ {
    "name" : "item 1",
    "value" : "value 1"
  }, {
    "name" : "item 2",
    "value" : "value 2"
  }, {
    "name" : "item 3",
    "value" : "value 3"
  } ]
}

第二个文件：

{
  "data" : [ {
    "name" : "item 4",
    "value" : "value 4"
  } ]
}

如果启用兼容模式且转换具有以下设置：

  • JSON块名称 = “data”

  • 每个块中的行数 = 3

  • '兼容模式' 已勾选

这将输出：

第一个文件：

{
    "data": [
        {
            "name": "item 1"
        },
        {
            "value": "value 1"
        },
        {
            "name": "item 2"
        },
        {
            "value": "value 2"
        },
        {
            "name": "item 3"
        },
        {
            "value": "value 3"
        }
    ]
}

第二个文件：

{
    "data": [
        {
            "name": "item 4"
        },
        {
            "value": "value 4"
        }
    ]
}

如您所见，启用兼容模式后，每个字段将被视为一个单独的对象。
