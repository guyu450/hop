获取变量

描述

“获取变量”转换允许您获取变量的值并从中创建字段。只有在需要将变量值用于字段时，才需要使用此转换。

用法

请注意，工作流/环境变量仅设置一次。管道需要启动才能获取任何新变量。正在运行的、顺序执行的或嵌套的（从技术上讲，嵌套管道与主管道相同）管道无法获取新的变量值。当管道执行器为每一行启动管道时，即认为管道已启动。

使用以下语法引用参数/变量：${myVariable}，例如引用上一个管道中的变量。

将字段、参数传递给下游变量的两种方法：

每个管道的参数必须唯一（不区分大小写）。管道执行器参数值优先于管道属性参数值。发送参数值优先于接收管道属性参数的默认值。

  • 使用管道执行器转换或”重复”操作：

    • 发送：在”参数”选项卡上添加要发送的字段（参数名称可以与字段名称相同）。

    • 接收：在紧邻的下游管道中，使用”获取变量”通过以下格式从参数设置变量/字段：${myParam}

  • 编辑任何上游管道的属性：

    • 发送：在管道属性的”参数”选项卡上（编辑管道图标）添加一个参数，并可选择为其设置默认值。可以在管道中使用各种转换设置参数值。

    • 接收：在紧邻的下游管道中，使用”获取变量”通过以下格式从参数设置变量/字段：${myParam}

其他：

另请参阅”设置变量”转换。

要将变量转换为除字符串以外的数据类型，请使用”选择值”-“元数据”选项卡。

要获取系统值，包括命令行参数，请使用”获取系统信息”转换。

例如，在变量列中，您可以指定：${java.io.tmpdir}/hfxt/tempfile.txt，在类Unix系统上它将被解析为 /tmp/hfxt/tempfile.txt。

故障排除

您必须始终指定数据类型，否则会出现以下错误：

选项

选项

描述

转换名称

此转换在管道工作区中显示的名称。

名称

字段名称。

变量

允许您输入完整的字符串变量，以返回行或将值添加到输入行。例如，您可以指定：$${java.io.tmpdir}/hfxt/tempfile.txt，在类Unix系统上它将扩展为 /tmp/hfxt/tempfile.txt。

您可以在输入字段中使用CTRL-SPACE（在OSX上为CMD-SPACE）查看已定义变量的列表。此辅助功能将把选定的变量插入到输入字段中。此处仅显示环境变量和具有JVM作用域的变量。在管道或工作流中创建的、带有父级、授予父级或根工作流作业的变量需要手动输入

类型

指定字段类型：字符串、日期、数字、布尔值、整数、大数字、可序列化或二进制。

格式

在确定类型后，允许您指定字段的格式。

长度

对于数字：数字中的有效数字总数；对于字符串：字符串的总长度；对于日期：字符串打印输出的长度（例如，输入4将仅返回年份）。

精度

对于数字：浮点数的位数。不适用于字符串、日期或布尔值。

货币

用于解释带有货币符号的数字。例如，$10,000.00或E5.000,00。

小数

用于指示数字值是使用句号（“.”）还是逗号（“,”）。

分组

用于指示数字值是使用句号（“.”）还是逗号（“,”）。

修剪类型

在处理之前修剪此字段的类型：选择无、左、右或两者（左和右）。
