向属性文件写入数据

描述

“属性输出”转换将一组数据行输出到一个Java属性文件中。数据需要以键/值格式进行结构化处理，以便能用于属性文件。

选项

常规选项卡

选项 描述
转换名称 转换的名称。此名称在单个管道中必须是唯一的。
键字段 输入字段名称，该字段将包含要写入属性文件的键值对中的键部分。
值字段 输入字段名称，该字段将包含要写入属性文件的键值对中的值部分。
注释

简短注释，会复制到属性文件的顶部。

只有第一行会被注释掉。任何额外的行必须手动注释掉。

内容

选项 描述
文件名 要创建的属性文件的名称，不包含文件扩展名。
追加 选中此选项可更新现有属性文件。文件中未被该转换处理的属性将保持不变。
创建父文件夹 如果要自动创建父文件夹，请选中此选项。
从字段接受文件名？ 如果文件名在输入流字段中指定，请选中此选项。
文件名字段 指定包含要写入的文件名的字段。
扩展名 指定文件扩展名。通常为”properties”。
在文件名中包含转换编号 在输出文件名中包含转换编号（在运行多个副本时）。
在文件名中包含日期 在输出文件名中包含日期，格式为yyyyMMdd（20081231）。
在文件名中包含时间 在输出文件名中包含时间，格式为HHmmss（235959）。
显示文件名…… 显示所有要写入的文件的路径和名称。
将文件添加到结果 将生成的文件名添加到此管道的结果中。内存中会保留一个唯一列表，可在工作流的下一个工作流操作中使用，例如在另一个管道中。
