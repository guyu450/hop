YAML输入

描述

YAML输入转换从YAML结构、文件或传入字段中读取数据。

选项

文件标签

选项 描述
转换名称 转换的名称。
源是否在字段中定义？ 源是否来自上一个转换的字段。
源是文件名 源是否为文件名，否则为目录。
从字段获取源 包含文件名或目录的字段。
文件或目录 文件或目录路径。
添加 将文件或目录添加到”选定文件”列表中。
浏览 浏览本地文件系统以查找文件或目录。
正则表达式
选定文件 选定的文件或目录。
删除 从列表中删除选定的行。
编辑 移动选定的行进行编辑。
显示文件名 预览文件名。

内容标签

选项 描述
忽略空文件 是否忽略空文件。
无文件时不引发错误 如果没有可用文件，是否引发错误。
限制 设置要读取的限制。
输出中包含文件名？ 将文件名添加到输出行中。
文件名字段名 包含文件名的字段。
输出中包含行号？ 将行号添加到输出行中。
行号字段名 包含行号的字段。
将文件添加到结果文件名

字段标签

选项 描述
名称 输出字段的名称。
键 元素的键。
类型 要转换为的数据类型。
格式 在数据类型转换中使用的格式或转换掩码。
长度 输出数据类型的长度。
精度 输出数据类型的精度。
货币 在数据类型转换期间使用的货币符号。
小数 在数据类型转换期间使用的数字小数符号。
分组 在数据类型转换期间使用的数字分组符号。
修剪类型 在数据类型转换期间使用的修剪类型。
获取字段 从输入中近似获取字段。
