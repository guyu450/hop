表格对比

描述

表格对比转换功能会比较两个表格中的数据（前提是它们具有相同的布局），找出两个表格数据之间的差异并记录下来。

选项

参考/对比数据标签页

选项 描述
参考连接 / 对比连接 用于获取参考/对比表格数据的数据库连接。
参考模式字段 / 对比模式字段 包含参考/对比表格的模式名称。
参考表字段 / 对比表字段 包含实际的表名。这意味着只要两个表具有相同的列名，你就可以对比名称不同的两个表。

其他字段标签页

选项 描述
键字段 应包含一个以逗号分隔的字段列表，这些字段构成了你要对比的表的”主键”。需要主键是因为没有此信息，两个表就无法正确连接。
排除字段 包含一个以逗号分隔的列列表，你希望将这些列排除在对比之外。例如，因为它们存在于第一个表中，但不存在于第二个表中。

附加字段标签页

选项 描述
错误数量字段 允许你指定输出列的名称，该列将包含在对比表时发现的错误总数。
参考/对比表记录数字段 允许你指定字段的名称，该字段将包含在每个表中找到的实际记录数。
左/内/右连接错误数字段 允许你指定字段名称，这些字段将包含每种连接类型发现的错误数。
错误处理键描述输入字段 允许你指定出现错误记录的”where子句”的输出字段名称。
错误处理参考/对比值输入字段 允许你指定实际不同值的输出字段名称。
