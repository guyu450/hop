XML 合并

描述

XML 合并转换将一个流中的 XML 标签添加到另一个流的主导 XML 结构中。目标流必须只有一行，因为它代表一个 XML 文档。另一个流可以包含多行，合并操作会将所有行的标签添加到目标文档中。合并后只会生成一行。这一行包含目标转换的字段以及合并的结果字段。

选项

选项 描述
转换名称 转换的名称。
目标 XML 转换 将目标文档发送到合并操作的转换。
目标 XML 字段 包含 XML 结构的字段。
源 XML 转换 将需要添加到目标的 XML 结构发送到合并操作的转换。
源 XML 字段 包含要添加到目标的 XML 结构的字段。
XPath 语句 用于在目标文档中查找新标签开始插入位置的 XPath 语句。启用复杂合并时，使用单个问号（?）作为占位符。
复杂合并 启用复杂合并语法的标志，使用 XPath 语句中的占位符
合并比较字段 包含在 XPath 语句中要替换的值的字段
结果 XML 字段 将包含结果的字段。
编码 用于 XML 头部以及转换 XML 的字符编码
省略 XML 头部 是否在输出中省略 XML 头部。无论是否包含头部，目标 XML 的字符编码都会保留。
从 XML 中省略空值 是否从输出中移除空值。如果未选择此选项，空值将作为空元素（如 <abc/>）包含在 XML 输出中。选择此选项后，空值将完全从输出中省略，不存在空元素。这对于在输出文件中节省空间（对于大量事务）或在输出中对特殊条件使用空标签很有用。
