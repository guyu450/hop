计算器

描述

计算器转换为您提供了预定义函数，这些函数可以对输入字段值执行。除了参数（字段A、字段B和字段C）外，您还必须指定函数的返回类型。在所有值计算完成后，您可以选择（通过”移除”选项）从结果（输出）中移除字段。当您使用一些临时值，且这些临时值最终不需要出现在管道字段中时，此功能非常有用。

选项

列 描述
新字段 计算结果的输出字段。对于计算后续字段所需但最终结果中不需要的临时字段，将 移除 设置为 是。
计算 此新字段所需的计算。
字段A 计算中使用的第一个字段。
字段B 计算中使用的第二个字段。
字段C 计算中使用的第三个字段。
值类型 此计算结果要使用的数据类型。
长度 为此计算结果设置的长度。
精度 为此计算结果设置的精度。
移除 要设置的布尔标志。对于仅在中间计算中需要且不需要包含在输出中的临时字段，设置为 是。
转换掩码 应用于日期或数字字段的转换掩码。
小数点符号 在输出字段中设置的小数点符号。
分组符号 在输出字段中设置的分组符号。
货币符号 在输出字段中设置的货币符号。

四舍五入1

返回与参数最接近的整数。结果通过加上1/2、取结果的下限并将结果转换为整数类型来四舍五入为整数。换句话说，结果等于表达式的值：floor (a + 0.5)。如果您需要”四舍五入到偶数”的舍入方法，请使用以下方法ROUND( A, B ) 且小数位数为0（B = 0）。

ROUND( A, B )

四舍五入2

将A四舍五入到最接近的偶数，保留B位小数。使用的舍入方法是”四舍五入到偶数”，也称为无偏舍入、收敛舍入、统计学家舍入、荷兰舍入、高斯舍入、奇偶舍入、银行家舍入或破折号舍入，在簿记中广泛使用。这是IEEE 754计算函数和运算符中使用的默认舍入模式。在德国，它通常被称为”Mathematisches Runden”。
