XML输入流（StAX）

描述

XML输入流（StAX）转换使用XML流API（StAX）解析器从XML文件读取数据。

用法

此转换对于快速处理大型复杂数据结构最为适用。

与使用内存处理且可能需要清除文件部分内容的 从XML获取数据 转换不同，XML输入流（StAX）转换将处理逻辑转移到管道中。

该转换本身提供原始XML数据流以及额外的处理信息。

当您在使用其他转换存在限制，或者在以下情况下需要解析XML时，建议使用此流转换：

  • 您需要快速加载数据，且数据加载与内存无关，无论文件大小如何。

  • 您需要以不同方式灵活读取XML文件的各个部分，并且不想重复解析文件。

由于某些XML文件的处理逻辑可能很复杂，因此在使用此转换时，您应该对现有的Hfxt转换有充分的了解。
