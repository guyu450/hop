卡珊德拉输出

描述

卡珊德拉输出转换使用CQL（卡珊德拉查询语言）3.x版本将数据写入到 Cassandra集群的卡珊德拉表中。

选项

选项 描述
卡珊德拉连接 在此处，你可以将连接名称指定为固定值或变量表达式。输入字段右侧有按钮，可帮助你管理元数据。
写入的表 指定要写入数据的表名。
一致性级别 有关可能的值列表，请参阅 卡珊德拉写入一致性级别。
提交批次大小 每次提交时要更新的行数
批次插入超时时间 指定在将批次拆分为较小的子批次之前，等待批次完全插入的毫秒数。你必须指定一个小于套接字超时时间的值，或者留空表示无超时。
子批次大小 如果由于达到批次插入超时时间而必须拆分批次，请指定子批次大小（行数）。
插入未记录批次 如果你想使用非原子批次写入，请选择此项。默认情况下，批次是原子性的（如果批次中的任何操作成功，则所有操作都会成功）。选择此选项可取消原子性限制。
生存时间（TTL） 指定写入列的时间量。如果时间到期，该列将被删除。
用作键的传入字段 指定使用哪个传入字段作为键。你可以使用传入转换字段的名称来指定键。
创建表 如果指定名称的表（列族）不存在，则选择此项以创建该表。
表创建的WITH子句 指定对表创建 WITH 子句的附加内容。
截断表 如果你想在插入传入行之前删除指定表中的任何现有数据，请选择此项。
更新表元数据 如果你想使用传入字段中不存在的信息更新表元数据，请选择此项。如果未选择此选项，除非选择了”插入列元数据中不存在的字段”选项，否则任何未知的传入字段都将被忽略。
插入列元数据中不存在的字段 如果你想根据默认表验证器插入列元数据中不存在的任何传入字段，请选择此项。如果选择了”更新表元数据”选项，则此选项无效。
