行生成器

描述

要使用字段，你必须有一个数据行。某些转换（如表格输入，前提是你运行了预览）会自动生成一个数据行。如果不存在数据行，请添加一个”生成行”转换来创建一行或多行，以便使用字段、打印变量或参数等。“生成行”转换会输出指定数量的空行或带有一组硬编码字段的行。默认情况下，这些行是空的；不过，它们可以包含一些静态字段。此转换主要用于测试目的。它对于生成固定数量的行可能很有用，例如，你恰好需要为12个月生成12行。有时，你可以使用”生成行”来生成一行作为管道的起始点。例如，你可以生成一行，其中包含两三个字段值，你可以用这些值来参数化你的SQL，然后再生成实际的行。示例：* 要生成一行示例数据，向管道中添加两个操作项。添加一个”生成行”转换并连接到”添加常量”。在”添加常量”中，你可以添加要生成的字段。在”生成行”中，你可以限制行数。* 要遍历100行，你可以向管道中添加一个”生成行”和一个”添加序列”操作，并在管道上连接它们。

选项

选项 描述
转换名称 此转换的名称，该名称在单个管道中必须唯一
限制 设置你要生成的最大行数
字段 在此表中配置要生成的行的结构和值（可选）。
永不停止生成行 此选项适用于你永远不想停止运行管道的实时用例。然后，此转换的输出用于驱动重复任务，如从文件、队列、数据库等进行轮询。
间隔（毫秒） 生成的行之间的间隔时间（以毫秒为单位）。
当前行时间字段名称 包含当前行生成时间的日期字段的*可选*字段名称
上一行时间字段名称 包含上一行生成时间的日期字段的*可选*字段名称
