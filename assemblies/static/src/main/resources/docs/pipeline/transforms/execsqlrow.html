执行行SQL脚本

描述

“执行行SQL脚本”转换会针对该转换接收到的每一个输入行执行一个SQL脚本。要执行的SQL可以作为管道字段传递，也可以从文件中读取。

选项

选项 描述
转换名称 转换的名称；此名称在单个管道中必须唯一
连接 选择要使用的数据库连接
提交 在执行数据库提交之前发送的行数
SQL字段名称 该字段要么包含要执行的SQL，要么可选择指定包含要执行SQL的文件路径
从文件读取SQL 如果选中，则”SQL字段名称”选项指定一个包含要执行SQL的文件，否则”SQL字段名称”选项指定实际要执行的SQL。（从5.0版本开始可用）
包含插入统计信息的字段 可选：如果您希望在流中获得一个额外的字段，该字段包含插入的记录数，请在此处定义字段名称。
包含更新统计信息的字段 与插入统计信息相同，但针对更新的行。
包含删除统计信息的字段 与插入统计信息相同，但针对删除的行。
包含读取统计信息的字段 与插入统计信息相同，但针对读取的行。

注意事项

由于该转换具有脚本/动态性质，它不使用预编译语句，因此并非旨在快速或优化运行。为了获得良好的性能，请使用专门的转换，如”表输出”（插入到）、“表输入”（选择）、“更新”、“删除”等。
