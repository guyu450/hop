Doris批量加载器

描述

Doris是一款现代化的大规模并行处理（MPP）分析型数据库产品。它能够提供亚秒级查询，并实现高效的实时数据分析。凭借其分布式架构，它能够很好地支持高达10PB级别的数据集，且操作简便。 Doris可以满足各种数据分析需求，包括历史数据报告、实时数据分析、交互式数据分析以及探索性数据分析。让您的数据分析更加轻松！Doris批量加载器允许您高速、大容量地将数据插入到 Doris中，相较于使用传统的数据库插入语句，这是一种更快的数据加载方式。

选项

常规

选项 描述
转换名称 转换的名称；此名称在单个管道中必须唯一
前端主机 前端主机的主机名
前端HTTP端口 用于连接前端主机的端口
数据库名称 您要连接的数据库
表名 要批量加载记录的表名
登录用户 用于连接数据库的用户
登录密码 连接数据库的密码
数据字段 数据必须合并到单个字段中，这可以是CSV格式的字段或JSON数据
格式 用于告知转换程序期望的是CSV格式还是JSON格式数据的指示符
行分隔符 用于指示行尾的分隔符
列分隔符 当使用CSV格式数据时，此分隔符将指示按哪个字符拆分字段
缓冲区大小 缓冲区大小（以字节为单位，0表示无限制）
缓冲区数量 缓冲区大小 * 缓冲区数量是在进行实际流加载之前缓冲数据的最大容量（0表示无限制）
