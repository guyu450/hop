销售云（Salesforce）插入或更新（Upsert）

描述

销售云（Salesforce）插入或更新（Upsert）转换通过销售云（Salesforce）网络服务，对现有记录进行更新，并将新记录插入到您的销售云（Salesforce）数据库中。您还可以使用以下其他转换来修改您的销售云（Salesforce）数据库：

常规

在转换名称字段中输入以下信息：

  • 转换名称：指定画布上销售云（Salesforce）插入或更新（Upsert）转换的唯一名称。您可以自定义名称，也可以保留默认名称。

连接

在以下转换选项中输入连接信息：

选项 描述
销售云（Salesforce）网络服务URL

指定销售 云（Salesforce）网络服务的URL。

默认值：https://login.sa lesforce.com/services/Soap/u/50.0

如果您的公司在销售云 （Salesforce）上使用”我的域名（My Dom ain）“，则可能需要更新此URL。如果 是这种情况，请向您的销售云（Sale sforce）管理员咨询URL。一般格式为 https ://NAME.my.salesforce.com/service s/Soap/u/50.0。您也可以在此处使用 沙盒的URL来访问沙盒。强烈建议使用 变量 来填充这些值。
用户名 指定用于向销售云（ Salesforce）进行身份验证的用户名
密码 指定 用于向销售云（Salesforce）进行身 份验证的密码。输入您的密码，后面 跟上安全令牌。例如，如果您的密码 是PASSWORD，安全令牌是TOKEN，那么 您应在此字段中输入PASSWORDTOKEN。
测试连接 点击此按 钮，以验证是否可以连接到您指定的 销售云（Salesforce）网络服务URL。

设置

在以下转换选项中输入插入过程设置：

选项 描述
超时时间 指定转换超时前的超时时间间隔（以毫秒为单位）。
使用压缩 选择此选项可在Hfx t与销售云（Salesforce）之间连接时压缩（.gzip）数据。
回滚所有更改 除非所有记录都成功处理，否则将回滚更改。当您 选择此选项时，无错误的记录将被插入，而有错误的记录将 在插入结果中标记为失败。默认行为是允许插入部分成功。
批处理大小 指定在提交插入操作之前收集的最大记录数。
模块

选择要插入记录的模块（表）。

插入或更新（Upsert）比较字段 指定用作比较基础的字段的销售云（Salesforce）ID，以确定是要更新现有记录还是插入新记录。

输出字段

在以下转换选项中输入输出信息：

销售云（Salesforce）ID字段名称：指定用于包含您更新和插入的记录集（批处理）中第一条记录的销售云（Salesforce）ID的字段。

字段

您可以通过”字段”表指定要插入到销售云（Salesforce）数据库中的字段。点击”获取字段”，用Hfxt数据流中的输入填充该表。

该表包含以下列：

选项 描述
模块字段 模块内的字段名称
流字段 Hfxt数据流中的字段名称
使用外部ID？

指 示该字段是否链接到外部ID的标志。为了解析ID，销售云（ Salesforce）需要对象类型、列名和关系名，语法如下：

对象名称:列名/关系

或者，点击”编辑映射”以指定自定义映射。例如，您可以将单个Hfxt字段映射到多个销售云（Salesforce）字段。
