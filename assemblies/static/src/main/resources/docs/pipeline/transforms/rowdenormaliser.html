行反规范化器

描述

反规范化器转换允许您通过查找键值对来对数据进行反规范化，并可选择在过程中转换数据类型。 注意：请务必查看《Beam入门》文档中关于此转换的说明。

选项

转换名称 转换的名称。此名称在单个管道中必须是唯一的。
键字段 定义输出行键的字段。
分组字段 在此处指定构成分组的字段。
目标字段 通过为键字段指定字符串值（见上文）来选择要反规范化的字段。提供了转换数据类型的选项。字符串作为键值对最为常见，因此您通常必须转换为整数、数字或日期。如果出现键值对冲突（为指定的组指定的键不唯一），请指定要使用的聚合方法。

元数据注入支持

您可以将支持元数据注入的字段与ETL元数据注入转换一起使用，以便在运行时将元数据传递到管道中。所有字段都可以注入，用于聚合字段的值如下

键 值
TYPE_AGGR_NONE 不进行聚合
TYPE_AGGR_SUM 对所有值求和
TYPE_AGGR_AVERAGE 计算平均值
TYPE_AGGR_MIN 取组中的最小值
TYPE_AGGR_MAX 取组中的最大值
TYPE_AGGR_COUNT_ALL 计算行数
TYPE_AGGR_CONCAT_COMMA 聚合用逗号分隔的值

示例

输入数据

输入数据必须按分组键排序（在此示例中为记录ID），如有需要，请使用 排序行 转换：

记录ID 键 值
345-12-0000 名字 米切尔
345-12-0000 姓氏 鲁诺尔夫斯多蒂尔
345-12-0000 城市 杰里赛德
976-67-7113 名字 埃尔登
976-67-7113 姓氏 韦尔奇
976-67-7113 城市 贾马尔湖
824-21-0000 名字 罗里
824-21-0000 姓氏 莱德纳
824-21-0000 城市 斯科蒂维尤

反规范化数据

设置 键字段 = “键”，并在 构成分组的字段 中添加 记录ID。按如下方式编制 目标字段 表：

目标字段名 值字段名 键值 类型
名字 值 名字 字符串
姓氏 值 姓氏 字符串
城市 值 城市 字符串

结果如下：

记录ID 名字 姓氏 城市
345-12-0000 米切尔 鲁诺尔夫斯多蒂尔 杰里赛德
976-67-7113 埃尔登 韦尔奇 贾马尔湖
824-21-0000 罗里 莱德纳 斯科蒂维尤
