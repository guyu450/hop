LDAP输出

描述

LDAP输出转换允许您将用户、角色和其他数据等信息写入LDAP服务器。以下部分介绍LDAP输出转换的可用选项。

常规选项卡

选项 描述
转换名称 转换的名称；此名称在单个管道中必须唯一。
主机 主机可以是LDAP目录服务器的IP地址或其DNS名称。
端口 LDAP目录服务器的端口号。
引用

确定如何处理引用。

  • 忽略：忽略引用。

  • 跟随：自动跟随任何引用。
取消别名引用

确定如何取消别名引用。

  • 始终：始终取消别名引用。

  • 从不：从不取消别名引用。

  • 查找时：仅在名称解析期间取消别名引用。

  • 搜索后：仅在名称解析后取消别名引用。
协议

确定使用哪种协议。

  • LDAP

  • LDAP SSL

  • LDAP TLS
使用身份验证 启用LDAP身份验证。
用户名 身份验证期间传递的用户名。
密码 身份验证期间传递的密码。
使用证书 启用证书的使用。
信任库路径
信任库密码
信任所有证书
测试连接 测试配置的到LDAP服务器的连接。

不存在则失败

旧DN字段名 包含旧专有名称（重命名）的字段。
新DN字段名 包含新专有名称（重命名）的字段。
删除RDN 是否删除RDN（相对专有名称）
