Azure事件中心写入器

描述

Azure事件中心写入器转换允许你将消息（事件）写入Microsoft Azure云平台上名为”事件中心”的流式服务总线。

选项

以下是使转换正常工作需要填写的重要选项：

  • 事件中心命名空间：你的事件中心命名空间名称

  • 事件中心实例名称：事件中心的名称，即实例本身。

  • SAS策略密钥名称：Azure仪表板中事件中心命名空间的”共享访问策略”部分中的策略名称。此策略需要启用”发送”声明。

  • SAS密钥连接字符串：你可以使用标记为”连接字符串 - 主密钥”的策略中的值

  • 批大小：每次调用Azure时在一批中发送的消息（事件）数量。

  • 消息字段：包含用作事件的消息的字段。请注意，你可以使用JSON输出或”JavaScript”等转换来组合消息。
