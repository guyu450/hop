正则表达式评估

描述

正则表达式评估转换会将输入字段的字符串与您使用正则表达式（regex）定义的文本模式进行匹配。此转换使用java.util.regex包。此转换所使用的正则表达式创建语法在java.util.regex.Pattern的Java文档中有定义。您可以使用此转换来解析复杂的文本字符串，并通过捕获组（由括号定义）从输入字段中创建新的字段。

用法

模式匹配

此转换的主要用途是检查输入字段是否与给定模式匹配：会向流中添加一个布尔字段，指示是否匹配。

该模式旨在匹配整个输入字段，而不仅仅是其中一部分。例如，给定输入：

"作者, 安" - 53 篇文章

像 \d* 篇文章 这样的正则表达式将不会匹配，即使输入的一部分（53 篇文章）确实与该模式匹配。要实现实际匹配，您需要在模式中添加 .*：

.*\d* 篇文章

捕获文本

此转换还可以捕获输入的部分内容，并将其存储在流的新字段中：为此，只需在正则表达式中添加常用的分组运算符（简单括号）。

对于与上述相同的输入文本，创建一个带有两个捕获组的正则表达式：

^"([^"]*)" - (\d*) 篇文章$

该转换将捕获值 作者, 安 和 53，因此您可以在管道中创建两个新字段（即一个用于姓名，一个用于文章数量）。

设置选项卡

设置选项卡包含以下选项：

选项 描述
要评估的字段 指定传入的Hfxt流中要与正则表达式进行匹配的字段名称。
结果字段名称 指定输出字段的名称。此字段将添加到传出的Hfxt流中，值为Y表示输入字段的值与正则表达式匹配，值为N表示不匹配。
为捕获组创建字段 选择根据正则表达式中的捕获组创建新字段。选择此选项后，捕获组中的子字符串将被提取并存储在您在捕获组字段表中指定的新输出字段中。捕获组字段表中必须为每个捕获组定义一个字段。表中字段的顺序必须与正则表达式中捕获组的顺序相同。您可以使用表中的列更改数据类型。
替换先前的字段 如果字段名称相同，选择用为捕获组字段名称创建的字段替换传入的Hfxt流中的字段。如果不选择此选项，则会为每个捕获组字段向传出的Hfxt流中添加新字段。只有在选择为捕获组创建字段选项时，此选项才可用。
正则表达式 指定您的正则表达式。点击测试正则表达式可打开正则表达式评估窗口。
使用变量替换 选择在评估正则表达式模式之前将变量引用扩展为其值。

测试正则表达式

您可以使用以下正则表达式评估窗口针对三个不同的输入字符串测试您的正则表达式。如果您的表达式包含一个组字段，请在比较部分中输入一个字符串，并且该字符串下方的选项将根据您的组进行拆分。

选项 描述
请输入新的正则表达式或进行修改 指定您的正则表达式。
要测试的值 指定要测试字符串的值（值1、值2或值3）。如果该值与您的表达式匹配，背景将变为绿色；如果不匹配，背景将变为红色。

  • 执行标志是 (?x)。
启用dotall模式

选择 将行终止符包含在点字符表达式匹配中。

  • 执行标志是 (?s)。
启用多行模式

选择匹配输入序列的行首 ^ 或行尾 $。默认情况下，这些表达 式仅在整个输入序列的开头和结尾匹配。

启用Unix行模式

选择仅在 .、^ 和 $ 的行为中识别行终止符。

  • 执行标志是 (?d)。
