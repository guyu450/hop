拆分字段

描述

“拆分字段”转换操作会根据指定的分隔符将一个字段拆分为多个字段。

选项

选项 描述
转换名称 转换的名称；此名称在单个管道中必须唯一
要拆分的字段 你想要拆分的字段的名称
分隔符 用于确定字段的分隔符。特殊字符（例如 CHAR ASCII HEX01）可以使用格式 $[值] 设置，例如 $[01] 或 $[6F,FF,00,1F]。
包围符 你可以指定一个包围字符串，当它放在一个值的周围时，允许该值中存在分隔符。例如，对于逗号 (,) 分隔符：aaaa,"123,456",ccc 可以使用包围符 " 解析为 3 个字段。
转义字符串 为了在值中包含分隔符字符，有时会使用转义字符串，如反斜杠、双反斜杠等。例如，对于逗号 (,) 分隔符：aaaa,123\\,456,ccc 可以使用转义字符 \\ 解析为 3 个字段。
字段表 在此表中，你可以定义拆分操作创建的每个新字段的属性。对于每个新字段，你必须定义字段名称、数据类型和其他属性。

示例

以下是拆分字段的示例：

示例 1

SALES_VALUES 字段包含："500,300,200,100"

使用以下设置将该字段拆分为四个新字段：

  • 分隔符：,

  • 字段：SALES1、SALES2、SALES3、SALES4

  • ID：

  • 移除 ID 否、否、否、否

  • 类型：数字、数字、数字、数字

  • 格式：., ., ., .

  • 分组：

  • 小数：.

  • 货币：

  • 长度：3、3、3、3

  • 精度：0、0、0、0

示例 2

SALES_VALUES 字段包含 "Sales2=310.50, Sales4=150.23"

使用以下设置将该字段拆分为四个新字段：

  • 分隔符：,

  • 字段：SALES1、SALES2、SALES3、SALES4

  • ID：Sales1=、Sales2=、Sales3=、Sales4=

  • 移除 ID 是、是、是、是

  • 类型：数字、数字、数字、数字

  • 格式：., ., ., .

  • 分组：

  • 小数：.

  • 货币：

  • 长度：7、7、7、7

  • 精度：2、2、2、2
