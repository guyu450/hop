JavaScript

描述

JavaScript转换提供了一个用户界面，用于构建可用于修改数据的JavaScript表达式。在脚本区域输入的代码会针对每一行输入数据执行一次。

用法

JavaScript转换提供了一个用户界面，用于构建可用于修改数据的JavaScript表达式。在脚本区域输入的代码会针对每一行输入数据执行一次。

该转换允许在单个转换实例中使用多个脚本。

Javascript转换不是输入转换，因此需要来自管道的输入流。

尽量减少脚本编写对于保持数据集成解决方案的可维护性非常重要。尽量避免使用JavaScript。

故障排除

  • Hfxt使用的是较旧版本的JavaScript（Rhino引擎），它支持ECMA 5以及部分ECMA 6。有关Rhino对ES2015/ES6、ES2016和ES2017的支持，请参阅 https://mozilla.github.io/rhino/compat/engines.html

  • “获取变量”按钮可能并不总是有效，因此请手动输入变量。

  • JavaScript转换在空白字符和换行符较少的情况下运行得更好，尤其是在使用GraphQL时。避免使用多行表达式或语句。

  • 确保为输出的JavaScript字段选择正确的类型。

var myTestString = "my test";

转换脚本

您在该转换中创建的脚本。

转换常量

一些预定义的静态常量，用于控制数据行的处理方式。
要使用这些常量，必须在脚本开头将pipeline_Status变量设置为CONTINUE_PIPELINE，以便将变量赋值应用于正在处理的第一行。否则，对pipeline_Status变量的任何后续赋值将被忽略。
可用的常量如下：

  • SKIP_PIPELINE：将当前行排除在输出行集之外，并继续处理下一行。

  • ERROR_PIPELINE：将当前行排除在输出行集之外，生成错误，并且不再处理任何剩余行。

  • CONTINUE_PIPELINE：将当前行包含在输出行集中。

  • ABORT_PIPELINE：将当前行排除在输出行集之外，并且不再处理任何剩余行，但不生成错误。

可在脚本中使用的字符串、数值、日期、逻辑、特殊和文件函数。这些包含的函数用Java实现，执行速度比JavaScript函数快。每个函数都有一个示例脚本，演示其用法。双击函数可将其添加到Javascript面板中。右键单击并选择”示例”可将示例添加到Javascript面板中。

Javascript面板

Javascript面板是编写代码的编辑区域。您可以通过双击要插入的节点，或使用拖放操作将对象放置到Javascript面板上，从左侧的Javascript函数面板中插入常量、函数、输入字段和输出字段。

Javascript面板底部的位置显示光标所在的行号和位置。

“优化级别”选择JavaScript的优化级别。取值如下：

  • 1：JavaScript以解释模式运行。

  • 0：不执行任何优化。

  • 1 - 9：执行所有优化。9执行的优化最多，脚本执行速度更快，但编译速度较慢。默认值为9。

脚本类型

您可以右键单击Javascript面板中的标签，打开包含以下命令的上下文菜单：

  • 添加新脚本 – 添加一个新的脚本标签。

  • 添加副本 – 在新标签中添加现有脚本的副本。

  • 设置转换脚本 - 指定为每一行传入数据执行的脚本。只能将一个标签设置为转换脚本。默认情况下，第一个标签是转换脚本。

  • 设置起始脚本 - 指定在处理第一行数据之前执行的脚本。

  • 设置结束脚本 – 指定在处理完最后一行数据之后执行的脚本。

  • 移除脚本类型 - 指定不执行该脚本。脚本标签不会被移除。要移除脚本标签，请单击关闭按钮（红色”X”），然后选择”是”以删除脚本标签。

脚本类型的图标显示在标签上，以表示标签上脚本的类型。要重命名脚本标签，请右键单击Javascript函数面板”转换脚本”部分中的标签名称，选择”重命名”，然后输入新名称。

在行中添加新字段

为保持行结构的一致性，必须按相同顺序向行中添加字段。

要添加字段，请在Javascript面板中将其定义为var，并在字段表中将其作为字段添加。

数值

在JavaScript中分配的大多数值默认情况下都是浮点值，即使您认为自己分配的是整数值。如果在对已知为整数的值使用 == 或switch/case时遇到问题，请使用以下结构：

switch(parseInt(valuename))
{
case 1:
case 2:
case 3:
 strvalueswitch = "one, two, three";
 break;
case 4:
 strvalueswitch = "four";
 break;
default:
 strvalueswitch = "five";
}

过滤行

要过滤行（例如从输出中删除行），请按如下方式设置pipeline_Status变量：

pipeline_Status = CONTINUE_PIPELINE
if (/* your condition here */) pipeline_Status = SKIP_PIPELINE

所有符合指定条件的行都将从输出中删除。

使用包含空格的字段名称

Javascript不允许您创建变量名中包含空格的变量。但是，您 可以 使用包含空格的字段名称。

例如，要将字段”field name with spaces”中的所有空格替换为下划线，请使用语法 this["field name with spaces"]。
