调用数据库存储过程

描述

“调用数据库存储过程”转换允许您执行数据库存储过程（或函数）并获取返回的结果。使用MySQL和JDBC时，无法检索存储过程的结果集。存储过程和函数只能通过其函数参数返回值，并且这些参数必须在”数据库存储过程调用”配置的”参数”部分中定义。

选项

选项 描述
转换名称 转换的名称；此名称在单个管道中必须唯一
连接 存储过程所在的数据库连接名称
存储过程名称 要调用的存储过程或函数的名称
查找 点击此按钮可在指定的数据库 连接上搜索可用的存储过程和函数（仅适用于Oracle和SQL Server）
启用自动提交 在某些情 况下，您希望使用指定的存储过程在数据库中执行更新操作
提交 在这种情况下，您可以选择使 用自动提交来执行更改，也可以不使用。如果禁用自动提交 ，则在该转换接收到最后一行数据后将执行一次提交操作。
结果名称 函数调用结果的名称；如果这是一个存储过程，请留空
结果类型 函数调用结果的类型；如果是存储过程，则不使用此选项。
参数

存储过程或函数所需的参数列表

  • 字段名称：字段的名称。

  • 方向：可以是IN（仅输 入）、OUT（仅输出）、INOUT（值在数据库中会被更改）。

  • 类型：用于输出参数，以便Hfxt知道返回的是什么
获取字段 填充输入流中的所 有字段，让您更轻松；删除不需要的行并重新排列剩余的行
