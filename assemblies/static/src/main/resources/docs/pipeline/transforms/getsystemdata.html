获取系统信息

描述

“获取系统信息”转换从Hfxt项目、Hfxt运行的环境或系统中检索系统信息。该转换包含一个表格，在其中您可以指定一个名称，并将其分配给任何想要检索的可用系统信息类型。此转换会生成一行，其字段包含请求的信息。它还可以接受任意数量的输入流，聚合此转换定义的任何字段，并将合并后的结果发送到输出流。

选项

选项 描述
转换名称 转换的名称，此名称在单个管道中必须唯一。
名称 您要赋予特定数据类型的名称
类型 可用系统数据类型的列表
