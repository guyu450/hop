流查找

描述

流查找转换类型允许您使用管道中其他转换传来的信息来查找数据。从源转换传来的数据首先被读入内存，然后用于从主流中查找数据。

选项

选项 描述
转换名称 此转换的名称，该名称在单个管道中必须唯一
查找转换 查找数据来源的转换名称
要查找的键…… 允许您指定用于查找值的字段名称。始终使用”等于”比较来搜索值
要检索的字段 您可以在此处指定要检索的字段名称，以及在未找到值时的默认值，或者在您不喜欢旧名称时指定新的字段名称。
保留内存 对数据行进行编码，以便在排序时保留内存。（技术背景：Hfxt会将查找数据作为原始字节存储在自定义存储对象中，该对象使用字节的哈希码作为键。计算哈希码会消耗更多CPU，但所需内存更少。）
键和值恰好是一个整数字段 在执行排序时保留内存。注意：仅在选中”保留内存”时有效。不能与”使用排序列表”选项结合使用。
使用排序列表 启用后使用排序列表存储值；在处理包含宽行的数据集时，这可以更好地利用内存。注意：仅在选中”保留内存”时有效。不能与”键和值恰好是一个整数字段”选项结合使用。
获取字段 自动填入源端（A）所有可用字段的名称；然后您可以删除所有不想用于查找的字段。
获取查找字段 自动插入查找端（B）所有可用字段的名称。然后您可以删除不想检索的字段
