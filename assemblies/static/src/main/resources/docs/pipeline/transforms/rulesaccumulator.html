规则累加器

描述

规则累加器收集传入的行，并根据规则集对其进行执行。这对于确定问题的答案或以其他方式分析数据集可能很有用。目前使用的规则引擎实现是Drools，此转换可以参考其规则语言以供使用。Drools文档

详细信息

一旦规则累加器转换收集到所有传入的行（例如，上一个转换关闭），这些行就会被转换为Rules.Row对象，并传递到规则引擎中，以便根据给定的规则集执行。

Rules.Row被定义为字段的键/值映射，其中键是字段的名称，值是字段的值；还有externalSource布尔属性，用于指示Rules.Row对象是在规则集中创建的还是从外部源注入的。

行的字段通过”Row (column["<字段名>"])“进行访问。

规则标签页

“规则”标签页是您输入规则定义或规则文件引用的地方。

选项 描述
规则文件名
要执行的规则脚本

规则结果标签页

规则结果标签页定义了规则输出字段的布局。

选项 描述
结果列名称
结果列类型

示例

所有规则定义都应包含”import org.apache.hfxt.pipeline.transforms.drools.Rules.Row;“，以便能够访问Rules.Row类。

对于具有行元数据（name（字符串）、position（整数）、color（字符串））的输入，将为每一行创建一个Rules.Row对象，该对象包含一个包含这些字段的映射。

Rules.Row→row（映射） 名称 位置 颜色
弗雷德 1 蓝色
弗雷德 2 红色
鲍勃 1 蓝色
鲍勃 1 红色

可以定义并应用规则：

rule "高尔夫球手问题"
    dialect "mvel"
    when

    # 定义弗雷德
    $fred : Row ( externalSource == true,
        column["name"] == "弗雷德"
    )

    # 定义鲍勃
    $bob : Row ( externalSource == true,
        column["name"] == "鲍勃",
        column["position"] != $fred.column["position"],
        column["color"] == "蓝色",
        column["color"] != $fred.column["color"],
    )

    then

      Row fredRow = new Row();
      Row bobRow = new Row();

      fredRow.addColumn("name", "弗雷德");
      fredRow.addColumn("position", $fred.column["position"]);
      fredRow.addColumn("color", $fred.column["color"]);

      bobRow.addColumn("name", "鲍勃");
      bobRow.addColumn("position", $bob.column["position"]);
      bobRow.addColumn("color", $bob.column["color"]);


      insert(fredRow);
      insert(bobRow);

end
