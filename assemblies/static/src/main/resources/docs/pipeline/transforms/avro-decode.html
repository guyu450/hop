Avro解码

描述

Avro解码转换允许您解码一个Avro字段并将其转换为Hfxt字段。

选项

选项 描述
转换名称 转换的名称。注意：此名称在单个管道中必须是唯一的。
源字段 选择要转换的字段（类型：Avro）的名称
源字段 您可以指定要从Avro记录中选择的Avro字段的名称。您还可以指定要转换为的Hfxt数据类型。请注意，像Map和Record这样的复杂数据类型会被转换为JSON，然后您可以在后续转换中进一步解析。注意：“Avro类型”列仅用于提供信息。它在运行时不使用。
获取字段按钮 您可以使用”获取字段”按钮从指定的Avro记录源字段的元数据中存在的模式中检索字段。例如，如果此字段中没有元数据（如从Kafka消费者获取数据的情况），您可以选择从Avro文件中读取。
