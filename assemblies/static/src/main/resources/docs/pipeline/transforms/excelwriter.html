Excel写入器

描述

Microsoft Excel写入器转换将来自”Hfxt out”的传入行写入到一个MS Excel文件中。它同时支持.xls和.xlsx文件格式。.xls文件使用二进制格式，更适合简单内容；而.xlsx文件使用Open XML格式，与模板配合使用效果良好，因为它能更好地保留图表和各种对象。

工作表部分

选项 描述
工作表名称 转换操作将向其写入行数据的工作表名称。
设为此活动工作表 如果勾选此选项，在MS Excel中打开Excel文件时，默认将打开上述工作表。
如果输出文件中已存在工作表 当输出文件中已经存在此工作表时（例如使用模板或写入现有文件时），您可以选择写入现有工作表，或者替换它。
保护工作表 XLS文件格式允许保护整个工作表不被更改。如果勾选此选项，您需要提供一个密码。Excel将显示该工作表是由您在此处提供的用户保护的。

模板部分

在创建新文件时（当替换现有文件或创建全新文件时），您可以选择创建现有模板文件的副本。请确保模板文件与输出文件类型相同（两者必须分别为xls或xlsx）。

在创建新工作表时，转换操作可以从当前文档（模板或转换操作正在写入的其他现有文件）复制一个工作表。如果目标工作表不存在，或者根据上述配置需要替换现有工作表，则会创建一个新工作表。

强制公式重新计算

如果勾选此选项，转换操作将尝 试确保输出文件中的所有公式字段都得到更新。

  • XLS文件格式支持一个 “脏”标志，转换操作会设置该标志。当文件在MS Excel中打开时，公式将立即重新计算。

  • 对于XLSX文件格式，转换操作必须自行 尝试重新计算公式字段。由于底层的POI库尚未 支持完整的Excel公式集，这可能会导致错误。 如果转换操作无法重新计算公式，将抛出错误。
保持现有单元格样式不变 如果勾选此选项，转换操 作将不会尝试设置正在写入的现有单元格的样式 。这在写入预定义样式的模板工作表时很有用。

字段部分

字段部分用于指定必须写入Excel文件的字段。您可以选择使用 模式定义 或手动定义所需字段的布局。

如果您决定使用 模式定义 来定义字段布局，请使用 模式映射 转换根据所选的 模式定义 调整传入流。

模式定义 我们要引用的 模式定义 的名称。

字段标题 如果设置了此选项，则用于标题/页脚，而不是”Hfxt”字段名称。
