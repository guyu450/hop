REST客户端

描述

REST客户端转换使您能够使用RESTful服务。表述性状态转移（REST）是一种关键的设计习惯用法，它采用无状态的客户端 - 服务器架构，其中Web服务被视为资源，并可以通过其URL进行标识。REST客户端转换可以使用预定义的REST连接，也可以直接使用完整的URL。使用REST连接时，URL（硬编码或从字段接受）将被视为相对于REST连接中定义的基础URL的路径。在转换的”标头”选项卡中指定的标头值将覆盖REST连接中定义的任何同名标头。不使用REST连接时，需要指定完整的URL。

选项

常规选项卡

“常规”选项卡用于输入访问资源的基本连接信息。

选项 描述
转换名称 此转换在管道工作区中显示的名称
REST连接 用于基础URL以及身份验证/授权标头名称和值的（可选）REST连接。
URL 指示资源的路径
从字段接受URL 表示资源的路径是从字段定义的
URL字段名称 指示定义资源路径的字段
HTTP方法 指示转换与资源的交互方式 - 选项为GET、PUT、DELETE、POST、HEAD或OPTIONS
从字段获取方法 表示GET方法是从字段定义的
方法字段名称 指示定义GET方法的字段
主体字段 包含POST、PUT和DELETE方法的请求主体。主体字段仅接受先前的字段，不接受硬编码值。
应用类型 指定资源的应用类型 - 选项为TEXT PLAIN、XML、JSON、OCTET STREAM、XHTML、FORM URLENCODED、ATOM XML、SVG XML或TEXT XML
连接超时 指示建立连接的超时时间（毫秒）
读取超时 指示等待读取数据的超时时间（毫秒）
结果字段名称 指定结果输出字段的名称
HTTP状态码字段名称 指定HTTP状态码字段的名称
响应时间（毫秒）字段名称 指定响应时间字段的名称

身份验证选项卡

如有必要，在”身份验证”选项卡中输入资源的身份验证详细信息。

Hfxt允许对HTTP登录和HTTP密码使用NULL参数/变量。
选项 描述
HTTP登录 指示访问资源所需的用户名
HTTP密码 指示与提供的HTTP登录用户名关联的密码
抢先式 在服务器给出未经授权的响应之前发送身份验证凭据的选项。由于 错误#4196，目前始终为true。
代理主机 指示代理主机的名称
代理端口 指示代理主机的端口号

SSL选项卡

“SSL”选项卡用于提供访问需要SSL证书身份验证的资源的身份验证详细信息。

选项 描述
信任库文件 指示信任库文件的位置
信任库密码 指示与提供的信任库文件关联的密码

标头选项卡

“标头”选项卡使您能够使用现有字段定义任何HTTP标头的内容。通过单击”获取字段”按钮填充字段列表。

要确定需要哪些标头，可以使用Postman并尽可能多地删除标头，以使请求仍能正常工作。在Postman中，您不需要使用值为”<请求发送时计算>“的标头。如果使用了”身份验证”选项卡，则无需手动添加”Authorization”标头。
选项 描述
字段 传入Hfxt流中包含标头信息的字段。将标头值字段名称添加到”字段”列中。
名称 此转换的传出Hfxt字段的名称。将标头键字段名称添加到”名称”列中。

参数选项卡

“参数”选项卡使您能够为POST、PUT和DELETE请求定义参数值。GET参数应直接作为URL的一部分。

选项 描述
参数 传入Hfxt流中包含参数信息的字段
参数 此转换的传出Hfxt字段的名称

矩阵参数选项卡

使用”矩阵参数”选项卡为POST、PUT、DELETE和PATCH请求定义矩阵参数值。

选项 描述
参数 传入Hfxt流中包含矩阵参数信息的字段
参数 此转换的传出Hfxt字段的名称
