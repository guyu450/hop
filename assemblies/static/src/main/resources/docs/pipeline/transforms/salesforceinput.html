内容标签页

内容标签页允许你在结果集中选择性地包含其他描述性字段。

高级

使用这些选项进一步细化在”设置”标签页中指定的查询返回的数据。例如，你可能只想查询指定日期范围内的已删除记录。“高级”面板包含以下字段：

选项

描述

检索

选择要检索的记录，以进一步定义你的数据集。你可以选择”全部”、“已更新”或”已删除”。

查询所有记录

选中此复选框以查询要检索的所有记录。清除此复选框以使用（以下）日期字段定义要查询的记录范围。

开始日期

指定在日期范围内检索记录的开始日期。格式为'yyyy-MM-dd HH:mm:ss'。

结束日期

指定在日期范围内检索记录的结束日期。格式为'yyyy-MM-dd HH:mm:ss'。
