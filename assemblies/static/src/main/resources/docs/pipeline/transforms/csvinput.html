CSV文件输入

描述

CSV文件输入转换从分隔文件中读取数据。您可以选择使用模式定义，也可以手动定义所需字段的布局。此转换的CSV标签其实不太准确，因为您可以定义任何想要使用的分隔符，例如竖线、制表符和分号；并不局限于使用逗号。内部处理机制使此转换能够快速处理数据。此转换的选项是文本文件输入转换选项的子集。与常规的文本文件输入转换相比，此转换的整体选项较少，但它有一些优势： 有关此转换中使用的有效日期和数字格式的信息，请查看日期格式化表和数字格式化表。

选项

选项 描述
转换名称 转换的名称。
文件名 或 文件名字段（来自先前转换的数据） 指定要读取的CSV文件的名称。 或 选择将包含要读取的文件名的字段名。如果此转换从先前的转换接收数据，则此选项以及在输出中包含文件名的选项将启用。
分隔符 指定目标文件中使用的文件分隔符字符。特殊字符（例如CHAR HEX01）可以使用格式$[值]设置，例如$[01]或$[6F,FF,00,1F]。
包围符 指定目标文件中使用的包围符字符。特殊字符（例如CHAR HEX01）可以使用格式$[值]设置，例如$[01]或$[6F,FF,00,1F]。
NIO缓冲区大小 这是读取缓冲区的大小。它表示一次从磁盘读取的字节数。
延迟转换 延迟转换算法将尝试避免不必要的数据类型转换，如果可行，这可以显著提高性能。典型的例子是从文本文件读取数据并写回到文本文件。
是否存在标题行？ 如果目标文件的第一行包含带有列名的标题行，请启用此选项。如果我们错误地在第一行没有任何列名的文件上设置此标志，Hfxt将把特定列在其特定位置找到的值设置为列名。如果在该特定位置，列的值为空，Hfxt将把列名设置为EmptyField_<n>，其中n是列在列集中的位置。 注意： 还要记得检查在文件分析后设置的猜测数据类型和列说明符，因为由于Hfxt在查看示例数据集时做出的错误假设，它们可能是错误的。
将文件名添加到结果 将读取的CSV文件名添加到此管道的结果中。内存中会保留一个唯一列表，可在工作流的下一个工作流操作中使用，例如在另一个管道中。
行号字段名（可选） 将在该转换的输出中包含行号的整数字段的名称。
是否并行运行？ 如果要运行此转换的多个实例（转换副本），并且希望每个实例读取CSV文件的不同部分，请选中此框。读取多个文件时，将考虑所有文件的总大小以拆分工作负载。在这种特定情况下，请确保所有转换副本都接收所有需要读取的文件，否则，并行算法将无法正常工作（原因很明显）。警告：由于技术原因，仅支持对其中字段不包含换行符或回车符的文件进行CSV文件的并行读取。
文件编码 指定要读取的文件的编码。
模式定义 我们要引用的 模式定义 的名称。
字段表 此表包含要从目标文件读取的字段的有序列表。
预览按钮 点击以预览来自目标文件的数据。
获取字段按钮 点击以根据当前设置（即分隔符、包围符等）返回目标文件的字段列表。所有识别出的字段都将添加到字段表中。
