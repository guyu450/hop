模糊匹配

描述

模糊匹配转换使用重复检测算法来查找可能匹配的字符串，这些算法会计算两个数据流的相似度。此转换会按照用户定义的最小值或最大值要求，将匹配值作为一个分隔列表返回。

算法定义

在”算法”字段中，有几个选项可用于比较和匹配字符串。

  • 莱文斯坦（Levenshtein） 和 达默劳 - 莱文斯坦（Damerau-Levenshtein）：通过查看从一个字符串转换为另一个字符串所需的编辑转换次数来计算两个字符串之间的距离。前者仅考虑插入、删除和替换。后者增加了换位。得分表示所需的最少更改次数。例如，“John”和”Jan”之间的差异为两次；要将”John”转换为”Jan”，需要一次转换将”O”替换为”A”，另一次转换删除”H”。

  • Needleman-Wunsch：计算两个序列的相似度，主要用于生物信息学。该算法会计算间隙罚分。上述示例的得分将为负二。

  • Jaro 和 Jaro-Winkler：计算两个字符串之间的相似度指数。结果是一个介于零（表示无相似度）和一（表示完全匹配）之间的分数。

  • 双字母相似度：将两个字符串拆分为字母对，并通过将公共字母对的数量除以两个字符串的字母对总数来计算两个字符串的相似度。

  • 变音位（Metaphone）、双倍变音位（Double Metaphone）、SoundEx 和改进的 SoundEx：是 https://en.wikipedia.org/wiki/Phonetic_algorithm#:~:text=A%20phonetic%20algorithm%20is%20an,indexing%20words%20in%20other%20languages[语音算法]，它们试图根据字符串的发音来匹配字符串。每种算法都基于英语，对于比较其他语言可能无用。

    • 变音位算法（Metaphone algorithm） 根据给定单词的英语发音返回一个编码值。“John”和”Jan”这两个名字的编码值都将返回”JN”。

    • 双倍变音位（Double Metaphone） 算法在其前身的基础上进行了根本性的设计改进，并使用更复杂的编码规则集。它可以为一个字符串返回一个主编码值和一个次编码值。“John”和”Jan”这两个名字各自返回的变音位键值为”JN”和”AN”。

    • SoundEx 算法 为一个名字返回一个由一个字母后跟三个数字组成的单个编码值。字母是名字的首字母，数字对其余辅音进行编码。

    • 改进的 SoundEx 算法是对其前身的改进。此算法的编码值为六位数字，对首字符进行编码，并且一个名字可以返回多个可能的编码。使用此算法，“John”这个名字返回的值为”160000”和”460000”，“Jan”也是如此。
