文本文件输入

描述

文本文件输入转换可从多种文本文件类型中读取数据，包括电子表格生成的格式和固定宽度的平面文件。该转换的功能允许您从文件或目录列表中读取数据，使用正则表达式形式的通配符，并接受来自先前转换的通用文件名。

使用正则表达式选择文件

文本文件输入转换可以通过正则表达式形式的通配符搜索文件。正则表达式比使用”*“和”？“通配符更复杂。以下是一些正则表达式的示例：

文件名 正则表达式 选定的文件
/dirA/ .userdata.\.txt 在/dirA/中查找所有名称包含userdata且以.txt结尾的文件
/dirB/ AAA.* 在/dirB/中查找所有名称以AAA开头的文件
/dirC/ [ENG:A-Z][ENG:0-9].* 在/dirC/中查找所有名称以大写字母开头并后跟一个数字（A0 - Z9）的文件

接受来自先前转换的文件名

此选项允许您在另一个转换（如”获取文件名”）中构造文件名，然后将其传递给此转换，可以作为输入流中的一个字段，也可以直接从其他转换的输出中读取。这使您可以使用来自任何源的文件名，包括文本文件和数据库表。

内容标签

内容标签允许您指定正在读取的文本文件的格式。以下是与此标签关联的选项列表：

选项

描述

文件类型

文件中包含的文本类型。可以是CSV或固定长度。选择CSV并不要求您的数据用逗号分隔，它表示文件有一个必须定义的分隔符。根据此选择，当您在最后一个”字段”标签中按下”获取字段”按钮时，Hfxt将启动一个不同的辅助图形用户界面。

分隔符

用于分隔文本单行中各个字段的一个或多个字符。通常是”;“或制表符。特殊字符（例如CHAR ASCII HEX01）可以使用格式$[值]设置，例如$[01]或$[6F,FF,00,1F]。

插入制表符

点击在”分隔符”框中插入一个制表符。

包围符

可选地，用于成对封装字段值的字符。包围符应出现在字符串的开头和结尾。但是，如果在字符串中间使用相同的字符，则该值将被拆分为两个字段值。为防止这种情况并确保值保持完整，您可以在字符串中间将包围符加倍，这将充当转义字符，并且该值不会被拆分。例如，如果您的包围符是'，而您有一个字段值'six o’clock'，这将被拆分为两个字段值”six o”和”clock”。如果您在中间将包围符加倍，变为'six o''clock'，那么o’clock中的'将不会被解释为包围符，并且值”six o’clock”将出现在结果集中。特殊字符（例如CHAR ASCII HEX01）可以使用格式$[值]设置，例如$[01]或$[6F,FF,00,1F]。

允许包围字段中换行？

如果启用，包围字段中的换行不会导致字段值结束。如果禁用，或者如果换行出现在非包围字段中，则字段值在换行处结束，这可能会影响转换的输出。如果您使用”获取字段”按钮，并且其中一个字段由于换行而结束，则该字段是”获取字段”功能识别的最后一个字段。

转义字符

指定用于标识在字段值中应按原样显示的字符的一个或多个字符，这些字符可能会被解释为控制或格式字符。例如，如果您将\用作转义字符，文本'Not the nine o'clock news'（其中'是包围符）将被解析为Not the nine o’clock news，而不是拆分字段值。特殊字符（例如CHAR HEX01）可以使用格式$[值]设置，例如$[01]或$[6F,FF,00,1F]。

在标题前添加文件名

启用此选项可将文件名添加到文件中的每个字段。这在连接数据时很有帮助，因为它可以清楚地表明每个字段来自哪个文件。

标题

如果您的文本文件有标题行（文件的第一行），请启用此选项。这些通常确定转换中使用的列名。如果您在没有标题的文件上设置此选项，则第一行中的数据值将被解释为标题，这可能会产生意外的结果。在这种情况下，如果字段为空，它将被命名为EmptyField_n，其中n是该行中列的位置。始终检查字段集，以确保正确解释了列名和数据类型。

标题行数

指定文件中包含标题的行数。

页脚

如果您的文本文件有页脚行（文件的最后一行），请启用此选项。这些通常提供有关文件的其他数据，例如谁创建了它或创建日期。页脚通常不进行处理。

页脚行数

指定包含页脚的行数。

行是否换行？

如果您处理的数据行超过特定页面限制而换行，请启用此选项。标题和页脚永远不被视为换行。

换行次数

指定一个值可以换行的行数。超过此值的部分将被视为单独的数据值。

分页布局（打印输出）？

如果此文本文件将被打印，请启用此选项。

每页行数

指定每页将打印的最大行数。最后一页可能包含的行数少于此数。
