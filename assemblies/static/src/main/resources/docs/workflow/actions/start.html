开始

描述

“开始”操作是一个特殊操作，因为它是所有工作流执行的起点。当你启用重复选项时，工作流将持续运行，并根据你指定的时间间隔重新启动。这可以是在特定日期的特定时间戳，也可以是每x秒/分钟。虽然这不能替代调度程序，但可用于基本调度。请注意，使用此功能会使工作流保持运行状态，这意味着Java进程将继续存在并占用系统资源。

描述

开始操作是一个特殊操作，因为它是所有工作流执行的起点。

每个工作流必须有且仅有一个开始操作。
开始操作有重复工作流的附加选项。这在本地和远程工作流引擎中均有效，但主要是出于历史原因而提供的，不应被视为 cron、 Airflow或任何其他类型调度的替代方案。

当你启用重复选项时，工作流将持续运行，并根据你指定的时间间隔重新启动。这可以是在特定日期的特定时间戳，也可以是每x秒/分钟。

虽然这不能替代调度程序，但可用于基本调度。请注意，使用此功能会使工作流保持运行状态，这意味着Java进程将继续存在并占用系统资源。
