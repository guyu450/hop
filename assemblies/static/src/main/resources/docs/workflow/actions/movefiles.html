描述

“移动文件”操作可将多个文件和/或文件夹移动到文件系统中的其他位置。

通过 VFS，此操作也适用于远程文件系统，例如使用FTP协议。

以下是在FTP服务器上移动（重命名）文件的示例（必须为源和目标提供用户名/密码）。

  • 文件源：ftp://username:password@ftpserver/dir/testfile_partly.txt

  • 文件目标：ftp://username:password@ftpserver/dir/testfile.txt

  • 在”目标文件”选项卡中勾选”目标是文件”。
