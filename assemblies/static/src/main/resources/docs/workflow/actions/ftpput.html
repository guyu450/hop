使用FTP上传文件

描述

“使用FTP上传文件”操作可将文件上传到FTP服务器。

描述

“使用FTP上传文件”操作可将文件上传到FTP服务器。

选项

常规选项卡

选项 描述
操作名称 工作流操作的名称。
常规选项卡
FTP服务器名称/IP地址 服务器名称或IP地址。
端口 FTP服务器连接的端口号。
用户名 与FTP服务器账户关联的用户名。
密码 与FTP服务器账户关联的密码。
代理主机 代理服务器主机名。
代理端口 代理服务器端口号。
代理用户名 代理服务器账户用户名。
代理密码 代理服务器账户密码。
测试连接 测试配置的连接。
高级设置
二进制模式 如果文件必须以二进制模式传输，请启用此选项。
超时时间 FTP服务器的超时时间（以秒为单位）。
使用主动FTP连接 如果使用主动模式连接到FTP服务器，请启用此选项；必须将防火墙设置为接受对FTP客户端将打开的端口的连接。默认模式为被动模式。
控制编码 选择用于确定文件名中特殊字符的字符编码。对于西欧和美国，ISO-8859-1通常就足够了。请选择对您的服务器有效的编码。

文件选项卡

选项 描述
源（本地）文件
本地目录 要从中上传文件的本地目录。
浏览…​ 浏览文件系统以选择本地目录。
通配符（正则表达式） 如果要上传多个文件，请指定一个正则表达式来定义要上传的文件集。
传输后删除文件？ 启用此选项可在文件上传后从本地目录中删除这些文件。
不覆盖文件 启用此选项可跳过远程目录中已存在的文件。
远程目录 要将文件上传到的FTP服务器上的目录。
测试文件夹 测试远程目录是否存在。这将连接到FTP服务器并尝试访问指定的目录。如果该目录不存在，上传将失败。
