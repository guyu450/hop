文件存在

描述

“文件存在”操作可验证指定文件是否存在，以及从运行 Hfxt的机器上是否可以访问该文件。您必须提供文件名。Hfxt会根据文件是否存在返回”True”或”False”值。“文件存在”操作可以成为与其他系统轻松集成的一个点。例如，假设您有一个分为三个部分的数据仓库加载过程。第一部分用PERL运行。您有批处理脚本，该脚本从远程位置访问数据，进行一级行处理，并将数据输出到指定目录。在这部分完成之前，您不想启动工作流，因此将工作流放在调度程序上。一旦任务完成，文件就会被放置在一个已知位置，以便”文件存在”。这就是启动最终处理工作流的信号。

在这部分完成之前，您不想启动工作流，因此将工作流放在调度程序上。

选项

选项 描述
操作名称 工作流操作的名称。
文件名字段 指定要验证的文件的文件名和路径。点击”浏览”，通过VFS浏览器导航到源文件或文件夹。
