“ZIP文件”操作会使用您在对话框中指定的选项创建一个标准的ZIP存档。

常规选项卡

选项 描述
操作名称 工作流操作的名称。
源文件
从先前操作获取参数

此复选框从先前工作流操作的结果行中 获取文件名规范。这是将从行中获取的内容。

  • 第一个字段必须包含文件名或文件夹。

  • 第二个字段应包含包含通配符

  • 第三个字段应包含排除通配符。

  • 第四个字段 应包含目标ZIP文件（每个文件可以不同）。
源目录/文件 要压缩的文件的源目录
包含通配符（正则表达式） 要包含 在ZIP存档中的文件的通配符（正则表达式）
排除通配符（正则表达式） 要从Z IP存档中排除的文件的通配符（正则表达式）
包含子文件夹 启用此选项可在子文件夹中搜索文件
ZIP文件
ZIP文件名 目标存档的完整名称
创建父文件夹 如果父文件夹不存在，则创建它
在文件名中包含日期 将日期添加到文件名
在文件名中包含时间 将时间添加到文件名
指定日期时间格式 允许您指定日期/时间格式掩码，
日期时间格式 日期时间格式掩码，如yyyy/MM/dd HHmmss
显示文件名 根据您指定的选项显示示例文件名
