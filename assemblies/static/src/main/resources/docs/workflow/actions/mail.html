邮件

描述

“邮件”操作可发送纯文本或HTML格式的电子邮件，并可选择添加文件附件。此操作可在工作流运行结束时使用，用于宣布运行成功或发送有关工作流失败的通知。例如，在成功加载结束时，向分发列表发送一封电子邮件，宣布加载成功并附上日志文件，这种情况并不少见。如果出现错误，可以发送电子邮件提醒分发列表中的人员。“邮件”操作需要一个SMTP服务器。在连接时可以使用身份验证和安全措施，但必须拥有SMTP凭证。可以将文件（如错误日志和常规日志）附加到电子邮件中。此外，为方便起见，可将日志压缩成一个存档文件。“邮件”操作既可以使用自身定义的邮件服务器配置，也可以从”邮件服务器连接”元数据类型获取服务器连接。在后一种情况下，操作自身的服务器配置将被忽略。

描述

“邮件”操作可发送纯文本或HTML格式的电子邮件，并可选择添加文件附件。

此操作可在工作流运行结束时使用，用于宣布运行成功或发送有关工作流失败的通知。

例如，在成功加载结束时，向分发列表发送一封电子邮件，宣布加载成功并附上日志文件，这种情况并不少见。

如果出现错误，可以发送电子邮件提醒分发列表中的人员。

“邮件”操作需要一个SMTP服务器。

在连接时可以使用身份验证和安全措施，但必须拥有SMTP凭证。

可以将文件（如错误日志和常规日志）附加到电子邮件中。

此外，为方便起见，可将日志压缩成一个存档文件。

“邮件”操作既可以使用自身定义的邮件服务器配置，也可以从 “邮件服务器连接” 元数据类型获取服务器连接。在后一种情况下，操作自身的服务器配置将被忽略。
