Shell

描述

Shell操作会在运行工作流的主机上执行一个Shell脚本。例如，假设你有一个程序，它读取五个数据表并以指定格式创建一个文件。Shell允许你在 Hfxt中完成部分工作，但可根据需要重用读取数据表的程序。Shell工作流操作与平台无关；你可以使用批处理文件、UNIX脚本等等。当你使用Shell工作流操作时，Hfxt会进行Java调用，以在指定位置执行程序。除了调用主机上的脚本外，你还可以直接在Shell操作中输入脚本（例如，Windows上的批处理脚本、Linux上的Shell脚本）。返回状态由操作系统调用提供。例如，在批处理脚本中，返回值1表示脚本执行成功；返回值0（零）表示执行失败。你可以为Shell工作流操作传递命令行参数并设置日志记录。

描述

例如，假设你有一个程序，它读取五个数据表并以指定格式创建一个文件。

脚本或可执行文件

Shell允许你在 Hfxt中完成部分工作，但可根据需要重用读取数据表的程序。

Shell工作流操作与平台无关；你可以使用批处理文件、UNIX脚本等等。

当你使用Shell工作流操作时，Hfxt会进行Java调用，以在指定位置执行程序。

嵌入式脚本

除了调用主机上的脚本外，你还可以直接在 Shell操作中输入脚本（例如，Windows上的批处理脚本、Linux上的Shell脚本）。

返回状态

返回状态由操作系统调用提供。

例如，在批处理脚本中，返回值1表示脚本执行成功；返回值0（零）表示执行失败。

你可以为Shell工作流操作传递命令行参数并设置日志记录。

选项

常规选项卡

选项

描述

操作名称

工作流操作的名称。

插入脚本

当你希望在”脚本”选项卡中执行脚本而不是执行脚本文件名时，请选中此选项。当你想要执行诸如dir、ls或ipconfig等操作系统命令而无需指定特定路径时，此选项也很有用。此选项会在工作目录中创建一个临时脚本并执行它。

给定变量时，会在脚本中解析变量。

脚本文件名

要启动的Shell脚本的文件名，应包含完整路径，否则将使用 ${user.dir} 作为路径。

工作目录

将用作Shell脚本工作目录的目录。工作目录仅在Shell脚本启动时才生效，因此”文件名”仍应包含脚本的完整路径。如果此字段留空或工作目录无效，将使用 ${user.dir} 作为工作目录。

日志记录设置

指定日志文件

启用此选项可指定一个单独的日志文件用于记录此工作流的执行情况。

追加到日志文件

启用此选项可将日志追加到现有日志文件，而不是创建一个新文件。

日志文件名

日志文件的目录和基本名称（例如 C:\logs）

日志文件扩展名

文件名扩展名（例如：log 或 txt）

在文件名中包含日期？

将系统日期添加到文件名中。（_20051231）

在文件名中包含时间？

将系统时间添加到文件名中。（_235959）

日志级别

指定Shell执行的日志记录级别。另请参阅.14 日志记录中的日志窗口。

将上一步结果复制到参数？

可以使用”将行复制到结果”转换将上一个管道的结果发送到Shell脚本（作为参数）。

对每个输入行执行一次

这实现了循环。如果上一个工作流操作返回一组结果行，你可以让此Shell脚本对找到的每一行执行一次。每次执行时，会将一行与”将上一步结果复制到参数”结合传递给此脚本。相应结果行的值可以在命令行参数 $1、$2、…​（在Windows上为 %1、%2、%3、…​）中找到。

参数字段

指定用作Shell脚本参数的字符串。

脚本选项卡

如果选中了 插入脚本选项，此选项卡将包含你的批处理或Shell脚本。
