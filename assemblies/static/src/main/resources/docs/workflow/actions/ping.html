描述

ping主机操作可用于使用ICMP协议ping主机。

当主机可达时，结果为true，否则为false。

选项

选项

描述

工作流操作名称

工作流操作的名称。

主机名/IP

要ping的主机的名称或IP地址

ping类型

要发送到指定主机名或IP地址的ping类型

  • 经典ping：这会将ping作为操作系统的命令行调用。当没有数据包（在”要发送的数据包数量”选项中定义）丢失时，结果为true。

  • 系统ping：此选项使用Java实现的方法。当主机名可以解析且主机在给定的超时时间内可达时，结果为true。

  • 先系统ping再经典ping：尝试两种选项（首先是系统ping，当系统ping失败时，尝试经典ping）

超时时间（毫秒）

使用系统ping选项时的超时时间（毫秒）。

要发送的数据包数量

要发送的数据包数量（默认值为2，仅经典ping选项使用）。
