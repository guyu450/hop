通过FTP获取文件

描述

“通过FTP获取文件”操作可从FTP服务器检索一个或多个文件。此工作流操作不会”遍历”系统。例如，它不会访问远程目录并进入其他目录以查找与通配符匹配的文件。此工作流仅从一个目录检索文件。
