复制文件

描述

“复制文件”操作可复制一个或多个文件或文件夹。

描述

“复制文件”操作可复制一个或多个文件或文件夹。

“文件”选项卡

选项 描述
操作名称 指示操作的名称。
源环境

指示可找到要 输入项的文件系统或特定集群。选项有”本地”和”“。

  • 本地：指定”文件/ 文件夹”字段中指定的项位于Hfxt本地的文件系统中。

  • ：指定”文件/文件夹”字段中指定的项应完全 使用该字段中的路径名。如果您已经知道文件路径， 并且只想将其复制并粘贴到窗口中，请使用此选项。
源文件/文件夹** 要从中复制的文 件或目录。如果在”源环境”字段中选择了”“以外的选 项，请单击该字段中的按钮以查看”打开文件”窗口。
通配符 以正则表达式术语定义要 复制的文件（而不是静态文件名），例如：.*\.txt 表示任何扩展名为 .txt 的文件。
目标环境

指示要将文件 放置到的文件系统或特定集群。选项有”本地”和”“。

  • 本地：指定”文件/ 文件夹”字段中指定的项位于Hfxt本地的文件系统中。

  • ：指定”文件/文件夹”字段中指定的项应完全 使用该字段中的路径名。如果您已经知道文件路径， 并且只想将其复制并粘贴到窗口中，请使用此选项。
目标文件 指示目标环境 的名称。如果在”目标环境”字段中选择了”“以外的选 项，请单击该字段中的按钮以查看”打开文件”窗口。

设置

选项 描述 默认值
包含子文件夹 如果选中，所选目录中的所有子目录也将被复制 未选中
目标是文件 确定目标是文件还是目录 未选中
复制空文件夹 如果选中，将复制所有目录，即使它们为空。要使此选项有效，必须选中”包含子文件夹”选项。（要使此功能生效，通配符必须为空） 已选中
创建目标文件夹 如果选中，如果指定的目标目录当前不存在，将创建该目录 未选中
替换现有文件 如果选中，目标目录中的重复文件将被覆盖 未选中
删除源文件 如果选中，复制后将删除源文件（移动操作） 未选中
将先前结果复制到参数 将先前的结果复制到参数。 未选中
将文件添加到结果文件名 从此操作复制的任何文件都将作为此操作的结果显示；显示在此操作中复制的文件列表 未选中
