等待文件

描述

“等待文件”操作会等待并定期检查文件是否存在。此工作流操作将处于休眠状态，并定期检查指定文件是否存在，之后工作流将继续执行。该操作可以无限期等待文件，也可以在一定时间后超时。

描述

等待文件操作会等待并定期检查文件是否存在。

此工作流操作将处于休眠状态，并定期检查指定文件是否存在，之后工作流将继续执行。

该操作可以无限期等待文件，也可以在一定时间后超时。

此操作需要定义单个文件。可以使用变量，但此操作不支持通配符，因此无法根据文件名模式等待多个文件的存在。

选项

选项 描述
操作名称 工作流操作的名称。
文件名 要等待的文件的名称和路径。
最大超时时间 以秒为单位的最大超时时间，若为0则表示无限期等待。
检查周期时间 检查文件的时间间隔（以秒为单位）。在执行开始时会检查文件，然后每隔”检查周期时间”秒检查一次，直到达到最大超时时间。工作流只能每隔”检查周期时间”停止一次，因为其他时间工作流操作处于休眠状态。30秒或60秒的检查周期时间似乎是在检测到文件的时间周期与所需CPU使用率之间的一个不错的折衷方案。
超时时视为成功 此选项确定当达到”最大超时时间”且未找到文件时的操作。
文件大小检查 启用此选项后，一旦工作流操作检测到指定文件，只有在自上次检查”周期时间秒”后文件大小未发生变化时，工作流才会继续。在文件在最终位置创建且另一个进程仍在写入该文件的情况下，此选项很有用。（最佳做法是将文件写入临时位置，完成后再移动）这是即使文件未创建，工作流也会继续的秒数。当达到超时时间时，“超时时视为成功”选项将决定是执行传出的成功跳转还是失败跳转。如果启用此选项，工作流操作将评估为成功，并执行传出的成功跳转。
将文件名添加到结果 将文件名添加到此工作流操作的结果字段中。
