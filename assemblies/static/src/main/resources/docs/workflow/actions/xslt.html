XSL管道

描述

XSL管道操作使用可扩展样式表语言转换（Extensible Stylesheet Language Transformations，简称XSLT）将XML文档转换为其他文档（XML或其他格式，如HTML或纯文本）。原始文档不会被更改；而是根据XML文件的内容创建一个新文档。

描述

XSL管道操作使用可扩展样式表语言转换或 XSLT 将XML文档转换为其他文档（XML或其他格式，如HTML或纯文本）。

原始文档不会被更改；而是根据XML文件的内容创建一个新文档。

选项 描述
操作名称 工作流操作的名称。
文件
从先前结果获取文件名 选中此选项后，将从先前 的结果集中读取XML文件名、XSL文件名和输出文 件名。如果存在多行数据，将进行循环处理。此 时，XML文件名是结果集中的第一个字段，XSL文 件名是第二个字段，输出文件名是第三个字段。
XML文件名 源XML文件的完整名称
XSL文件名 XSL文件的完整名称
输出文件名 创建的文档的完整名称（XSL转换的结果）
设置
转换工厂 可以选择JAXP或SAXON作为转换工厂。
如果文件已存在

定义 当存在同名输出文件时的行为。可用选项如下：

  • 创 建唯一名称的新文件：将创建一个新的输出文件

  • 不执行任何操作：不会进行任何操作

  • 失败：工作流将失败
将文件添加到结果文件名 将目标文件名添加到此工作流操作的 结果文件列表中，以供下一个工作流操作使用。
