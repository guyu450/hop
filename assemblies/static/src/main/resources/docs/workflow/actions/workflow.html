描述

工作流 操作会将先前定义的工作流作为当前工作流的子工作流来执行。

为方便使用，也可以在对话框中通过点击”新建工作流”按钮来创建新的工作流。

使用”工作流”操作来执行先前定义的工作流。

这使您能够进行”功能分解”。也就是说，您可以用它们将工作流分解为更易于管理的单元。

例如，不应使用包含500个操作的单个工作流来编写数据仓库加载任务。

更好的做法是创建较小的工作流并将它们组合起来。

日志记录设置标签

默认情况下，如果您未设置日志记录，Hfxt将获取正在生成的日志操作，并在工作流内创建一个日志记录。

例如，假设一个工作流要运行三个管道，而您未设置日志记录。这些管道不会将日志信息输出到其他文件、位置或特殊配置中。

在这种情况下，工作流执行并将日志信息放入其主工作流日志中。

在大多数情况下，工作流日志中提供日志信息是可以接受的。
例如，如果您要加载维度，您希望加载维度运行的日志显示在工作流日志中。如果管道中存在错误，它们将显示在工作流日志中。但是，如果您希望将所有日志信息保存在一个位置，则必须设置日志记录。

选项 描述
指定日志文件？ 启用此选项可为此工作流的执行指定一个单独的日志文件
日志文件名 日志文件的目录和基本名称；例如 C:\logs
日志文件扩展名 文件名扩展名；例如，log或txt
日志级别 指定工作流执行的日志记录级别。有关更多详细信息，请参阅 日志记录。
追加到日志文件？ 启用此选项可追加到日志文件，而不是创建新文件
创建父文件夹 如果日志文件的父文件夹不存在，则创建它
在日志文件名中包含日期？ 将系统日期以YYYYMMDD格式（例如20051231）添加到文件名中。
在日志文件名中包含时间？ 将系统时间以HHMMSS格式（例如235959）添加到文件名中。另请参阅”日志记录”中的日志窗口。

参数标签

指定要传递给子工作流的参数：

选项 描述
将结果复制到参数 上一个工作 流或管道的结果会传递到此工作流操作的参数中
将参数值传递给子工作流 启用 此选项可将工作流的所有参数传递给子工作流。
参数 指定要传递给工作流的参数名称。
流列名称 允许您将结果集传入记录的字段捕获为参数。
值

允许您为子工作流 的参数指定值。您可以通过以下方式进行操作：

  • 手动输入一些文本（例如：ETL工作流）

  • 使用参数设 置值（例如：${Internal.workflow.Name}）

  • 使用手动指定的文本和参数值的组合（ 例如：${FILE_PREFIX}_${FILE_DATE}.txt）
