描述

“评估表中的行数”操作可评估表中的行数，并允许您定义成功条件，该条件可用于将工作流分支为成功/错误流。

您可以仅测试目标表中的行数，也可以编写自定义SQL语句。

对于成功条件，您可以检查行数是否：

  • 等于

  • 不等于

  • 小于

  • 小于或等于

  • 大于（默认）

  • 大于或等于
