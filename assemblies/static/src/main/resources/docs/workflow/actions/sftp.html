使用SFTP获取文件

描述

“使用SFTP获取文件”操作使用安全FTP协议从FTP服务器检索一个或多个文件。如果指定的文件或模式被成功检索，该操作返回true；如果在检索文件时出现问题，则返回false。

描述

“使用SFTP获取文件”操作使用安全FTP协议从FTP服务器检索一个或多个文件。

如果指定的文件或模式被成功检索，该操作返回true；如果在检索文件时出现问题，则返回false。

如果在连接到SFTP服务器时遇到 算法协商失败 错误，请查看本页面末尾的 算法协商失败错误 部分。

算法协商失败错误

如果”使用SFTP获取文件“操作返回如下所示的错误消息，则您（或您正在连接的服务器）可能正在使用在最近的 Hfxt版本中此操作所使用的依赖项里被视为不安全的密钥类型。

com.jcraft.jsch.JSchhAlgoNegoFailException: 算法协商失败…​

更好、更安全的选择是将密钥升级到更安全的类型。但是，您仍然可以通过在启动命令（在 hfxt-gui.sh/bat 或 hfxt-run.sh/bat 中，或者在 HFXT_OPTIONS 环境变量中）的 HFXT_OPTIONS 变量中添加以下选项来连接到此SFTP服务器：

-Djsch.client_pubkey=ssh-rsa,ssh-ed25519,ecdsa-sha2-nistp256,ecdsa-sha2-nistp384,ecdsa-sha2-nistp521,rsa-sha2-512,rsa-sha2-256 -Djsch.server_host_key=ssh-ed25519,ecdsa-sha2-nistp256,ecdsa-sha2-nistp384,ecdsa-sha2-nistp521,rsa-sha2-512,rsa-sha2-256,ssh-rsa
