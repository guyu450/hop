获取邮件（POP3/IMAP）

描述

“获取邮件（POP3/IMAP）”操作可从POP3或IMAP服务器检索邮件，并将其存储到一个或多个文件中。

描述

“获取邮件（POP3/IMAP）”操作可从POP3或IMAP服务器检索邮件，并将其存储到一个或多个文件中。

设置选项卡

选项 描述
操作

此下拉框允 许您指定对检索到的电子邮件消息执行的操作：

* 获取邮件 * 将邮件移动到文件夹（仅IM AP支持，因为POP3只知道一个文件夹”收件箱”） * 删除邮件
POP3设置
检索

选择要检索的电子邮件：

  • 所有邮件

  • 检索前……封邮件
检索前……封邮件数量 如果选择”检索前… …封邮件”，则允许您指定要检索的邮件数量。
检索后删除邮件 勾选此项可在检索后删除pop服务器上的邮件。
IMAP设置
选项 描述
IMAP文件夹 IMAP服务器上要从中检索邮件的文件夹
包含子文件夹 勾选此项 可从选定的IMAP文件夹中选择子文件夹中的邮件
检索

选择以下选项之一

  • 获取所有邮件

  • 获取新邮件

  • 获取旧邮件

  • 获取已读邮件

  • 获取未读邮件

  • 获取已标记邮件

  • 获取未标记邮件

  • 获取草稿邮件

  • 获取非草稿邮件

  • 获取已回复邮件

  • 获取未回复邮件
检索前……封邮件 指定要检索的邮件数量
检索后

指定检索邮件后要对电子邮件消息执行的操作：

  • 不执行任何操作

  • 删除邮件

  • 将邮件移动到文件夹
移动到文件夹 将检索到的邮件移 动到IMAP服务器上的另一个文件夹（如果选择了 将邮件移动到文件夹）
创建文件夹 如果不存在，则在IMAP服务 器上创建一个文件夹以将邮件移动到该文件夹。
