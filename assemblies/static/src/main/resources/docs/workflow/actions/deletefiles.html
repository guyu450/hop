删除文件

描述

“删除文件”操作可删除一组指定的文件，也可选择连带子文件夹一起删除。

描述

“删除文件”操作可删除一组指定的文件，也可选择连带子文件夹一起删除。

选项

选项 描述
操作名称 工作流操作的名称。
包含子文件夹 同时删除所选文件夹中的子文件夹
是否将上一步结果复制到参数？ 如果文件集来自上一个工作流操作（作为结果文件的一部分），请启用此选项。
文件/文件夹 要删除的文件或文件夹
通配符 如果上一个选项是文件夹，则此正则表达式用于匹配要删除的文件。例如，要删除所有以.dat结尾的文件，正则表达式应为 ".*\.dat$"。
文件/文件夹列表 要删除的文件/文件夹的完整列表

指定文件夹和通配符（正则表达式）后，使用 添加 按钮将所选文件/文件夹添加到表格中。使用 删除 或 编辑 按钮删除或编辑表格中选定的行。
