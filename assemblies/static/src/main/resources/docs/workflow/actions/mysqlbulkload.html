批量加载到MySQL

描述

“批量加载到MySQL”操作将文本文件中的数据加载到MySQL表中。此操作使用MySQL的LOAD DATA命令。

描述

批量加载到MySQL操作将文本文件中的数据加载到MySQL表中。

此操作使用MySQL的 LOAD DATA 命令。

选项

选项 描述
操作名称 工作流操作的名称。
连接 要使用的到MySQL数据库的连接。
目标模式 要加载的表的模式。
目标表名 要加载到的表的名称。
源文件名 要加载的文件的名称。
本地 如果文件是本地文件，请勾选此项。
优先级

加载文件时的优先级。可用选项如下：

  • NORMAL（默认）：在 LOAD DATA 命令上不设置优先级

  • LOW PRIORITY：使用LOW_PRIORITY修饰符时，LOAD DATA语句的执行会延迟， 直到没有其他客户端从该表读取数据。这仅影响仅使用 表级锁定的存储引擎（如MyISAM、MEMORY和MERGE）。

  • CONCURRENT：使用CONCURRENT修饰符且MyISAM表 满足并发插入条件（即表中间没有空闲块）时，在LOAD DATA执行期间，其他线程可以从该表检索数据。 即使没有其他线程同时使用该表，此修饰符也会对LOAD DATA的性能产生一点影响。
字段终止符 要使用的字段终止符。
字段包围符 要使用的字段包围符。
字段转义符 要使用的转义字符。
行起始符 要使用的行起始字符串。
行终止符 要使用的行终止字符串。
字段 要加载的字段，用逗号 (,) 分隔。
替换数据 如果要替换目标数据中的数据，请勾选此选项。
忽略前 …… 行 忽略文本文件中的前 …… 行。
将文件添加到结果 如果要在后续工作 流操作中重复使用文本文件的文件名，请勾选此选项。
