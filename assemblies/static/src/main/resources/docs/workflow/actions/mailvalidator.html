邮件验证器

描述

邮件验证器操作会检查电子邮件地址是否有效。检查通过时将跳转到成功分支，否则将跳转到失败分支。

描述

邮件验证器 操作会检查电子邮件地址是否有效。

检查通过时将跳转到成功分支，否则将跳转到失败分支。

选项

选项 描述
操作名称 工作流操作的名称。
电子邮件地址 需要检查的电子邮件地址或列表（用空格分隔）。
设置
进行SMTP检查？

默认情况下， Hfxt 仅会检查电子邮件地址的结构（使用正则表达式）。

如果要进行SMTP检查，请 选择此选项并填写发件人电子邮件地址（见下文）。

Hfxt将 从提供的待检查电子邮件地址中提取域名，并尝试从 该域名获取所有交换器。将对每个交换器进行查询。
超时时间 为了 进行SMTP检查，Hfxt将在目标SMTP主机上打开一个套 接字。在此处指定套接字超时时间（默认值为0）。
发件人电子邮件地址 如 果选择了”进行SMTP检查？“选项，则此字段为必填项 。Hfxt需要发件人电子邮件地址才能查询SMTP主机。
默认SMTP服务器 如果您知道要查询哪个SMTP服务器 ，请在此处指定，然后Hfxt将仅查询这一个服务器。
