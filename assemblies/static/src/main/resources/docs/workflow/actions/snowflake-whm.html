Snowflake仓库管理器

Snowflake仓库管理器 操作提供了创建、删除、恢复、暂停和更改Snowflake仓库的功能。

这使得 Hfxt工作流能够在加载数据之前恢复仓库，完成后立即暂停仓库，还能根据部分加载任务可能需要更多处理能力的情况调整仓库大小。

选项

  • 连接：要使用的到Snowflake数据库的连接

  • 仓库名称：仓库的名称

  • 操作：（创建、删除、恢复、暂停、更改）你希望对仓库执行的操作。

操作：创建仓库

此操作使用你提供的设置创建一个新仓库。

选项 描述
替换？ 如果仓库已存在，用你的新设置替换现有仓库。
若仓库存在则失败？ 如果仓库已存在，此操作将失败。如果未选中且 “替换？” 也未选中，若仓库已存在，此操作将不执行任何操作。
仓库大小 （超小、小、中、大、超大、2倍超大、3倍超大）要创建的仓库大小。
仓库类型 （标准、企业）要创建的仓库类型。企业仓库比标准仓库有更多可用内存。
最大集群大小 集群化仓库的最大集群大小。
最小集群大小 集群化仓库的最小集群大小。
自动暂停 仓库在闲置多少分钟后将自动暂停。
自动恢复？ 对仓库运行查询时，仓库是否应自动恢复？
初始时暂停？ 创建的仓库是否应处于暂停状态。
资源监控器 用于跟踪Snowflake使用情况和计费的资源监控器。
注释 关于仓库的注释。

操作：删除仓库

此操作从Snowflake中删除一个仓库。

选项 描述
若仓库不存在则失败？ 如果仓库不存在，此操作将失败。

操作：恢复仓库

此操作在Snowflake中恢复一个仓库。在此操作之前，仓库必须处于暂停状态，否则操作将失败。

选项 描述
若仓库不存在则失败？ 如果仓库不存在，此操作将失败。

操作：暂停仓库

此操作在Snowflake中暂停一个仓库。在此操作之前，仓库必须处于启动状态，否则操作将失败。

选项 描述
若仓库不存在则失败？ 如果仓库不存在，此操作将失败。

操作：更改仓库

此操作更改仓库，使用户能够调整大小、更改仓库类型、更改自动暂停设置等。

选项 描述
若仓库不存在则失败？ 如果仓库不存在，此操作将失败。
仓库大小 （超小、小、中、大、超大、2倍超大、3倍超大）要创建的仓库大小。
仓库类型 （标准、企业）要创建的仓库类型。企业仓库比标准仓库有更多可用内存。
最大集群大小 集群化仓库的最大集群大小。
最小集群大小 集群化仓库的最小集群大小。
自动暂停 仓库在闲置多少分钟后将自动暂停。
自动恢复？ 对仓库运行查询时，仓库是否应自动恢复？
资源监控器 用于跟踪Snowflake使用情况和计费的资源监控器。
注释 关于仓库的注释。
