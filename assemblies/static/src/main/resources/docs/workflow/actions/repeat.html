重复

描述

“重复”操作会重复执行您选择的管道或工作流，直至满足特定条件。该条件可以是： 除了工作流和管道执行器转换之外，“重复”和”结束重复”操作还允许您从工作流构建循环。使用此操作需要一个工作流或管道以及一个运行配置。该操作将持续执行指定的工作流或管道，直到满足以下条件之一：设置了某个变量，或者将变量设置为特定的可选值，或者在子工作流中触发了”结束重复”操作。

描述

重复操作会重复执行您选择的管道或工作流，直至满足特定条件。该条件可以是：

  • 工作流中的某个变量被设置或被设置为某个特定值

  • 在指定的重复工作流中执行了”结束重复”操作

除了工作流和管道执行器转换之外，“重复”和 “结束重复”操作还允许您从工作流构建循环。使用此操作需要一个工作流或管道以及一个运行配置。该操作将持续执行指定的工作流或管道，直到满足以下条件之一：设置了某个变量，或者将变量设置为特定的可选值，或者在子工作流中触发了”结束重复”操作。

如果您使用变量名来指定要重复的文件，请确保设置了带有文件扩展名的默认参数，以便Hfxt知道它是管道文件还是工作流文件。
在管道中设置的作用域为”在JVM中有效”的变量，在重复管道的上游将无法访问。

示例

示例项目示例：/loops/repeat-action.hwf 和 child-check-set-counter-value.hpl 运行一个管道，每次运行时都会增加 ${COUNTER} 变量的值。如果变量值超过10，则会设置变量 ${END_LOOP}。“重复”操作会检测到这个变量，然后循环停止。由于工作流中 COUNTER 的变量作用域设置为”在当前工作流中有效”，因此当您在子工作流中设置 COUNTER 时，新值会向上游传递。

要设置的参数/变量

您可以在此对话框中指定任何参数或 变量的值。这些值本身可以包含变量，在每 次迭代之前都会解析这些变量。如果设置了 执行后保留变量值 选项，我们 将在文件首次执行之前仅计算一次表达式。

要将参数发送到”重复” 操作，请设置”参数/变量名称”和”值”列。” 值”可以是硬编码的，也可以引用参数/变量 名称。参数不会自动在”重复”操作中传递。
