检查Web服务可用性

描述

“检查Web服务可用性”操作会检查给定的URL（例如Web服务URL）是否有效、能否连接以及能否从中读取数据。如果在给定的超时时间内成功连接并能读取数据，该操作将返回”true”，否则返回”false”。有关失败原因的更多信息可以在日志中作为错误日志操作找到。

描述

“检查Web服务可用性”操作会检查给定的URL（例如Web服务URL）是否有效、能否连接以及能否从中读取数据。

如果在给定的超时时间内成功连接并能读取数据，该操作将返回”true”，否则返回”false”。

有关失败原因的更多信息可以在日志中作为错误日志操作找到。

选项

选项 描述
操作名称 工作流操作的名称。
URL 指定要验证的URL。
连接超时时间（毫秒） 以毫秒为单位的连接超时时间。该值取决于此URL的服务质量和经验。
读取超时时间（毫秒） 连接成功后，工作流操作会尝试读取数据。此值给出以毫秒为单位的读取超时时间。该值取决于此URL的服务质量和经验。
