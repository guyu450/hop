Neo4j约束

描述

Neo4j约束操作可用于在Neo4j图中对节点或关系属性创建或删除约束。 要对Neo4j索引执行类似操作，请查看Neo4j索引操作。

描述

Neo4j约束操作可用于在Neo4j图中对节点或关系属性创建或删除约束。

要对Neo4j索引执行类似操作，请查看 Neo4j索引操作。

选项

  • Neo4j连接：要更新索引的Neo4j连接的名称

  • 要执行的约束更新：您可以在此处指定约束更新列表

    • 更新类型：CREATE（创建）或DROP（删除）

    • 要建立索引的对象类型：NODE（节点）或RELATIONSHIP（关系）

    • 约束类型：UNIQUE（唯一）或NOT_NULL（非空）

    • 约束名称：您的约束名称（必填）

    • 对象名称：要更新其约束的节点或关系的标签

    • 属性：要应用约束的属性
