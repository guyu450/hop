写入日志

描述

“写入日志”操作会将特定字符串写入Hfxt日志系统。此操作与”写入日志”转换类似。典型用例是将变量值和其他自定义日志信息记录到Hfxt日志系统中。如果未指定任何字段，它将把所有字段写入日志。如果至少指定了一个字段，它将只打印该字段。必须在”日志消息”部分指定参数和变量。必须设置日志级别。如果希望打印出参数和变量，请将日志详细级别设置为”基本”。在”日志消息”部分打印参数或变量的示例：COUNTER: ${COUNTER} 。如果不存在字段，则必须使用”生成行”转换来创建一个虚拟行，以便打印变量或参数。

描述

写入日志操作会将特定字符串写入Hfxt日志系统。

此操作与 写入日志 转换类似。

典型用例是将变量值和其他自定义日志信息记录到Hfxt日志系统中。

向Hfxt日志系统写入（未加密的）密码或其他敏感信息的变量时要小心！

如果未指定任何字段，它将把所有字段写入日志。如果至少指定了一个字段，它将只打印该字段。必须在”日志消息”部分指定参数和变量。

必须设置日志级别。如果希望打印出参数和变量，请将日志详细级别设置为”基本”。

在”日志消息”部分打印参数或变量的示例： COUNTER: ${COUNTER}

如果不存在字段，则必须使用”生成行”转换来创建一个虚拟行，以便打印变量或参数。

如果错误导致任何内容无法写入日志，请禁用失败的Hfxt，添加日志记录，然后重新运行。
