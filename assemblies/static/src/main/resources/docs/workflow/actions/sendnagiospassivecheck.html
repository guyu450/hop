发送Nagios被动检查

描述

“发送Nagios被动检查”操作会向Nagios发送被动检查。您可以发送监控信息，例如关于工作流中的启动和结束进程的信息。它需要在Nagios服务器上安装NCSA插件（NSCA是一个Linux/Unix守护进程，允许您将来自远程机器和应用程序的被动警报和检查与Nagios集成。对于处理安全警报以及冗余和分布式Nagios设置很有用。）有关Nagios NSCA插件的更多详细信息和设置说明，请参阅Nagios被动检查文档。

描述

发送Nagios被动检查操作会向Nagios发送被动检查。

您可以发送监控信息，例如关于工作流中的启动和结束进程的信息。

它需要在Nagios服务器上安装NCSA插件（NSCA是一个Linux/Unix守护进程，允许您将来自远程机器和应用程序的被动警报和检查与Nagios集成。

对于处理安全警报以及冗余和分布式Nagios设置很有用。）

有关Nagios NSCA插件的更多详细信息和设置说明，请参阅Nagios 被动检查文档。

选项

选项 描述
服务器
操作名称 工作流操作的名称。
主机名/IP地址 Nagios服务器名/IP地址
服务器端口 Nagios服务器端口（通常为5667）。
密码 连接到Nagios服务器NSCA的密码（Nagios服务器和 客户端共享）。如果允许无密码连接，此字段可以留空。
连接超时 在指定 的连接超时（以毫秒为单位）后失败（默认值为5000）。
响应超时 在指定 的响应超时（以毫秒为单位）后失败（默认值为10000）。
发送方
主机名/IP地址 定义您的发送方主机名/IP地址。
服务名称 定义用于记录事件的服务名称。
加密模式

  • 三重DES

  • 未知（默认）
