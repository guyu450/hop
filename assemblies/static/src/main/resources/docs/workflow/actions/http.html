HTTP

描述

HTTP操作使用HTTP协议从Web服务器检索文件。此操作可用于访问合作伙伴网站上的数据。例如，每日数据导出或每日客户列表位于指定的网站。此外，软件即服务（SaaS）提供商可能会提供一个URL来定位报告。您可以调用该URL来检索包含数据的Excel文件或ZIP文件。Salesforce要求您使用SOAP API来检索数据。如果您公司环境中的HTTP流量过大，您可以选择使用带有HTTP身份验证的代理服务器。
