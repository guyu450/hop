使用属性文件

属性文件是用于存储键值对的简单文本文件。它们通常用于在代码库之外管理配置设置和变量。在 Hfxt中，属性文件可用于在工作流中一次性设置多个变量。

属性文件是扩展名为 .properties 的文本文件。文件中的每一行代表一个键值对。键和值可以用等号（=）、冒号（:）或空白字符分隔。

变量替换

“变量替换”选项允许您根据现有变量值动态创建和设置变量。启用此选项后，在设置变量之前，变量名称或值字段中的任何变量引用都将被解析。这使得可以创建名称和值取决于其他变量内容的新变量，从而为工作流中的变量管理提供了一种灵活且动态的方法。使用语法 ${MyVariable} 来检索变量值。
