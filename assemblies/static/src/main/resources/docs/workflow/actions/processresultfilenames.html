处理结果文件名

描述

“处理结果文件名”操作允许您将多个文件和/或文件夹复制、移动或删除到文件系统中的其他位置。

描述

“处理结果文件名”操作允许您将多个文件和/或文件夹复制、移动或删除到文件系统中的其他位置。

选项

选项 描述
工作流操作名称 工作流操作的名称。
操作

从以下选项中选择一个

  • 复制（默认）

  • 移动

  • 删除
目标文件夹 定义目标文件夹
创建目标文件夹 当目标文件夹不存在时，使用此选项创建它
替换现有文件 使用此选项覆盖现有文件
从结果中移除源文件名 使用此 选项从结果文件名列表中移除已处理的文件名
将目标文件名添加到结果 使用此选项将 已处理的目标文件名添加到结果文件名列表中
在文件名中添加日期 将日期添加到目标文件名中，例如 yyyyMMdd
在文件名中添加时间 将时间添加到目标文件名中，例如 HHmmss
指定日期时间格式 允许您指定自己的日期时间格式，例如 yyyyMMdd_HHmmss
在扩展名前添加日期 如果不选中 此选项，日期/时间将附加在文件扩展名之后
限制于
操作限制于 定义包含和排除通配符
通配符（正则表达式） 用于包含文件的正则表达式通配符
排除通配符（正则表达式） 用于排除文件的正则表达式通配符
成功条件
成功条件

成功条件：从以下选项中选择一个：

  • 所有操作正常时成功

  • 至少移动 x 个文件时成功（在下面的限制字段中指定 x）

  • 错误数量小于（在 下面的限制字段中指定最大错误数量）时成功
错误数量小于 上述”成 功条件“选项中指定的错误数量或文件数量。
