简单评估

描述

简单评估操作会评估结果流中变量或字段的内容或值。使用简单评估的输出连接两个操作。如果条件评估成功，将调用绿色（成功）分支；如果条件评估不成功，将调用红色（失败）分支。

描述

简单评估操作会评估结果流中变量或字段的内容或值。

使用简单评估的输出连接两个操作。

如果条件评估成功，将调用绿色（成功）分支；如果条件评估不成功，将调用红色（失败）分支。

用法

  • 空值与空字符串相同。例如，要检测任何数据类型的空值，将类型设置为字符串，将成功条件设置为”如果值等于”，并将值文本框留空。

  • 简单评估操作有一定限制。如需了解更复杂的条件，请参阅：https://hfxt.apache.org/manual/latest/workflow/actions/eval.html
