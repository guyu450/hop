管道

描述

“管道”操作会在工作流中运行先前定义的管道。此操作是从工作流到实际数据处理活动（管道）的接入点。

描述

管道操作会在工作流中运行先前定义的管道。

此操作是从工作流到实际数据处理活动（管道）的接入点。

用法

一个常见工作流的示例包括获取FTP文件、检查必要的目标数据库表是否存在、运行一个填充该表的管道，以及在管道失败时发送错误日志邮件。对于此示例，“管道”操作定义了要运行哪个管道来填充该表。

另请参阅：

  • 工作流操作，它从工作流中执行子工作流。

  • 工作流执行器转换，它从管道中执行工作流。

  • 管道执行器转换，它从管道中执行子管道。

运行配置 管道可以在不同类型的 管道配置 中运行。选择所需的运行配置，以控制管道的执行位置和方式。

日志记录标签

默认情况下，如果您未设置日志记录， Hfxt将获取生成的日志条目，并在工作流中创建一个日志记录。例如，假设一个工作流要运行三个管道，而您尚未设置日志记录。这些管道不会将信息记录到其他文件、位置或特殊配置中。在这种情况下，工作流运行并将信息记录到其主工作流日志中。

在大多数情况下，工作流日志中提供日志信息就足够了。例如，如果您有加载维度，您希望加载维度运行的日志显示在工作流日志中。如果管道中出现错误，它们将显示在工作流日志中。但是，如果您希望将所有日志信息保存在一个地方，那么您必须设置日志记录。

选项 描述
指定日志文件 为运行此管道指定一个单独的日志文件。
名称 指定日志文件的目录和基本名称（例如C:\logs）。
扩展名 指定文件名扩展名（例如.log或.txt）。
日志级别 指定运行管道的日志记录级别。有关更多详细信息，请参阅 日志记录。
追加日志文件 追加到日志文件，而不是创建一个新文件。
创建父文件夹 如果日志文件的父文件夹不存在，则创建它。
在文件名中包含日期 将系统日期以YYYYMMDD格式（_20051231）添加到文件名中。
在文件名中包含时间 将系统时间以HHMMSS格式（_235959）添加到文件名中。

参数标签

向下游传递参数：在”参数”标签上，选中管道转换复选框以 将参数值传递给子管道。参数必须已存在于管道中（例如在管道属性中），或者，在”参数”标签上，您可以指定新参数。“参数”标签允许您覆盖现有参数值，或者通过将值留空将其设为NULL。

向上游传递字段值：子管道需要一个”复制行到结果”转换才能向上游发送一行数据。这要求子管道中存在一行数据。请注意，工作流中不存在行数据，但您可以在后续子管道中使用”获取变量”来使用第一个子管道的字段值。

如果您想从管道向上游传递单个值到工作流并对该变量进行操作，请使用”设置变量”。在这种情况下，您可以选择”在父工作流中有效”的作用域。

选项 描述
将结果复制到参数 使用”复制行到结果”转换 ，将前一个管道的结果作为管道的参数进行复制。
将参数值传递给子管道 将工作流的所有参数传递给子管道。
参数 指定传递给管道的参数名称。
流列名称 指定前一个管道传入记录的字段作为参数。
值 通过以下操作之一指定管道参数值：
- 手动输入值（例如ETL工作流）。
- 使用另一个参数 设置值（例如${Internal.workflow.Name}）。
- 使用手动指定的值和参数值的组合（例如 {openvar}FILE_PREFIX}_${FILE_DATE}.txt）。
获取参数 获取管道已关联的现有参数。
