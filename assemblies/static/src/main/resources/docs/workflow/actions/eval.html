JavaScript

描述

JavaScript操作会运行JavaScript代码并返回一个布尔表达式。该结果可用于确定接下来将执行哪个操作。你可以使用函数、过程调用、与（AND）、与符号（&）、或（OR）、等于（EQUAL）等。JavaScript工作流操作会计算并返回true或false。

描述

JavaScript操作会运行JavaScript代码并返回一个布尔表达式。

该结果可用于确定接下来将执行哪个操作。

你可以使用函数、过程调用、与（AND）、与符号（&）、或（OR）、等于（EQUAL）等。

JavaScript工作流操作会计算并返回true或false。

选项

选项 描述
操作名称 工作流操作的名称。
JavaScript JavaScript字段。

示例

typeof parent_workflow.getVariable("DETAIL_ID_DATASOURCE_ID") != "undefined" && parent_workflow.getVariable("DETAIL_ID_DATASOURCE_ID").toString() == ""
parent_workflow.getVariable("API_RETRY_COUNTER") != parent_workflow.getVariable("API_RETRY_LIMIT")

故障排除

  • 在JavaScript中尽可能去除换行符。

评估

JavaScript操作的结果要么是true，要么是false。换句话说，它需要以一个布尔表达式结束。

以下是一些可能用于结束脚本的评估：

lines_input > 100

或者

true

或者

parent_workflow.getVariable("INPUT_DIRECTORY").equals("/tmp");

以下变量可用于表达式：

变量 描述
errors 上一个工作流操作中的错误数量（长整型）。
lines_input 从数据库或文件中读取的行数（长整型）。
lines_output 写入数据库或文件的行数（长整型）。
lines_updated 数据库表中更新的行数（长整型）。
lines_read 从之前的管道转换中读取的行数（长整型）。
lines_written 写入下一个管道转换的行数（长整型）。
files_retrieved 从FTP服务器检索到的文件数量（长整型）。
exit_status shell脚本的退出状态（整型）。
nr 上一个工作流操作的工作流操作编号（长整型）；在每个后续工作流操作中递增。
is_windows 如果Hfxt在Windows上运行则使用（布尔型）。
parent_workflow 当前工作流操作的父工作流。
action 当前工作流操作。

变量

以下是如何评估变量字符串的内容：

parent_workflow.getVariable("NR_OF_ROWS") == 1000000;

由于我们可以访问parent_workflow对象，我们也可以通过以下方式在父工作流中设置变量：

parent_workflow.setVariable("NR_OF_ROWS", "1000000");

例如，你可以在这个工作流操作中执行以下操作来操作变量：

useDate = parent_workflow.getVariable("use_date").equals("1");
if (useDate == 0) {
  date = new java.util.Date();
  date.setDate(date.getDate()-1); //Go back 1 full day
  dateFormat = new java.text.SimpleDateFormat("yyyyMMdd");
  newDateStr = dateFormat.format(date);
  parent_workflow.setVariable("start_date", newDateStr);
}
