在Windows和Unix之间转换文件

描述

“在Windows和Unix之间转换文件”操作可将文件从Windows（DOS）格式（行尾以CR/LF结束）转换为Linux/Unix格式（行尾以LF结束），反之亦然。当格式未知时，此操作还具有猜测功能，并可转换为另一种格式。
