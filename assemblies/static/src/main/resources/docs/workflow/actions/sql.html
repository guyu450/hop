SQL

描述

SQL操作会从该操作的配置或文件中执行一个或多个SQL脚本。只要用分号分隔，你就可以执行多条SQL语句。SQL工作流操作非常灵活；你可以执行存储过程调用、创建和分析表等等。与SQL工作流操作相关的常见用途包括截断表、删除索引、分区加载、刷新物化视图、禁用约束、禁用统计信息等等。

描述

SQL操作会从该操作的配置或文件中执行一个或多个SQL脚本。

只要用分号分隔，你就可以执行多条SQL语句。

SQL工作流操作非常灵活；你可以执行存储过程调用、创建和分析表等等。

与SQL工作流操作相关的常见用途包括截断表、删除索引、分区加载、刷新物化视图、禁用约束、禁用统计信息等等。

选项

选项 描述
操作名称 工作流操作的名称。
数据库连接 要使用的数据库连接。
从文件加载SQL 启用此选项可从SQL文件名指定的文件中加载SQL语句
SQL文件名 包含SQL语句的文件的文件名。
是否将SQL作为单个语句发送？ 启用此选项可不分隔分号。当给定脚本或多条语句应作为单个语句处理和提交时，此选项通常很有用。
是否使用变量替换？ 启用此选项可在SQL脚本中使用变量。
SQL脚本 要执行的SQL脚本。多条语句可用分号分隔。
