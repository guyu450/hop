描述

“解压文件”操作会将一个或多个文件解压到指定的目标位置。

选项

常规选项卡

选项

描述

操作名称

工作流操作的名称。

源文件

从之前获取参数

如果您想使用（来自之前工作流操作的）结果文件列表作为要解压的文件列表，请选中此选项。

压缩文件名

压缩文件的名称；如果想使用通配符，可以是一个文件夹。

源通配符

如果上一个选项是文件夹，您可以在此处输入正则表达式通配符。

例如：要匹配 /folder/test.zip，正则表达式 te.\.zip 将匹配不到任何内容。

请使用 .*te.\.zip 来匹配它前面的文件夹。

对于Windows文件路径，匹配时斜杠的方向会相反，因此请使用 \/ 而不是 \\。

解压后的文件

使用压缩文件名作为根目录

如果您想为每个压缩文件名创建一个单独的目录（与文件名相同），请选中此项。

目标目录

解压到的目标目录

创建文件夹

如果您想创建目标文件夹，请选中此项。

包含通配符

使用此正则表达式选择压缩存档中要提取的文件

排除通配符

使用此正则表达式选择压缩存档中要提取的文件

在文件名中包含日期

在解压后的文件名中包含当前日期（格式：yyyyMMdd）

在文件名中包含时间

包含时间（格式：HHmmss）

自行指定日期时间格式

允许您自行指定日期时间格式（默认格式为：yyyyMMdd'_'HHmmss）

如果文件已存在

选择如果目标（解压后）文件已存在时要采取的操作：跳过、覆盖等。

提取后

选择压缩文件提取后要采取的操作：

  • 不执行任何操作，

  • 删除文件

  • 移动文件

移动文件到

如果上一个选项是”移动文件”，您可以在此处选择目标目录。
